## 窗口布局

主窗口和 FinalShell 的布局一样，只是会话标签是竖向的：

- 左上：当前会话的服务器监控。
- 左下：竖向会话列表；切到另一页是按文件夹排好的已保存连接（见 [“连接”页](#连接页)）。
- 右上：终端。
- 右下：“文件”“传输”“隧道”“进程”“网络”“命令”六页，也可以在单独的标签中打开（见下面）。

底部面板可以收起，只留下底部的一行标签，终端占满其余的高度。标签行右端、“在单独的标签中打开”左边的箭头按钮收起面板（向下箭头，“隐藏面板”），再点一次展开（向上箭头，“显示面板”）；标签行右键菜单的“隐藏面板”“显示面板”和快捷键“显示或隐藏底部面板”（macOS 上 Cmd+J，Windows 和 Linux 上 Ctrl+Shift+J）也一样。收起时点一个标签的名字，面板就在这一页展开，高度和收起前一样；打开面板某一页的操作也会展开它，比如点服务器监控的进程列表会打开“进程”页。是否收起保存在 `settings.json`，下次启动恢复。在单独的标签中打开的面板就是面板本身，不受影响；全屏时都只显示终端。

底部面板也可以放到终端右边：标签行右键菜单的“将面板移到右侧”把它放进右边的一栏，占满整个高度，终端和命令输入框在左边；“将面板移到底部”放回去。这一栏默认宽 460 DIP，调整窗口大小时宽度不变，多出或少了的宽度都给终端。放不下的标签可以横向滚动（在标签上滚动鼠标滚轮、触控板或键盘），“文件”表格的列也一样。在右边时隐藏面板，这一栏就不显示，终端右边缘留一条窄条，上面是“显示面板”按钮（向左箭头；标签行里的隐藏按钮是向右箭头）；快捷键、窄条的右键菜单和打开面板某一页的操作都会再显示它，和在底部时一样。放在哪一边保存在 `settings.json`。在单独的标签中打开的面板不受影响，全屏也不变。

服务器监控也可以放到右边：它的右键菜单最上面的“移到右侧”把它放进同一栏，“移到左侧”放回去。这时会话列表占满左边一栏，监控放回左边时恢复原来的高度。底部面板在终端下方时，右边一栏只有监控，占满整个高度，在终端和底部面板的右边。面板也在右边时，监控在上、面板在下，中间有分隔条。这时隐藏面板，面板收起为这一栏底部的一行标签，行尾是“显示面板”按钮（向上箭头），监控占满其余的高度；点一个标签就在这一页展开面板。监控无论在哪一边都跟随当前会话，在单独的标签中打开的面板旁边也有它。放在哪一边保存在 `settings.json`；全屏时只显示终端。

所有表格的列都可以拖宽或拖窄：拖动表头右边缘那条细线即可；双击这条线会让该列适配内容宽度（Docker 容器列表、回收站窗口和快速连接列表中则是恢复默认宽度）。Docker 容器列表、桌面的“文件”和“回收站”窗口原来列宽固定，现在也都能拖。Docker 容器列表的名称列占用其他列剩下的宽度：拖动它右边缘的细线，会移动它和后一列之间的边界，名称变宽多少，后一列就变窄多少；双击这条线恢复后一列的默认宽度。列宽在应用退出前一直保留。

## 会话和标签

窗口左下是竖向的会话列表，在顶部切换按钮的“会话 (N)”页。每个会话有一个状态点：绿色是已连接，黄色是连接中，红色是失败。列表可以滚动，会话可以拖动排序。会话的右键菜单有 “重新连接”“复制会话”“断开”“重命名”“关闭”。

主区域上方有一行横向标签，和会话列表是同一组会话：每台服务器一个标签，顺序与列表一致，像浏览器标签一样。一台服务器的标签代表它的行以及它下面的子行（面板行和桌面）。点标签会回到这台服务器上次停留的那一行，终端、底部面板、桌面和监控随之切换；在列表里选中某一行，标签也会跟着切换。标签的右键菜单包含会话列表里这台服务器的操作（“切换到桌面模式”或“切换到终端模式”，按它当前显示的模式给出另一个；“重新连接”“复制会话”“断开”、连接信息），以及“向右分屏”“向下分屏”、“重命名”（直接在标签上改名）和“关闭”，再往下是“关闭其他标签”“关闭右侧标签”“关闭左侧标签”“关闭已断开的标签”“关闭全部标签”。标签行末尾带强调色的“+”新开一个标签页。服务器标签最前面的小图标表示它当前显示的内容，只占一个状态点左右的宽度：`>_` 表示终端，显示器表示桌面，面板行则显示该页的图标；连接状态显示为图标右上角的小圆点（类似角标），鼠标悬停提示里也会写明当前模式。标签平分标签行的宽度，每个最窄 120 DIP；放不下时可以用滚轮横向滚动（不显示滚动条），标签行末尾的下拉菜单列出全部标签，选中后自动滚动到该标签。每个会话各自记住底部面板停在哪一页，切换服务器不会互相覆盖。会话列表里，服务器的面板行和桌面用虚线连到服务器，不同服务器之间留有一点间距。

关闭已连接或正在连接的服务器时会先确认，不论是从标签、列表的关闭按钮或右键菜单，还是用快捷键：关闭会断开连接，它的桌面、面板和传输也一起结束。已断开的服务器、面板行和新标签页直接关闭。从菜单一次关闭多个标签时只确认一次，并说明其中几个仍在连接。

标签行最左边的按钮把整个左侧栏（服务器监控和会话列表）收起，主区域占满窗口宽度；再点这个按钮（这时箭头朝右），或用快捷键“显示或隐藏左侧栏”（macOS 上 Cmd+B，Windows 和 Linux 上 Ctrl+Shift+B），左侧栏重新显示。是否收起保存在 `settings.json`。

会话标签可以起一个只在本次运行有效的名字，用来区分连到同一台服务器的几个标签。右键菜单的“重命名”，或会话列表有键盘焦点时按 F2，会把标签的名字原地变成输入框，名字已选中。按 Enter 保留新名字；按 Esc、点别处或焦点移走则保留原来的名字。名字会去掉首尾空白并保持一行；名字为空或等于主机自己的标题时恢复成主机名，右键菜单的“恢复原名”也一样。改过名的标签，鼠标悬停提示显示主机和地址。凡是称呼这个标签的地方都显示新名字：会话列表和在列表里打字查找、传输，以及改名之后打开的文件编辑器标签。这个名字不会保存：断开、重新连接后仍在，关闭标签后就没了。“复制会话”新开的标签用主机名。新标签页还没有主机，不能改名。在终端里按 F2 会交给终端里运行的程序。

“+”按钮新开一个新标签页（见下面），它左边的终端按钮新开一个[本地终端](#本地终端)。新标签页和会话一样可以切换、拖动、关闭，但标题里的数目不算新标签页。全部关掉后右边仍显示快速连接，在那里连接会新开一个标签页。

连接成功时记下时间，供快速连接的“最近连接”使用。主机的 `noMonitor` 为 `true` 时不轮询服务器状态，也就不开额外的 exec 通道（有些跳板机不允许）。

每个连接每 30 秒发送一次 SSH 保活消息（`keepalive@openssh.com`），和 OpenSSH 的 `ServerAliveInterval` 一样，免得会话安静时，或里面的程序一段时间不输出时，被路由器、防火墙和代理断开。保活不依赖服务器监控和它的 exec 通道；途经的每台跳板机的连接也各自发送；经过 SOCKS5 或 HTTP 代理时，主机的保活消息穿过代理。收到任何回应都算。连续三次没有回应（每次等 15 秒，间隔更短时等一个间隔）就关闭连接，会话显示“连接已断开”，可以重新连接，而不是一直显示已连接，直到敲键盘才发现。间隔在“选项 › 常规”里设置，设为 0 关闭保活。

第一次连接一台主机时弹窗显示主机指纹，信任后记入配置目录里的 `finallyshell/known_hosts`。指纹变化的连接会被拒绝；如果服务器重装过或换过密钥，点错误提示上的 **信任新密钥**，确认新指纹后会替换 `known_hosts` 里这台主机的旧密钥并重新连接。

### 底部面板单独成标签

底部面板标签行最右边的按钮（“在单独的标签中打开”，两个向外的箭头）打开一个面板行：会话列表里缩进在会话正下方的一行，在右边整块区域显示底部面板，不显示终端，方便看“进程”“网络”这些需要高度的表格。这一行显示所选页的图标和名称，比如“网络”。它的提示文字，以及在列表里打字查找时用的文字，是“server1 | 网络”，用的是会话现在的名称；面板行自己不能重命名。会话自己那一行照旧显示终端和底部面板。

- 面板行是同一个会话的另一个视图，不是第二个连接：用的是会话的连接、文件、隧道、进程和网络列表。在面板行里打开的文件夹，会话那一行显示的也是它。
- 它有自己选中的页，打开时是当时选中的那一页，行的图标和名称跟着变。点左边监控里的进程列表会切到它的“进程”页。
- 一个会话最多一个面板行：已经打开时，按钮选中它。
- 在面板行里，这个按钮是“返回终端”（两个向内的箭头），选中会话那一行。面板行一直留着，直到用它的 × 或右键菜单（“返回终端”“关闭”）关掉。
- 拖动会话时面板行跟着走，面板行不能单独拖动。关闭会话时面板行一起关闭，重新连接时保留，显示新的连接。关闭面板行不会断开任何东西。
- 面板行不是会话：“会话 (N)”的数目和退出时的询问都不算它。
- 终端的操作在面板行里不起作用：全屏、查找、命令输入框。
- 新标签页没有这个按钮。连接失败或已断开的会话也能打开面板行，各页显示会话的状态。

### 标签上的编程智能体

会话的 shell 里运行编程智能体时，会话那一行在名称后面、同一行上显示智能体的图标，连到同一台服务器、各自运行智能体的几个标签就分得清了。图标的提示文字是智能体的名称（“Claude Code”）。图标是单色的，用这一行文字的颜色，和其他图标一样。名称太长时先截断名称，图标留着。名称本身不变：重命名过的标签显示自己的名称和图标，传输、在列表里打字查找、编辑器的标签都只用名称。面板行不显示图标，它的会话那一行显示。

| 智能体 | 它的程序 |
|---|---|
| Claude Code | `claude`、`@anthropic-ai/claude-code` |
| Codex | `codex`、`@openai/codex` |
| Gemini CLI | `gemini`、`@google/gemini-cli` |
| pi | `pi`、`@mariozechner/pi-coding-agent` |
| opencode | `opencode`、`opencode-ai` |
| Amp | `amp`、`@sourcegraph/amp` |
| Cursor CLI | `cursor-agent` |
| GitHub Copilot CLI | `copilot`、`@github/copilot` |
| Qwen Code | `qwen`、`@qwen-code/qwen-code` |
| Goose | `goose` |
| Kimi CLI | `kimi` |
| Kiro CLI | `kiro-cli` |
| Aider | `aider`、`aider-chat` |
| Crush | `crush` |
| Droid (Factory) | `droid` |
| Auggie | `auggie`、`@augmentcode/auggie` |

Aider、Crush、Droid 和 Auggie 在应用用的图标集里没有图标，显示一个通用的机器人。

怎么判断：

- 看的是 shell 所在终端的前台程序，和 shell 的目录一起（见[跟随终端目录](#跟随终端目录)），通过会话自己连接的 exec 通道读服务器的 `/proc`，所以连到同一台服务器的两个标签分得开。它的名称，或者它第一个参数的名称，整个等于上表中的一个，就是那个智能体：`pip` 不是 `pi`，`claude-monitor` 也不是 `claude`。程序是运行时或启动器（`node`、`bun`、`deno`、`python`、`npx`、`bunx`、`pnpm`、`uvx` 等，以及 `sudo`）时，看它运行的脚本或包，所以 `node /usr/lib/node_modules/@anthropic-ai/claude-code/cli.js` 和 `npx @openai/codex` 都算。
- 在终端里按回车、命令输入框发送命令后读，大约 250 毫秒和 1.5 秒后各一次；按 Ctrl+C、Ctrl+D、Ctrl+Z 后也读，这几个键不用回车就能结束或暂停智能体。标签显示着智能体时，还每 10 秒读一次，智能体自己退出时图标就会消失。其他时候不读，一个标签同时最多只有一次读取。读取失败（比如超时）时什么都不变：图标留着，每 10 秒的读取也照旧，直到有一次读取成功。
- 看不到：`tmux` 或 `screen` 里的智能体，`ssh` 到另一台主机后运行的智能体；没有 `/proc` 的服务器（macOS、BSD）；关了 exec 通道的主机（`noMonitor`）。用 `sudo` 运行的智能体看得到，除非 `/proc` 挂载时用了 `hidepid`。
- 选项 › 终端 ›“在标签上显示其中运行的编程智能体”默认打开，关掉后不显示图标，也不为此读取（文件面板跟随终端时，它的读取照旧）。

图标来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（MIT 许可证，列在第三方许可证里）。这些图标是其所有者的商标，只用来指明正在运行的程序。

## “连接”页

左下面板顶部的切换按钮“会话 (N) | 连接”在会话标签和已保存的连接之间切换。“连接”页就是连接管理器里那棵文件夹和连接的树，像 MobaXterm 的会话树、Xshell 的“会话”窗格那样一直留在主窗口里，又不占终端的宽度。它显示名称和类型标签，顺序和连接管理器不排序时一样，从不显示已删除的连接。鼠标悬停在连接上显示 `用户@主机:端口` 和备注的第一行。开着会话的连接名称后面有一个点，颜色和会话列表里那个会话的点一样：已连接是绿色，连接中是黄色。

- 双击连接，或选中后按 Enter，打开会话：选中的是新标签页时就在这个标签页里打开，和快速连接一样。会话显示在右边，左下面板仍停在“连接”页，可以接着打开下一台；“会话 (N)”的数目会加上新开的会话。在文件夹上双击或按 Enter 展开或收起它，点箭头、按左右方向键也一样。
- 顶部的搜索框和连接管理器的搜索一样过滤：每个词都要匹配名称、地址、用户名、备注或连接类型，不区分大小写。搜索框下方的类型筛选与搜索同时生效，本次运行中会保留选择。包含结果的文件夹会展开，并选中第一个结果，按 Enter 就能连接；按 ↓ 进入树；按 Esc 清空搜索。它的搜索和类型筛选与连接管理器互不影响。
- 右键菜单和连接管理器的一样：连接上有“连接”“编辑”“复制连接”“重命名”（F2）“移动到文件夹”“复制主机地址”“删除”；文件夹上有“全部连接”“新建连接”“新建子文件夹”“重命名”“移动到文件夹”“删除”；行下面的空白处有“新建连接”“新建文件夹”。F2 和 Delete 作用于选中的行。把行拖到文件夹上，或拖到连接上（进入它所在的文件夹）来移动，和连接管理器一样。
- 删除前都会先问，删除连接也问：连接会移到已删除的连接里，这一页不列出它们，要恢复得在连接管理器里勾选“显示已删除”。
- 显示这一页时，标题栏的“+”是“新建连接”：建在选中的文件夹里，或选中的连接所在的文件夹里。它打开的编辑器和“编辑”打开的编辑器都属于主窗口（不是模态的）；保存后这一页会选中这个连接。
- 两处读的是同一份连接，所以在任一处重命名、移动、删除，另一处马上就能看到。
- “切换会话/连接”快捷键（macOS 上是 Cmd+Shift+E，其他系统是 Ctrl+Shift+E，可以在“快捷键”页修改）在两页之间切换：切到“连接”页时键盘进入搜索框（全屏时先退出全屏），切回会话时键盘回到终端。

显示哪一页存为 `settings.json` 的 `leftPanelPage`，展开了哪些文件夹存为 `connectionTreeExpanded`，按文件夹 ID 记，所以文件夹改名或移动后仍保持展开。在这一页展开或收起任何文件夹之前，所有文件夹都是展开的。这两项都不同步：它们是这台电脑上窗口留下的样子，和窗格大小一样。

## 新标签页和快速连接

启动时打开一个新标签页。上面的“快速连接”列出所有没删除的主机（名称、主机、用户名）：

- 先是最近连接过的（最多 30 个），最后连接的在最上面。
- 下面是其他主机，最后添加的在最上面。新建、复制、导入时记下添加时间（`createdAt`）。没有添加时间的旧主机排在最后，按保存的顺序。

两部分都有时上面分别标着“最近连接”“其他连接”。所以刚添加的主机不用先连接一次，马上就出现在这里。

- SSH 和远程桌面主机使用不同的图标和类型标签。点击或按回车时，SSH 在当前标签页打开会话；远程桌面交给系统客户端打开，不替换当前标签页。
- 搜索框边输入边过滤，按名称、地址、用户名、备注和类型匹配，顺序和不搜索时一样。上下方向键选择，跳过“最近连接”“其他连接”这两行。
- “清空”清掉最近连接记录。不删主机，它们都还列在“其他连接”里。
- “连接管理器”按钮打开连接管理器。在新标签页选中时从连接管理器连接，也连在这个标签页里。
- 一个主机都没有时显示“新建连接”按钮，下面是“连接管理器”按钮，新用户还没添加主机也能从别的客户端导入连接（见下文）。
- 两种页面上都有“本地终端”按钮，在这个标签页里打开[本地终端](#本地终端)。

## 本地终端

本地终端是一个在本机运行 shell、而不是连接服务器的标签，不用离开应用就能试点东西。会话列表标题栏里“+”左边的终端按钮在列表末尾打开一个并选中它（“选项 › 常规”设成不选中新标签时除外）；新标签页上的“本地终端”按钮在这个标签页里打开。没有默认快捷键。

- 它在用户主目录里运行“选项 › [终端](#terminal-defaults)”里的“本地终端程序”，用 MyGo 终端插件的伪终端（macOS 和 Linux 上是 Unix 伪终端，Windows 上是 ConPTY）。没有设置时运行用户的登录 shell（`$SHELL`，没有时 macOS 上是 `/bin/zsh`，其他系统是 `/bin/sh`），Windows 上运行 PowerShell（`pwsh.exe`，没有时 `powershell.exe`，再没有时 `%COMSPEC%` 或 `cmd.exe`）。文字是 UTF-8：主机的编码和退格键、删除键设置是给服务器的。
- 它在列表里的一行和会话的一样，只是状态点换成一台电脑，颜色和状态点一样：程序运行时是绿色，结束后是灰色，启动不了是红色。名字是“本地终端”，下面一行是“本机”，或者程序设置的标题（OSC 0 和 2），和终端应用显示的一样。“重命名”“复制会话”（再开一个本地终端）“断开”（结束程序）“重新连接”“关闭”都和会话一样。“会话 (N)”的数目算它。
- 终端以及它的字体、配色、鼠标、按键、查找栏和全屏都和会话的一样。命令输入框发送到它，命令记在它自己的历史里（`history/local.txt`，见 [configuration.md](configuration.md)）；Tab 不补全任何东西，因为路径和命令名是从服务器读的，历史列表里也没有服务器的历史。
- “命令”页和命令编辑器发送到它。“传输”页和在其他标签上一样，显示所有会话的传输：传输队列是整个应用的，每个传输的“重试”“打开”作用于它自己的会话。“文件”“隧道”“进程”“网络”页都还在，切换时布局不跳，每页显示“本地终端不支持此功能”。底部面板没有“在单独的标签中打开”按钮。
- 服务器监控在哪一边都显示一行“本地终端”，不显示服务器状态，也不轮询任何东西。标签上不显示编程智能体的图标。
- 发送到：“全部会话”不包括本地终端，免得发给所有服务器的命令也在本机运行；从本地终端自己的“命令”页发送时也一样，只发给服务器。“选择会话…”列出它，带电脑图标，可以像会话一样勾选。显示它时，“当前会话”发送到它。
- 程序退出后标签显示“已退出”，“重新连接”、双击它那一行或在终端区域按 Enter（“重新连接”快捷键）在同一个标签里重新启动程序。找不到程序时显示“无法启动 …”和错误；找到了却运行不了时，错误写在终端里，然后程序结束。
- 本地终端的程序在运行时，退出应用会先询问，和已连接的会话一样，单独一行（“还有 1 个本地终端打开，退出会结束其中的程序。”）。
- 本地终端的任何东西都不保存、不同步：重启后本地终端不会回来。

终端区域没有分屏，所以本地终端也没有分屏。监控本机、本地文件浏览、重启后恢复本地终端都没有做。

## 连接管理器

连接管理器在 macOS 上用 Cmd+O 打开，其他系统用 Ctrl+Shift+O（可以在“快捷键”页改）。它是单独的窗口，标题是“连接管理器”。和 FinalShell 一样是文件夹和连接的树，列是名称、类型、主机、端口、用户名、备注（备注只显示第一行）。点列头排序，拖列头边缘改宽度。

主机列表存在 `<用户配置目录>/finallyshell/hosts.json`。密码从不写进去，存在系统的凭据存储里（见[密码存在哪里](configuration.md#密码存在哪里)）。

工具栏：

- 新建连接。
- 新建文件夹：建在选中的文件夹里，选中的是连接就建在它所在的文件夹里。
- 全部折叠、全部展开。
- 导入：从别的客户端导入连接（见下面）。
- 显示已删除。
- 文件夹筛选：“全部”，或只看某个文件夹。
- 类型筛选：“全部类型”“SSH”或“远程桌面”。
- 搜索框。

连接管理器打开时，文件夹保持上次离开时的展开或折叠状态，重启后也一样（`managerTreeExpanded`）；第一次打开时全部折叠。用“全部展开”“全部折叠”或点箭头改变。

树的下面是“连接后关闭窗口”，默认勾选。它记在 `settings.json` 的 `keepManagerOpen` 里，没有这一项就是关闭。

搜索边输入边过滤，按名称、地址、用户名、备注和类型匹配，每个词都要匹配，不分大小写。搜索与两个筛选条件同时生效。自动展开含有结果的文件夹并选中第一个结果，回车就连接它。清空搜索并取消类型筛选后恢复原来展开的文件夹。

双击连接或按回车：在主窗口打开会话（主窗口选中的是新标签页时就连在那个标签页里），把主窗口提到前面，勾选了“连接后关闭窗口”就关掉连接管理器。

连接的右键菜单：

- 连接。
- 编辑。
- 复制连接：副本的名称是“<名称> - 副本”。代理或跳板机设置、隧道、记住的密码和代理密码也一起复制，凭据存储里的也复制到新连接下。
- 重命名（F2）。
- 移动到文件夹。
- 复制主机地址：复制主机的地址。
- 删除（Delete 键）。

文件夹的右键菜单有全部连接、新建连接、新建子文件夹、重命名、移动到文件夹、删除。删除文件夹前先问。里面的连接和子文件夹移到它的上一级（顶层的文件夹就移到顶层），提示里会写明移到哪里。

“全部连接”按树里的顺序，为这个文件夹及其子文件夹里的每个连接打开会话，每个都和双击一样打开：第一个在选中的新标签页里（选中的是新标签页时），其余各开一个标签页；勾选了“连接后关闭窗口”就关掉连接管理器。已删除的连接不算在内，文件夹里没有连接时这一项不可用。超过 10 个连接时先问“连接 N 台服务器？”，并写明文件夹。不知道密码的连接会弹出密码框，后面的连接等它答完，所以密码框一次只弹一个；点“取消”跳过这个连接，接着连下一个。“连接”页的右键菜单也有这一项。

把连接或文件夹拖到文件夹那一行就移进去，拖到连接那一行就移到那个连接所在的文件夹，拖到空白处移到顶层。文件夹不能拖进自己或自己的子文件夹。

删除连接只是移到“已删除”（`deletedAt`）。勾选“显示已删除”后，已删除的连接灰色显示在原来的文件夹里，右键可以“恢复”或“彻底删除”（先问）。彻底删除都走 `deleteHostForever`，同时清掉为这个主机记住的密码和代理密码，内存里的和凭据存储里的都清掉。

删除（或彻底删除）别的连接正在用的跳板机时先问，提示里列出哪些连接会因此连不上。跳板机的下拉框本来就只列没删除的连接。

从连接管理器打开的连接编辑器是连接管理器的模态窗口（见 [子窗口](development.md#子窗口)）。保存后连接管理器里马上显示并选中这个连接。

主窗口的 [“连接”页](#连接页) 显示的是同一棵树，一处的改动另一处马上就能看到。

## SSH 密钥

从 **选项 → SSH 密钥**打开密钥管理器，也可在已保存连接的“终端”页点击**部署公钥**。列表包括 `~/.ssh` 中的密钥及已保存连接引用的其他路径。可以筛选密钥，或按文件名、类型、位数、加密状态、注释、SHA256 指纹和引用主机数排序。详情显示完整指纹和随机艺术图；**复制公钥**只复制 OpenSSH 格式的公钥，不会复制私钥。

可生成 Ed25519（默认）或 RSA 4096 密钥，也可导入已有的 OpenSSH 兼容私钥。生成时可设置口令。新密钥对写入 `~/.ssh`；替换未被连接引用的密钥时须单独确认，现有两个文件都会先备份。删除仍被连接引用的密钥须再次确认；删除只影响本地，不会从服务器撤销公钥。管理器不删除 `~/.ssh` 之外的密钥。

**部署公钥**可选中多个已保存的 SSH 连接。程序用已有凭据登录，以登录用户的身份把公钥加入各自的 `~/.ssh/authorized_keys`，无需 root。追加前保留带时间戳的备份；不会重复添加，也不会绕过已有公钥条目的限制。结果按主机显示。验证会新建 SSH 连接，只能用所选密钥认证，不回退到密码。只有验证成功的连接才能切换为密钥登录；除非主动勾选清除密码，否则凭据库会保留旧密码。没有可用凭据时，请先正常连接一次，再重试部署。

**禁用密码认证**是独立的可选操作，会影响整台服务器。只有本次部署已验证密钥登录成功，而且再次使用该密钥登录后能通过公共提权流程执行操作，才会修改配置。如果 OpenSSH 主配置足够靠前地包含标准片段目录，优先写入配置片段；否则备份并修改主配置。存在自定义 Include 或 Match 规则时不自动修改，请人工处理。`sshd -t` 和生效配置检查均通过后才重载；失败时回滚改动并保留备份。请保留一个独立的恢复会话：禁用密码认证可能使其他用户或服务无法登录，键盘交互认证不受影响。

## 导入连接

连接管理器工具栏的“导入”打开“导入连接”窗口，是连接管理器的模态窗口。顶上的“导入来源”选从哪里导入：下面的各个来源，每个一节。窗口打开时是这次启动以来最后选的来源（第一次是 FinalShell）。

选了来源就去它存放连接的地方找它的文件或目录（读文件在 goroutine 里，读完通过 `App.post` 显示）。找不到，或者这个来源没有固定的位置，就弹出选择文件或文件夹的对话框（显示隐藏文件和文件夹）。取消了就说明要选什么，并给出选择的按钮。读到之后，顶上显示它的路径（除了 Windows，主目录写成 `~`），旁边的“选择文件…”或“选择文件夹…”随时换一个。

窗口里列出读到的所有 SSH 连接（名称、主机、用户名、文件夹、说明），每行一个复选框，默认全选。“全选”“全不选”改变所有行，回车、双击或空格切换选中的一行。

- 和已有主机地址（不分大小写）、端口、用户名都相同的连接灰色显示“已存在：…”，不能勾选，不会导入。来源里两条相同的，只导入第一条。
- 读不了的文件或文件里的行（格式不对、太大、读取失败、没有主机地址）算失败。其他类型的连接（RDP、VNC 等）和在别的客户端里已删除的连接算跳过。两种都列在表格下面，带着文件名，或者文件名和行号（`文件:行`）。
- “说明”列写着连接的哪些设置没有导入，比如代理，或者导入后要选私钥文件，以及它要经过的跳板机。

点“导入 N 个”：按来源的文件夹结构放进同名文件夹。从顶层逐级按名称找，已有的就用，没有就新建，只建有连接导入的文件夹。没有文件夹的来源导入到顶层。然后关掉窗口，在连接管理器里展开这些文件夹、选中第一个导入的连接，连接管理器底部显示导入、跳过、失败各多少个，以及多少个要选私钥文件。

所有来源都一样：

- 添加时间（`createdAt`）记为导入的时间，所以导入的连接在快速连接里排在“其他连接”的前面。
- 别的客户端存的密码不导入：它们用自己的密钥加密，Finallyshell 不解密。第一次连接时会询问（默认记住，存进系统的密钥库）。带密码的服务器列表，密码存进系统的密钥库，和“记住密码”一样，不会写进 `hosts.json`。
- 来源写明的私钥文件就是导入后主机的私钥文件。存在别的客户端自己的密钥库里的私钥不导入：主机是“私钥”认证但没有私钥文件，“说明”列和导入结果会提示去选。

### 从 FinalShell 导入

FinalShell 把连接存在数据目录的 `conn` 文件夹里，Finallyshell 按顺序找数据目录：

- Windows：`%LOCALAPPDATA%\finalshell`、`%APPDATA%\finalshell`、`%ProgramFiles%\FinalShell`、`%ProgramFiles(x86)%\FinalShell`、`C:\finalshell`。FinalShell 装在别的目录、数据也在安装目录里时，要自己选。
- macOS：`~/Library/FinalShell`、`~/Library/Application Support/finalshell`。
- Linux：`~/.finalshell`、`~/.local/share/finalshell`。

可以选数据目录、它的 `conn` 文件夹，或者 FinalShell 导出的文件夹。

导入的字段：名称、主机、端口、用户名、备注（`description`）、文件夹、认证方法、是否启用 exec 通道（关掉的导入后关闭服务器监控）。添加时间不用 FinalShell 的 `create_time`。

- 密码不导入。FinalShell 把密码加密存在文件里，Finallyshell 不解密，也不读这个字段。
- 私钥认证的连接导入后是“私钥”认证但没有私钥文件。FinalShell 把私钥存在它自己的 `config.json` 里，连接只记着私钥的 ID；这个文件不读，要编辑连接选私钥文件。
- 代理（`proxy_id` 指向 FinalShell 自己的代理列表）、端口转发、终端编码、退格键设置都不导入（还不知道 FinalShell 存的值是什么格式）。用了代理的连接在“说明”列里注明。

FinalShell 的文件格式没有官方文档，导入按其他开源客户端（Hatoba、LiteShell、MeatShell、OpenFinalShell）的 FinalShell 导入代码整理，写在 `internal/importer/finalshell.go` 的注释里。解析尽量宽松：不认识的字段忽略，缺的字段用默认值（端口 22、密码认证），端口写成字符串也认。

当 `protocol` 或 `conection_type` 明确写出协议名称时，也能导入 Telnet 和串口连接；不根据端口猜测未知的数字类型。文件中有可识别的串口参数时会一并导入。

### 从 Xshell 导入

Xshell 把每个会话存成一个文件 `<名称>.xsh`，放在它的 `Sessions` 文件夹里，子文件夹就是它的文件夹。在 Windows 上，Finallyshell 按顺序找这个文件夹：

- `文档\NetSarang Computer\<版本>\Xshell\Sessions`（Xshell 6 及以后），新版本优先，用户目录的“文档”和 OneDrive 的“文档”都找。
- `文档\NetSarang\Xshell\Sessions`（Xshell 5）。
- `%APPDATA%\NetSarang\Xshell\Sessions`（更早的版本）。

在 macOS 和 Linux 上，或者 Xshell 的会话存在别处（在它的选项里设置）时，要自己选。可以选 `Sessions` 文件夹、它所在的 `Xshell` 文件夹，或者任何里面有 `.xsh` 文件或 `.xts` 导出文件（Xshell 的“文件”→“导出”）的文件夹：导出文件直接读，不解压，里面的文件夹导入到它所在的文件夹下面。选择对话框只能选文件夹，所以要导入 `.xts` 文件，就选它所在的文件夹。

导入的字段：名称（文件名去掉 `.xsh`）、主机、端口、用户名、备注（会话的“说明”）、文件夹、认证方法。支持 SSH、Telnet 和串口，跳过 Rlogin 等不支持的类型。Telnet 还会保留终端类型和登录提示文本。导入串口后请核对设备名和参数；无法识别的参数使用默认值。

- 密码不导入。Xshell 把密码加密存在会话文件里，Finallyshell 不解密，也不读这个字段。
- 公钥认证的会话导入后是“私钥”认证但没有私钥文件：Xshell 把私钥存在它自己的密钥库里，会话只记着私钥的名字。要编辑连接选私钥文件（需要的话从 Xshell 的“用户密钥”导出成 OpenSSH 格式）。
- 代理（Xshell 自己代理列表里的名字）、端口转发、终端设置都不导入。用了代理的会话在“说明”列里注明。

Xshell 的会话文件没有官方文档，导入按用户公开的会话文件和其他读这种文件的工具整理，写在 `internal/importer/xshell.go` 的注释里。Xshell 6 及以后写的文件（UTF-16）和旧版本写的文件（ANSI 代码页，中文 Windows 上是 GBK）都能读。解析尽量宽松：不认识的段和字段忽略，没写协议算 SSH，没写端口算 22。

### 从 SecureCRT 导入

SecureCRT 在配置文件夹的 `Sessions` 文件夹里每个会话存一个 `.ini` 文件，它的每个文件夹是一个子文件夹。Finallyshell 在这里找配置文件夹：

- Windows：`%APPDATA%\VanDyke\Config`。
- macOS：`~/Library/Application Support/VanDyke/SecureCRT/Config`。
- Linux：`~/.vandyke/SecureCRT/Config`。

SecureCRT 可以把配置文件夹放到别处（Options › Global Options › General › Configuration Paths 里能看到在哪）。可以选配置文件夹、它的 `Sessions` 文件夹，或者里面的某个文件夹（导入它的会话，文件夹从它下面算起）。`Sessions` 顶层的 `Default.ini` 是 SecureCRT 的默认设置，`__FolderData__.ini` 是文件夹里会话的顺序，都不是会话。最多读 10000 个会话文件，超出后的第一个列为失败。

导入的字段：名称（去掉 `.ini` 的文件名）、主机、端口、用户名、备注（会话的描述）、文件夹。支持 SSH2、SSH1、Telnet 和串口，跳过 RLogin、RDP 等不支持的类型。串口会保留 COM 口或设备名及可识别的参数。

- 密码不导入。SecureCRT 把密码加密存在会话文件里，Finallyshell 不解密，也不读这些行。
- 有自己的私钥文件的会话（公钥选项里设的）导入后是“私钥”认证，用这个私钥文件；SecureCRT 写的是 `.pub` 文件时，用对应的私钥。路径里的 `${VDS_CONFIG_PATH}` 是配置文件夹。用 SecureCRT 全局私钥的会话，如果它的认证方法里公钥排在密码前面，就用配置文件夹里 `SSH2.ini` 写的全局私钥文件。认不出的私钥路径（别的 SecureCRT 变量、在 macOS、Linux 上读到 Windows 路径，或者 `Sessions` 文件夹旁边找不到 `SSH2.ini` 时的全局私钥）导入后要自己选私钥文件，“说明”列会提示。
- 防火墙设置不导入：通过代理连接的会话在“说明”列写“代理没有导入”，通过另一个会话（跳板机）连接的写“跳板机没有导入”。端口转发、登录动作、终端和外观设置也不导入。

SecureCRT 的文件格式没有官方文档，导入按 VanDyke 的脚本示例和其他开源项目的 SecureCRT 读取代码整理，写在 `internal/importer/securecrt.go` 的注释里。解析尽量宽松：别的格式的行和用不到的选项忽略，缺的用默认值（SSH2、端口 22、密码认证），多行的值（二进制值，以及描述以外的列表）跳过。

### 从 MobaXterm 导入

MobaXterm 把会话存在 `MobaXterm.ini` 里。在 Windows 上，Finallyshell 先找 `%APPDATA%\MobaXterm`（安装版），再找 `Documents\MobaXterm`。便携版把它放在 `MobaXterm.exe` 旁边，要自己选。也可以选从 MobaXterm 导出的会话文件：“Export all sessions to file”或“Export sessions from this folder”导出 `.mxtsessions` 文件，“Save session to file”导出一个会话的 `.moba` 文件。中文 Windows 上保存的文件（GBK 编码）也能读。

支持 SSH、Telnet 和串口，跳过 RDP、VNC、SFTP 等不支持的类型。串口会保留 COM 口和可识别的参数。导入的字段：名称、主机、端口、用户名（MobaXterm 的 `<default>` 是不指定用户名）、注释（作为备注）、文件夹（会话文件夹，和 MobaXterm 里一样嵌套；单独导出的文件夹就是同名的文件夹），以及私钥文件，作为主机的私钥文件（路径里的 `_CurrentDrive_` 就是盘符 `C`）。在 macOS 和 Linux 上，Windows 的私钥路径在本机不存在：主机是“私钥”认证但没有私钥文件，导入后再选。

- 密码不导入。MobaXterm 把密码加密存在会话之外（有主密码保护），Finallyshell 不读。
- SSH 网关（跳板机）和代理不导入：主机直接连接，“说明”列里会注明。导入后可以在连接编辑器里设置跳板机。
- 终端设置、颜色和字体、登录后执行的命令、X11 转发、MobaXterm 的 SSH 隧道都不导入。

MobaXterm 的文件格式没有官方文档，导入按 Ruzgfpegk 的 gist “.mxtsessions file format”（对 MobaXterm 26.3 逆向整理的格式说明）和其他开源工具（mobaConverterGo、mobaxterm2ssh、mobaxterm-mcp）的读取代码整理，写在 `internal/importer/mobaxterm.go` 的注释里。还没有用用户的真实文件核对过，所以解析尽量宽松：不认识的段和字段忽略，缺的字段用默认值（端口 22、密码认证），读不了的行算作失败，并标出行号。

### 从 SSH 配置文件导入

OpenSSH 客户端的配置 `~/.ssh/config`（Windows 上是`%USERPROFILE%\.ssh\config`）存在就读它；不存在，或者点“选择文件…”，可以选任意文件（文件名不限）。按 `ssh` 的读法读：

- `Host` 行的每个名字是一个连接，以这个名字命名：`Host web db` 是两个。通配模式（带 `*`、`?` 或 `!` 的名字）不是连接，但其中的设置用于匹配到的名字；第一个 `Host` 之前的行用于所有名字。每项设置取文件里第一个适用的行，和 `ssh` 一样：末尾 `Host *` 下写 `User deploy`，所有自己没写用户名的主机都用它。
- 导入的字段：`HostName`（`%h` 是名字；没写就用名字作主机）、`Port`、`User`（没写就用本机的用户名，和 `ssh` 一样）、第一个 `IdentityFile` 作私钥文件，以及 `ProxyJump`。关键字不分大小写，`Key value` 和 `Key=value` 都认，值可以加引号，`#` 是注释。
- 私钥文件路径里，`~` 保留为主目录，`%d`（主目录）、`%u`（本机用户）、`%h`（主机）、`%r`（用户名）、`%n`（名字）、`%p`（端口）和 `%%` 会展开。其他记号原样保留，“说明”列里注明。
- `ProxyJump` 指向文件里的另一个名字时，两个都导入后（或者跳板机已存在），那个连接就是跳板机，“说明”列里显示。链式的（`a,b`）用最后一跳。跳板机不是文件里的名字（`user@host:port`，或者没有对应的 `Host` 行），或者没有导入，就不设置：主机直接连接，“说明”列里注明；说明跟着勾选变：取消勾选跳板机，经过它的主机马上改成没有导入。`ProxyCommand` 也不导入，按代理注明。
- `Include` 就地读入其他文件，支持通配符；相对路径在所选文件的目录里（即 `~/.ssh`，和 `ssh` 一样）。最多读 16 层、256 个文件。
- 连接导入到顶层，没有备注。有私钥文件的主机用“私钥”认证和这个文件；其他的用密码认证，第一次连接时询问（文件里没有密码）。

列在表格下面的：只有通配模式的 `Host` 行和 `Match` 块（不支持）算跳过；不是 1 到 65535 之间数字的 `Port`（忽略）、解析不了的行（引号没有闭合）、读不了或超过限制的 `Include` 算失败。其他关键字（`LocalForward`、`CertificateFile` 等）忽略。

### 从 CSV 或 Excel 文件导入

“CSV 或 Excel 文件”导入记在表格里的服务器列表：`.csv`、`.tsv`、`.txt` 文件，或者 Excel 工作簿（`.xlsx`）里第一个没有隐藏的工作表。它没有固定的位置，所以选了就直接弹出选择文件的对话框。窗口底部的“保存模板…”保存一个 `servers.csv`（默认放在下载目录）：表头用界面的语言，还有一行示例，照着填好再导入。

第一行是表头（上面有标题行也行：前十行里第一个有主机列的行就是表头）。按表头找列，不分大小写，忽略空格、`_` 和 `-`；别的列忽略：

| 字段 | 表头 |
| --- | --- |
| 名称 | name、label、title、名称、名字、别名 |
| 主机（必需） | host、hostname、address、ip、ip address、主机、主机名、主机地址、地址、ip地址 |
| 端口 | port、端口 |
| 用户名 | user、username、login、用户、用户名、账号 |
| 密码 | password、密码 |
| 私钥 | key、private key、key file、identity file、私钥、私钥文件 |
| 文件夹 | folder、group、文件夹、分组 |
| 备注 | notes、note、description、comment、comments、备注、说明 |

- 没有主机列的文件不导入，窗口里列出读到的表头。
- 按文件里的顺序列出。空行跳过。没有主机、或者端口不在 1 到 65535 之间的行，带着行号列在表格下面，算失败。
- 主机写成 `主机:端口`（IPv6 地址写 `[IPv6]:端口`）的，导入时主机只取主机部分；端口格是空的时用这个端口（端口格有值就用端口格的）。不带方括号的 IPv6 地址不拆。写成 `用户@主机`，用户名格是空的时就用这个用户名。
- 单元格前后的空格忽略，密码格除外：密码按写的原样导入。只有空格的密码格算空。
- 文件夹写 `生产/数据库`（或者用 `\`）是嵌套的文件夹。没有文件夹列的列表导入到顶层。
- 写了私钥文件的主机用这个私钥登录，它的密码格不用。其余的用密码登录。
- 密码存进系统的密钥库，和“记住密码”一样，不会写进 `hosts.json`。表格里有一列“密码”，有密码的行显示 `••••`，不显示密码本身。

文本文件：按 Excel 保存时的编码读：“CSV UTF-8”（带字节顺序标记）、普通的“CSV”（系统的代码页，中文 Windows 上是 GBK）、“Unicode 文本”（UTF-16，用制表符分隔）。分隔符从制表符、`;`（很多欧洲语言的 Excel 这样存 CSV）、`,` 里选：按哪一个分，前十行里有一行是带主机列的表头，就用哪一个，所以表头上面的标题行不影响（几个都行时，用表头里认得的列最多的那个）。没有主机列的文件看第一行：有制表符就是制表符；`;` 比 `,` 多就是 `;`；否则是 `,`。第一行写 `sep=;` 的，按它说的来。引号按 Excel 的写法读。

Excel 文件：单元格都按文字读，数字不带末尾的 `.0`，公式读 Excel 或 LibreOffice 保存时一起存下的结果。不套用数字格式（日期、货币）。Excel 97-2003 工作簿（`.xls`）、设了密码的工作簿、OpenDocument 表格都读不了：窗口会请你另存为 `.xlsx` 或 CSV。有些系统导出的 `.xls` 其实是文本文件，按文本读。

限制：文件最大 10 MB，前 10000 行以后的不读（列出第一个没读的行）。工作簿的每个部分解压后最多 32 MB，工作表最多大约一百万个单元格。

## 连接编辑器

“新建连接”和“编辑连接”打开一个单独的窗口，左边是页面，下面是“确定”“取消”。

### SSH 连接

- 名称、主机、端口、备注（多行）。
- 认证方法（密码、私钥或 SSH Agent）、用户名，然后是密码，或者私钥文件（“浏览…”选文件）和私钥密码。
- “记住密码”（私钥是“记住私钥密码”），默认开。
- **双因素认证（TOTP）**：粘贴 Base32 密钥或 `otpauth://totp/` URI。普通密钥默认使用 6 位验证码、30 秒周期和 SHA-1；URI 还可指定 8 位验证码、其他周期，以及 SHA-256 或 SHA-512。保存或移除时需要确认；留空会保留原密钥。TOTP 密钥与登录密码分开存储。
- “启用 exec 通道（服务器监控）”。

错误提示显示在对应的输入框下面。

SSH 键盘交互式认证要求验证码时，客户端使用对应主机保存的 TOTP 密钥；验证码有效期只剩 3 秒或更短时，等待下一组。密码提示仍使用登录密码。没有保存 TOTP 密钥时，交互式连接会显示服务器的提示，请你手动输入验证码。在“连接”页或连接管理器中右键单击 SSH 主机，选择 **复制当前验证码**。菜单或复制提示会显示有效期；验证码本身只写入剪贴板。剪贴板历史由系统管理。

选 **SSH Agent** 时，用 SSH Agent 里的私钥登录（Bitwarden、1Password、KeePassXC、OpenSSH 的 `ssh-agent`、Windows 的 OpenSSH agent 服务），硬盘上不需要私钥文件。私钥文件、私钥密码、密码和“记住密码”都不显示，仍可选填 TOTP。“SSH Agent：使用 选项 › 常规 里的地址”这一行有个 **检测** 按钮，列出 agent 里的私钥（类型、SHA256 指纹、备注），不登录；只是列出私钥，不会让 agent 弹窗请你批准。连接时像 OpenSSH 一样依次尝试 agent 里的私钥，直到服务器接受其中一把。Bitwarden 等每次签名都会弹窗请你批准，连接会一直等你的答复。登录期间 agent 的连接一直开着，登录后关闭。跳板机也能用 SSH Agent 登录，每一跳按它自己的方式登录。

失败时，终端上方的提示条说明原因，并带一个“SSH Agent 设置”按钮，打开 选项 › 常规：地址上找不到 agent（写出地址，或者说没有设置 `SSH_AUTH_SOCK`）、agent 里没有私钥、服务器拒绝了 agent 里的所有私钥、agent 没有签名（被你拒绝了）。不会弹出密码框。不支持 agent 转发（`ssh -A`）。

### 远程桌面

选择 **远程桌面**，用系统的客户端打开保存的连接：Windows 使用 mstsc，
Linux 使用 FreeRDP，macOS 使用 Windows App。编辑器可以设置显示、
本地资源、连接及网关选项。

#### 通过 SSH 使用远程桌面

在 **连接** 页的 **通过 SSH 主机连接** 中选择一台已保存的 SSH 主机。
**SSH 主机访问的目标** 可以填写内网主机名或 IP，也可以带端口；留空则使用
远程桌面连接的地址和端口（默认 3389）。此模式不能和远程桌面网关同时使用。

Finallyshell 按 SSH 主机原有的方式登录并验证主机密钥，或复用已有的 SSH
会话。先从 SSH 主机检查目标 TCP 端口，再在本机 `127.0.0.1` 建立隧道，
并将这个地址交给远程桌面客户端。客户端仍会验证登录身份和证书；证书名称
与回环地址不匹配时可能有提示。Windows 和 Linux 上，客户端进程退出后隧道
会停止。macOS 上请在用完后到 **隧道** 页停止隧道；Windows App 会自行询问密码。

### Telnet 连接

在连接编辑器中选择 **Telnet**，填写主机和端口（默认 23），需要时可开启每 30 秒一次的保活。不保存连接也可以在“快速连接”中输入 `telnet://主机[:端口]` 后按回车；IPv6 地址需要用方括号括起来。不要在地址中写用户名或密码。“终端”页可设置上报的终端类型、字符编码和退格键、删除键的行为；对端支持窗口尺寸协商时，调整终端大小会同步给对端。

自动登录默认关闭，导入的连接也是如此。“认证”页默认不区分大小写地匹配 `login:` 或 `username:`，以及 `password:`，也可自定义正则表达式。只有先匹配用户名提示、且你已确认明文风险，才会自动发送密码。“记住密码”只存到系统凭据库，不参与同步；密码留空则手动输入。**Telnet 不加密**，请只在可信网络中使用，并避免复用 SSH 密码。Telnet 直连，不支持代理或 SSH 管理功能。

### 串口连接

在连接编辑器中选择 **串口**。可以选择或刷新已检测到的串口，也可以手动输入本机设备名，例如 `COM4`、`/dev/ttyUSB0` 或 `/dev/cu.usbserial-…`。Windows、Linux、macOS 均以当前账户权限直接打开设备，不会自动提权。

可选择常见波特率或输入自定义值，并设置数据位、校验位、停止位和流控（无、RTS/CTS 或 XON/XOFF）。默认是 9600 波特、8 数据位、无校验、1 停止位、无流控。发送的行结束符可选 CR、LF 或 CRLF。本地回显默认关闭，在设备上输入密码时请保持关闭。“终端”页可设置字符编码和退格键、删除键的行为。设备拔出后，重新接入并选择 **重新连接**。串口不支持 SSH 管理功能。

### 终端

- 终端类型：发给服务器的 `TERM`，默认 `xterm-256color`。
- 退格键发送、删除键发送、字符编码：每一项的第一个选择是“默认：…”，跟随 [选项的“终端”页](#terminal-defaults)；也可以给这个主机单独选。可选的值和那一页一样。

在 `hosts.json` 里是 `backspace`（`del`、`ctrl-h`）、`delete`（`vt220`、`del`、`ctrl-h`）和 `encoding`（名字见[终端](#terminal-defaults)），没有就是“默认”。以前版本保存的主机没有 `backspace`，所以跟随全局设置，全局默认还是 `^?`，行为不变。

### 代理和跳板机

类型选“不使用”（直接连接）、“代理库”、SOCKS5、HTTP、HTTPS、SOCKS4 / 4a 或“跳板机”。

- “代理库”选用代理管理器里保存的代理。主机保存一份完整副本：在代理库中修改，所有使用它的主机一起生效；不支持代理库的旧版本用这份副本连接。“测试”显示它上次的测试结果；“新建代理”新建后直接选中。在本页手动填写的代理可以用“存入代理库…”保存到代理库。
- HTTPS 是经 TLS 加密连接的 HTTP 代理，会按代理的域名校验证书。SOCKS4 只有用户 ID、没有密码，域名按 SOCKS4a 交给代理解析，仅支持 IPv4。

- SOCKS5 和 HTTP（`CONNECT`）填代理的主机、端口（默认 1080 / 8080），代理需要认证时填用户名和密码（HTTP 是 Basic 认证）。SOCKS5 由代理解析主机名，所以主机可以填只有代理那边认识的名字。
- “跳板机”从已保存的其他连接里选一个（不能选自己），相当于 `ssh -J`：先登录跳板机，再由跳板机的 SSH 服务器转发到这台主机（跳板机要允许 TCP 转发）。跳板机自己也可以设代理或跳板机，按顺序一跳一跳连过去。绕回来形成循环时，编辑器和连接时都会提示 “跳板机形成了循环：a → b → a”。
- 每一跳都和直接连接它一样：第一次连接时确认它的主机指纹，用它自己的登录方式和密码。连接时，还不知道的密码按顺序一个一个问：先问主机自己的，再问它的代理的，再问各个跳板机的。标题写“输入跳板机密码”或“输入代理密码”，下面写是哪个主机、为了连接谁。主机改成走跳板机后重新连接，也会先问新跳板机的密码。
- 代理密码和主机密码一样存在系统的凭据存储里（跟着“SSH 连接”页的“记住密码”），不写进 `hosts.json`。
- 出错时说明是哪一跳：“代理 1.2.3.4:1080：连接被拒绝：端口没有开放代理服务” “跳板机 web-1：认证失败：…”“跳板机 web-1：无法连接到 10.0.0.5:22：…”。
- 关闭或断开会话时，跳板机的连接一起关闭。

#### 代理管理器

代理管理器（连接管理器工具栏的“代理管理”、“代理”页的“管理代理…”，或选项里的“代理管理”页，显示的是同一个代理库）按名称保存代理：SOCKS5、HTTP、HTTPS 和 SOCKS4，可带用户名和密码。表格列出每个代理的地址、使用它的主机数和上次的测试结果；“新建代理”“编辑”“复制”“删除”管理代理库，搜索框按名称、地址、用户名或备注查找。修改代理会同步更新使用它的主机；删除代理时，这些主机保留各自的副本，照常连接。主机的副本在别处被单独修改过（比如在不支持代理库的旧版本里），就保留为它自己的代理。

“测试”（每一行、编辑表单里，或“全部测试”）会经过代理访问 ip-api.com（使用应用的界面语言），不行再依次换 ip.sb、Cloudflare，显示代理建立连接的耗时（300 毫秒内绿色、1 秒内橙色、更慢红色）、外网看到的出口 IP 和它的归属地（国家、地区、城市、运营商）。失败时说明原因：连接被拒绝、超时、密码错误，或代理拒绝连接目标。

代理库和它的密码随主机一起同步（见[同步](#同步)）。不支持代理库的旧版本照常同步，不会改动代理库。

### 隧道

连接编辑器列出隧道的名称、类型、监听地址、目标或出口、限制，以及是否随会话启动。双击一行或用右键菜单编辑，保存后在下次连接时生效。

| 类型 | 监听位置 | 出口或目标 |
|---|---|---|
| 本地转发（`-L`） | 本机 | 由 SSH 服务器连接主机和端口，或连接 `/var/run/docker.sock` 等 Unix 绝对路径。 |
| 远程转发（`-R`） | SSH 服务器 | 由本机连接固定的主机和端口。 |
| 动态转发（`-D`） | 本机 | 通过 SSH 服务器处理 SOCKS5 CONNECT，不支持 UDP 和 BIND。 |
| HTTP 正向代理 | 本机 | 由 SSH 服务器处理普通 HTTP 请求和 CONNECT。 |
| SOCKS5 反向代理 | SSH 服务器 | 由本机处理 SOCKS5 CONNECT。 |
| HTTP 反向代理 | SSH 服务器 | 由本机处理普通 HTTP 请求和 CONNECT。 |

监听端口留空或填 `0`，启动时分配空闲端口；固定端口会检查同一端的监听冲突，包括通配地址。远程隧道的监听地址只能是 IP 地址或 `localhost`。默认只监听监听端机器的 `127.0.0.1`。允许其他计算机访问时，必须明确确认开放范围。若要从公网访问服务器端的监听端口，还要检查 SSH 服务的 `GatewayPorts` 和防火墙策略；SSH 返回端口不代表公网已可达。

本地 SOCKS5 和 HTTP 代理可以在同一端口同时提供两种协议。填写用户名和密码后，客户端须通过 SOCKS5 用户名密码认证或 HTTP Basic 代理认证。代理客户端与监听端之间的认证本身不加密，应使用回环地址或可信网络。不要把无认证的代理或 Docker 套接字开放给不可信网络。远程隧道可以由本机直接出站，也可以使用本机可达的 SOCKS5 或 HTTP CONNECT 上游，并为上游单独设置认证。

**高级**设置支持 IPv4、IPv6 地址或 CIDR 网段白名单、并发连接数、整个隧道的单向限速（KiB/秒），以及每条连接的空闲超时。数字留空或填 `0` 表示不限制。远程隧道的白名单使用 SSH 服务器报告的发起方地址，不读取 HTTP 请求头。关闭**随会话启动**后，仍可在隧道页手动启动。

### 隧道场景

在连接编辑器打开 **隧道 → 从场景添加…**。命令面板也能为单个 SSH 连接打开场景。选好用途，核对或修改地址和端口，再添加到连接草稿，保存连接后生效。建议的本地端口会避开应用已有隧道和本机监听端口，启动时仍会检查端口是否可用；建议的远程端口不会预先探测服务器。

- **服务器服务与内网**：访问 MySQL、PostgreSQL、Redis、MongoDB、Elasticsearch、管理面板，或内网另一台机器的 SSH、远程桌面。核对页会显示客户端应连接的地址。Docker 和 MySQL 场景可以连接远程 Unix 套接字；访问 Docker 套接字可能获得等同于 root 的权限。
- **正向与反向代理**：在本机提供 SOCKS5、HTTP 或混合代理，也可用反向代理让服务器借用本机网络。向导会提示常见的本机代理端口，但端口正在监听不代表协议可用。可以复制终端环境变量，以及 HTTP 代理的 APT 和 Docker 配置示例。只有环境变量命令可在确认后粘贴到已连接的终端，按回车才执行；向导不会更改服务器文件。
- **内网穿透与局域网共享**：通过 SSH 服务器发布本机服务，或按白名单向局域网共享监听端口。非回环地址需要确认谁能连接。共享代理前请开启认证；对外发布前，请用公网访问助手检查 GatewayPorts 和防火墙。场景本身不修改服务器配置。

**从 ssh 命令导入…** 可预览 `-L`、`-R`、`-D` 或对应的 OpenSSH 配置指令，不执行命令。SSH 配置文件导入器也会导入转发；其中的非回环监听默认禁用，核对访问范围后再启用。可从场景窗口复制为 SSH 命令或配置指令。无法用 OpenSSH 安全还原的隧道（如 HTTP 代理、启用认证的代理、带白名单或限额的隧道）只输出注释，不生成生效的转发指令。`ExitOnForwardFailure` 可识别，但不改变应用逐条启动隧道的行为。

### 系统代理

在本机回环监听且未启用代理认证或白名单的 SOCKS5、HTTP 或混合隧道上，可启用 **运行时用作系统代理**。PAC 留空时使用手动代理；填写 `all` 则通过 PAC 全局代理。也可输入精确域名、`*.example.org` 或 `10.0.0.0/8` 等网段，用逗号分隔。未匹配流量直连。IPv6 网段需要客户端支持 PAC 的 `isInNetEx`；部分应用不遵循系统设置。

支持 Windows 当前用户的 Internet 设置、macOS 已启用的网络服务，以及 Linux 的 GNOME 桌面。后生效的隧道替换前一个系统代理；生效隧道停止、应用退出，或意外退出后再次启动时，恢复原设置。也可在命令面板选择 **恢复系统代理**，不影响正在运行的隧道。

### 公网访问和局域网共享

在连接编辑器或 **隧道** 页右键单击远程隧道，选择 **公网访问…**；若仅监听
回环地址，则选择 **设为公网访问…**。请明确选择服务器监听地址。监听所有
接口时，任何能访问服务器的设备都可能连到该端口。不要把未认证的代理暴露到
公网；请启用认证并限制访问来源。

- **运行检查**会查看 `GatewayPorts`、可用的中继工具以及服务器防火墙。
  将 `GatewayPorts` 改为 `clientspecified` 需要确认和提权。应用会备份配置，
  校验后重载 sshd，失败时恢复原设置。自定义 `Match` 或 `Include` 规则需要
  手动检查。配置生效后要重新连接 SSH，仅在旧连接上重启隧道不够。
- **服务器中继**在服务器回环地址上建立 SSH 远程转发，再通过单独的 SSH
  执行通道运行 `socat`、`ncat` 或 Python 3.8 以上版本。服务器需要支持
  `setsid`，使用固定的对外端口，并且遵守回环地址绑定。中继会隐藏原始客户端
  IP，因此不支持隧道的来源白名单。小于 1024 的服务器端口通过提权界面授权。
  启用中继会关闭自动启动和后台启动。请从助手手动启动；停止隧道或断开 SSH
  时，中继也会停止。
- 助手可以在已启用的 UFW 或可明确确定区域的 firewalld 中放行 TCP 端口。
  应用在本机记录添加过的规则。请在 **已添加的规则…** 中移除不再需要的规则，
  包括对应隧道已经删除的规则。云安全组需要另行检查，建议只放行预期来源。
- 可以从本机测试 TCP 或发送 HTTP `GET /`。收到 HTTP 响应（即使是错误码）
  仅代表这个地址能从本机访问。可以复制公网地址或在浏览器中打开；要确认
  其他网络也能访问，请从相应网络另行测试。

本地隧道绑定非回环地址后，可右键选择 **共享到局域网…**，复制匹配的活动网卡
地址，并参考显示的子网设置来源白名单。请只在可信局域网共享，代理应开启认证。
Windows 可检查是否存在启用的应用专用入站规则，复制 `netsh` 命令，或通过 UAC
请求添加规则。检查仅供参考，网络配置文件、规则范围和本地化命令输出都可能
导致无法判断。新规则适用于所有程序和网络配置文件，停止隧道后仍保留；不再
使用时，请在 Windows Defender 防火墙中移除或缩小规则范围。

### 按键和其他行为

- 回车等于“确定”（备注里回车是换行），Esc 等于“取消”。
- 同时只开一个编辑器。已经开着时再点新建连接或编辑，只会把开着的那个提到前面，里面没保存的内容不会丢。
- 修改已经打开会话的主机，下次连接时生效。
- **转发 SSH 代理**默认关闭。启用后，每个终端 shell 都会请求转发选项中配置的本地代理，与主机的登录方式无关。终端打开期间，能访问转发套接字的远端用户可请求签名，请只在信任的服务器上启用。
- **X11 转发**默认关闭。非信任模式通过本地 X 服务器的 SECURITY 扩展获取受限 cookie，不会自动降级为信任模式。信任模式下远程 X 客户端可操作本地窗口和读取输入，请只在信任的主机上启用。本地显示地址默认使用 `$DISPLAY`；Windows 未设置时使用 `localhost:0`，可在 **选项 → SSH 密钥**修改。请先启动本地 X 服务器（如 XQuartz、VcXsrv 或 Xming）。如果连不上本地显示、认证失败或服务器拒绝转发，终端会提示原因，shell 仍然打开。
- 编辑期间主机在连接管理器里被删除了，“确定”只提示“此连接已被删除”，不会把它存回去。

## 服务器监控和系统信息

左上（或终端右边那一栏的上部，见[窗口布局](#窗口布局)）显示当前会话的服务器：IP、运行时间、负载、CPU、内存和交换、内存占用前几的进程、网速和延迟曲线、磁盘。每 2 秒通过 SSH 读取一次 `/proc`，所以只支持 Linux 服务器。一次读取超过 10 秒（比如 `df` 卡在失效的网络挂载上）就放弃，下一次照常开始。未连接时显示 FinalShell 那样的空白占位（“-”、0%）。点进程列表打开[进程页](#进程页)。

在监控上任意位置右键，可以把它移到另一边（“移到右侧”或“移到左侧”），或选择显示哪些部分：“运行时间和负载”“CPU、内存、交换”“进程”“网络”“延迟”“磁盘”各有一个勾选项。IP 那一行和“系统信息”按钮总是显示。这个选择对所有主机都一样，空白占位也隐藏同样的部分。全部隐藏时，面板显示 IP 那一行和“右键选择显示哪些内容”。隐藏的部分仍在读取数据，所以重新显示时曲线的历史马上就有。网速曲线上方的网卡名仍然是它自己的菜单（见下文）。选择保存在 `settings.json` 的 `monitorHidden` 里，只在这台电脑上。

网速曲线默认显示流量最大的网卡：服务器开机以来字节数最多的那个，从不选 `lo`。曲线右上角的网卡名点开是一个菜单：“自动（流量最大）”和 `/proc/net/dev` 里的每个网卡及其当前网速，先是其他网卡，然后是 Docker 的 `veth*`，最后是 `lo`。选一个网卡就勾上或取消勾选，勾了几个时曲线显示它们的合计，标签写成“eth0 + wg0”。每个网卡有自己的历史，所以一选就能看到最近两分钟；后来才出现的网卡（比如 VPN）下一次读取时就进菜单。选择按主机保存（`hosts.json` 的 `monitorIfaces`，随主机同步）。选中的网卡服务器上已经没有时跳过它；选中的都没有了，曲线回到流量最大的网卡，标签写“eth0（自动）”，提示里列出缺的网卡。它们在菜单里仍然勾着，标着“不存在”，直到取消勾选。

IP 下方的“系统信息”按钮弹出主机名、系统（`/etc/os-release`）、内核、架构、CPU 型号和核数、内存、运行时间、IP 地址、硬盘，“复制”把这些复制成纯文本。每次打开时通过一个 exec 通道读取一次，用一段 POSIX sh 脚本，BusyBox 也能跑。缺 `lscpu`、`nproc`、`ip` 之类的工具时跳过或换用别的。

### 概览中的内存

**概览 › 内存**卡区分不含缓存的占用、缓冲与可回收缓存、空闲内存。可用内存是内核估计的无需使用交换区即可分配的内存；虚拟内存承诺量是独立的指标，不等于交换区占用。卡片还会显示交换区用量、换入和换出速率、交换倾向（内核提供时）。

**释放内存**在确认后清理内核缓存，菜单还会在内核支持时提供内存碎片整理。两项操作都以 root 权限执行，可能短时增加负载。清缓存不释放运行中应用占用的内存；操作结果对比前后观测值，不保证释放多少。交换区只展示，不做修改。

### 以 root 权限执行

SSH 已以 root 登录时，程序直接执行；否则先试非交互式 `sudo`。如果 `sudo` 需要密码，程序会尝试一次内存中已有的 SSH 登录密码，再尝试已保存的提权密码或弹窗询问 `sudo` 密码。当前账户无法使用 `sudo` 时，可以在弹窗中改用 root 密码（`su`）。

成功的提权方式会沿用到连接断开。密码输入为遮蔽显示；勾选 **记住（系统凭据存储）** 后，只有通过认证才会保存。输错可以重试，每次操作最多提交三次。无法提权或取消时，程序会显示管理员可复制的授权命令。系统本身的限制（例如 root 账户已锁定、内存控制项只读）仍然有效。

Docker 和 Podman 会先尝试用当前 SSH 用户访问引擎，再尝试免密 `sudo`。仍需要 root 权限时，在 Docker 页或概览卡片中点击**使用 root / sudo**。刷新不会弹出密码框，但可复用当前连接已成功授权的方式。取消密码输入后仍可重试。提权被拒绝或提权后仍无权访问引擎时，应用会显示管理员可执行的 sudo 授权命令。Docker 还会提示 `usermod -aG docker <user>`；更新组成员后需重新连接。`docker` 组拥有等同于 root 的权限。

### Docker 页 › 容器

支持筛选和排序、按编排项目分组，以及显示或隐藏已停止的容器。可通过复选框、按住 Ctrl／Command 点击或按住 Shift 点击选择多行，然后在选中项菜单中批量操作或查看实时统计。双击容器查看详情，右键菜单还提供日志、终端、已发布端口等入口。“在桌面浏览器中打开（经服务器内部）”用桌面浏览器打开运行中的容器，浏览器的连接从服务器发出：先列出服务器本机上的已发布端口（或其绑定地址），再列出容器在各网络中的 IP 加容器端口，未发布的端口也能打开。删除等破坏性操作会先列明受影响的对象。

以 root 权限访问引擎后，Docker 各页及日志均以该账户执行。在交互式容器终端中，应用只发送命令，不会代填已保存的密码；如果 `sudo` 或 `su` 要求密码，请在终端中输入。当前用户可直接访问或可免密使用 `sudo` 时，不会提示输入密码。

**新建容器**可配置镜像、命令、端口、挂载、环境变量、网络和资源限制。运行命令预览会遮盖环境变量和日志选项的值。**复制容器配置**不会复用发布端口或静态 IP，但挂载可能仍会共享数据。**编辑容器**会替换独立的 Docker 容器，保留表单未展示的设置，并在替换失败时尝试恢复原容器。该功能需要 Docker 的 Unix 套接字和 `curl`；编排服务请修改其 Compose 文件。替换不会保留容器可写层的改动。

**实时统计**打开时每两秒采集 CPU、内存、网络速率、磁盘 I/O 和进程数。**容器文件**要求容器正在运行、未暂停且有相应的命令行工具，可浏览、重命名、新建目录和删除。文件或文件夹可在容器与 SSH 服务器的绝对路径之间复制；复制前会检查目标是否已存在。服务器与本机之间请使用 SSH 文件面板传输。行菜单还可将容器提交为镜像，或将文件系统导出为服务器上的 tar 文件，两者都不包含挂载的存储卷，但可能包含敏感数据。

目录列表也支持使用 BusyBox 的 Alpine 容器。如果列表无法无歧义地表示文件名，应用会拒绝显示，而不是展示失真的名称。重命名遇到同名条目会报告冲突，不会覆盖它。

### Docker 页 › 镜像

镜像页列出 Docker 或 Podman 上的本地镜像，包括无标签镜像。有标签的镜像每个标签占一行。可点击任意列标题排序，按引用、ID、平台或容器名称搜索，也可仅显示悬空或未使用的镜像。悬停在创建时间上可查看准确日期，悬停在引用数量上可查看容器名称。总大小按镜像去重，不重复计算标签；不同镜像可能共享镜像层。按住 Ctrl/Cmd 或 Shift 选择多行后，可批量移除。

通过行菜单或已选镜像的操作按钮，可查看详情（包括可复制的字段及原始 JSON）、镜像层历史、添加标签、推送、移除，或在服务器上保存 TAR 或 gzip 归档。保存不会覆盖已有路径，需要服务器支持 `mktemp` 和 `ln -T`，压缩时还需要 `gzip`。「运行容器」会转到容器页。被容器引用的镜像无法常规移除；在 Docker 上，强制移除须阅读单独的风险提示并勾选确认。Podman 的强制移除可能删除依赖容器，因此已禁用。移除操作不会顺带清理父镜像；如需清理，请使用「清理」。

拉取可指定平台，也可选择拉取所有标签。Docker Hub 公共镜像建议默认关闭，使用 Podman 时不提供。构建使用服务器上的上下文与 Dockerfile，支持多个标签、构建参数、目标阶段、平台、跳过缓存和重新拉取基础镜像。请只构建可信的 Dockerfile，不要把凭据写进构建参数。加载会还原镜像归档，导入则从根文件系统归档创建镜像。可输入服务器路径，也可经 SFTP 将本地 TAR/TAR.GZ 上传到私有临时目录；连接可用时，操作结束后会清理该目录。

耗时操作会实时显示引擎输出并可停止，停止不会回滚已完成的变更。推送被仓库拒绝时，请检查权限并在「系统」中登录。清理默认只处理悬空镜像，确认前会展示清单和大小估算。若选择包括所有未使用镜像，也可能删除带标签的镜像。客户端会在清理前复核候选镜像和容器清单；复核与清理并非原子操作，实际范围以执行时引擎判断为准，输出会报告实际释放空间。

### Docker 页 › 编排

在 Docker 页选择**编排**，即可查看项目和服务容器。项目列表显示运行中的容器数量；服务表支持筛选、排序及多选服务后批量操作。应用优先使用 Docker Compose v2；无法直接读取列表时，包括使用 Docker Compose v1 或 `podman-compose` 时，会从容器标签读取。不支持的选项会说明禁用原因。

通过项目或服务菜单，可部署、启动、停止、重启、拉取镜像，或拉取后重建。部署前可校验已保存的配置，也可查看或跟随项目及服务日志。操作会实时显示输出；取消会关闭对应的 SSH 命令通道，但服务器上已经开始的操作可能继续。修改后会刷新编排列表和概览。

编排文件和 `.env` 可在远程 SFTP 编辑器中打开。保存后，回到项目即可校验或部署。**新建项目**写入 `compose.yaml` 和可选的 `.env`，不会覆盖现有文件；目录非空时会先询问，SFTP 无法写入时通过共享机制提权，校验通过后可立即部署。应用在本地记录自己创建的项目，尚未部署的项目也会留在列表中。

**下线**会移除项目容器和网络，除非明确勾选，否则保留存储卷和镜像。确认时会尽可能列出带有项目标签的存储卷。**删除项目**还可删除由应用新建的目录，必须输入项目名称确认；该目录中的所有内容都会丢失，包括存放在其中的绑定挂载数据。

### Docker 页 › 网络、存储卷和系统

- **网络：** 支持筛选、排序和查看详情，包括子网、地址范围及已接入的容器。创建时可设置 IPv4/IPv6、驱动选项和标签。通过行菜单接入或断开容器、复制网络信息，或删除选中的网络。此页清理只删除确认列表中未使用的本地网络；内置网络、入口网络和仍有容器接入的网络受保护。
- **存储卷：** 支持仅显示未使用的卷，查看标签、驱动选项、引用容器，或按需测算大小。引擎位于当前 SSH 主机且用户可通过 SFTP 读取挂载点时，可在「文件」页浏览。删除或清理会永久删除数据；删除前会复核卷的身份。在 Docker 23 或更高版本（API 1.42 或更高版本）中，此页默认只清理列表中未使用的匿名卷；若要包含具名卷，须明确勾选并确认。
- **系统：** 查看引擎信息和磁盘占用，实时查看和筛选近期事件，或按类别选择清理并查看估算。暂停事件或离开事件页会停止远端事件流。系统会依次执行确认的步骤并实时显示输出。网络和存储卷只删除所列对象；容器、镜像和构建缓存按引擎执行时判定的范围清理。停止等待不会撤销已执行的更改。
- **镜像仓库和守护进程：** 以 root 权限访问引擎时，仓库管理使用 root 账户的 Docker 配置，否则使用 SSH 用户的配置。界面只显示仓库地址和凭据助手名称，不显示凭据。登录须配置凭据助手，密码只通过标准输入传输。守护进程编辑器仅用于可识别且使用默认套接字和配置路径的 Linux Docker 系统服务；即使 SSH 用户已可访问套接字，编辑器也通过共享机制提权。保存前需要 Python 3 和 `dockerd --validate` 按运行中服务的启动参数校验配置；Docker 20.10 可以读取配置，但不能保存。保存时会将现有文件备份为 `daemon.json.bak-<yyyymmddHHMMSS>`（世界协调时）。重启须另行确认。Podman 不提供守护进程编辑、镜像仓库管理或存储卷清理等 Docker 专属操作。

## 终端

右上是终端。会话断开后保留最后的画面，顶部出现“重新连接”。

### 查找

Ctrl+Shift+F（macOS 是 Cmd+F）在终端右上角打开查找栏（MyGo 的 `ui.FindBar`）。

- 边输入边用插件的 `Search` 搜屏幕和滚动历史，高亮所有匹配，显示“第几项，共几项”。
- 回车到下一个（往上，更早的输出），Shift+回车到上一个。F3 / Shift+F3（macOS 是 Cmd+G / Shift+Cmd+G）也行。
- Esc 或“完成”关闭查找栏，结束搜索，键盘回到终端。
- 再按一次快捷键时全选查找框里的文字。
- 每个会话的查找栏分开，[分屏](#分屏)的会话里每个分屏的也分开；快捷键打开获得焦点的分屏的查找栏。
- 不区分 ASCII 字母大小写（插件就是这样）。

### 全屏

Ctrl+Shift+Enter（macOS 是 Cmd+Enter）隐藏左边栏和下面的文件面板，只留终端，窗口也进入系统的全屏。再按一次退出全屏。

- Esc 只在没有 shell 接收它时退出全屏（新标签页、断开的会话），连接着的终端里 Esc 照常发给 shell（vi 要用）。
- 窗口本来就是系统全屏的，退出程序的全屏时保持系统全屏。
- 用系统的办法（macOS 的绿色按钮）退出系统全屏，也一起退出程序的全屏。
- [面板行](#底部面板单独成标签)没有终端，在那里按这个键不起作用。全屏时切到面板行，只显示它的面板。
- [分屏](#分屏)的会话全屏时显示它所有的分屏。

### 分屏

会话的终端可以分成几个分屏，像 Ghostty、iTerm、Windows Terminal 的标签那样，把部署、日志和 `htop` 并排放在同一台服务器上。每个分屏是会话的 SSH 连接上的一个独立 shell（这个连接上新开的一个通道），不用重新登录。[本地终端](#本地终端)的分屏再运行一次本地终端程序。

- **分屏**：向右分屏（macOS 是 Cmd+D，其他系统是 Alt+Shift+=）在获得焦点的分屏右边开一个分屏，向下分屏（Cmd+Shift+D，Alt+Shift+-）在它下面开一个，新分屏获得焦点。新 shell 的终端类型、按键和编码和第一个一样。分屏可以接着分，横竖都行。会话行的右键菜单和[命令输入框](#命令输入框)最右边的分屏按钮里有同样的项，还有“放大此分屏”“平均分配”“移动分屏”“关闭此分屏”，作用于获得焦点的分屏；只有一个分屏时，除了两个分屏项都是灰的。从按钮选一项后，键盘留在获得焦点的分屏的终端里。在终端里右键打开的是终端自己的菜单（复制、粘贴、全选、清屏）：这个菜单由 MyGo 的终端生成，应用加不了项。
- **焦点**：获得焦点的分屏有蓝色边框，其他分屏稍微变暗。点一下分屏就让它获得焦点（这次点击也会交给它的终端，所以选择文字、用鼠标的程序照常可用）。Cmd+Option+方向键（其他系统是 Alt+方向键）把焦点移到那一边的分屏。
- **调整大小**：分屏之间的分隔条可以拖动，每个分屏最窄 120 DIP、最矮 60 DIP；双击分隔条两边平分。行菜单里的“平均分配”让所有分屏一样大。
- **移动**：有两个以上分屏时，鼠标停在分屏顶部中间会出现一个小把手。把它拖到另一个分屏上：那个分屏显示左、右、上、下四块落点，离鼠标最近的一边变亮，松手后就在那一边分出来放下拖动的分屏，它原来的位置让给旁边的分屏。shell、输出和文件面板跟随的目录都跟着分屏走，只是换了位置。拖动时一张分屏的小卡片（编号、标题和最后一行）跟着鼠标；按 Esc 取消，放回自己身上，或者放到相邻分屏它本来就在的那一边，什么都不变。只有把手接收按下：在分屏别的地方拖动是选择文字，用鼠标的程序在把手旁边照常收到点击。放大分屏或者打开查找栏时没有把手。行菜单里的“移动分屏”可以把获得焦点的分屏和左、右、上、下的分屏交换；快捷键页面也有这四个操作，默认没有快捷键。
- **放大**：“放大此分屏”（Cmd+Shift+Enter，其他系统是 Ctrl+Shift+X）让获得焦点的分屏占满终端区域；再按一次，或者移动焦点，显示全部分屏。
- **关闭**：会话有多个分屏时，关闭标签（Cmd+W，Ctrl+Shift+W）关闭获得焦点的分屏，只剩一个时关闭会话，和 Ghostty 一样。shell 退出（`exit`、Ctrl+D）的分屏会关闭，旁边的分屏占用它的位置并获得焦点。
- **连接断开**：连接断开时所有分屏都结束，会话和只有一个终端时一样显示“连接已断开”。重新连接在每个分屏里重新打开 shell，布局不变。
- **服务器拒绝**：服务器限制一个连接上的会话数（OpenSSH 的 `MaxSessions`，默认 10；服务器监控和 SFTP 各占一个）。被拒绝的分屏不会加上，并弹出提示说明原因。
- **跟随获得焦点的分屏的**：命令输入框（占位文字是“发到获得焦点的分屏”）、[命令页](#命令页)和[命令编辑器](#命令编辑器)发给获得焦点的分屏的 shell；命令页的“全部会话”给每个会话发一次，发给它获得焦点的分屏。文件面板跟随获得焦点的分屏的目录，焦点移动时也转过去（见[跟随终端目录](#跟随终端目录)）；会话行显示获得焦点的分屏里运行的编程助手；查找栏作用于获得焦点的分屏。
- **会话行**在名字后面显示分屏的会话有几个分屏（▦ 3）。
- 分屏不保存：会话打开时只有一个分屏。

### 命令输入框

终端下面是一行命令输入框，和 FinalShell 的命令输入框一样：一个终端图标、没有占位文字的输入框，以及最右边的“历史”按钮和分屏按钮。默认打开；“选项 › 终端 › 命令输入框”可以关掉它，或者关掉其中某个弹出列表，那里也列出了它的按键（见[终端 › 命令输入框](#终端--命令输入框)）。

- 回车把输入框里的内容加一个回车发给 shell，和在终端里输入一样（经过会话的编码转换），然后清空输入框。终端的按键不受影响：只有在输入框里打字时，键盘才在输入框。
- Tab 补全光标处的词：
  - 像路径的词（含 `/`，或以 `~`、`.` 开头）打开路径选择，分多列列出服务器上的文件夹：先文件夹（以 `/` 结尾），再文件，图标和文件面板的图标主题一样，隐藏文件排在最后。输入可以筛选（不区分大小写），筛选为空时按退格键回到上一级，方向键移动，回车或 Tab 插入。插入文件夹后接着列出它里面的内容；插入文件后加一个空格。名字里的空格等会被 shell 另作解释的字符用 `\` 转义。最多列出 2000 项，后面显示“还有 N 项”。含有控制字符（换行、转义序列）的名字以转义形式变暗显示，不能插入：发送出去的话，换行后面的内容会作为另一条命令执行。含有控制字符的命令名和服务器历史里的行不列出。
  - 否则，第一个词打开命令补全：服务器 PATH 里以它开头的命令。每次连接用一个 exec 通道读取一次：有 bash 时用 `compgen -c`（包括内置命令），没有 bash 时列出 `$PATH` 里的每个文件夹。关闭了“启用 exec 通道”的主机改为通过 SFTP 列出 `/usr/local/sbin`、`/usr/local/bin`、`/usr/sbin`、`/usr/bin`、`/sbin` 和 `/bin`。
  - 其他词打开当前文件夹的路径选择。
- 相对路径从 shell 的工作目录算起：shell 报告的（OSC 7），或应用从服务器读到的（见[跟随终端目录](#跟随终端目录)）；都没有时从文件面板的文件夹算起。`~` 是主目录。文件夹通过会话的 SFTP 读取，所以没有 SFTP 的服务器会在弹出列表里显示错误，发送和历史照常可用。
- ↑、Alt+H（macOS 上为 Cmd+Shift+H）或“历史”按钮打开历史列表（按钮让键盘留在输入框，列表打开时再点就关闭；关掉历史列表后按钮隐藏）：以前发送过的、以已输入内容开头的命令，最新的在最下面，紧挨输入框。↑ ↓ 移动；← → 高亮选中命令里的一个字段（词），这样可以从 `yum -y install epel-release` 里单独取出 `epel-release`。回车把这个字段插入到光标处的词的位置；没有高亮字段时，把整条命令放进输入框。“清空列表”删除这台主机的历史。
- 历史由程序按主机保存：从输入框发送的每条命令，每条只留一次，最新的在最后，条数不限（文件超过 10 MB 时从最旧的删起，见 [configuration.md](configuration.md#命令历史)）。后面接着服务器上 `~/.bash_history` 和 `~/.zsh_history` 里的命令，每次连接通过 SFTP 读取一次，所以在终端里输入的命令也会出现（bash 在 shell 退出时才写历史文件）。
- 回车只发给这个会话（分屏时发给获得焦点的分屏），不管命令页的“发送到”设成什么，也从不询问。要把命令发给多个会话，用[命令页](#命令页)或它的[命令编辑器](#命令编辑器)。
- “历史”右边的分屏按钮（左右两格的图标）在输入框上方打开分屏菜单：向右分屏、向下分屏、放大此分屏、平均分配、移动分屏、关闭此分屏，带快捷键，和会话行右键菜单里的是同一组（见[分屏](#分屏)）。它们作用于获得焦点的分屏。会话正在连接或已断开时按钮是灰的。
- Esc 关闭弹出列表，再按一次 Esc 键盘回到终端。“聚焦命令输入框”（Ctrl+Shift+L，macOS 上是 Cmd+Shift+L）在输入框和终端之间切换键盘。
- 新标签页没有输入框。正在连接或已断开的会话里，输入框显示为禁用。

常用的命令可以存成[命令页](#命令页)里的按钮。

### ZMODEM（rz/sz）

在 SSH 终端运行 `rz`，选择一个或多个本地文件并确认上传。请直接使用 `rz`，不要加覆盖参数。客户端会要求保留已有文件，但实际写入策略由远端接收程序决定。运行 `sz -- 'file'` 后，选择本地目标并逐个确认待接收的文件；选择器默认定位到已配置的下载目录。传输不需要额外的 SSH 通道、SFTP 或提权。

传输页显示当前文件、速度及取消按钮。下载校验通过后才会以原文件名保存；若同名则加上 ` (1)` 之类的序号。拒绝不安全的文件名，不支持目录或达到 4 GiB 的单个文件。传输过程中自动重传；取消或断开后需重新运行命令。本地终端不使用 ZMODEM。

### 关键词高亮

SSH 终端默认用红色标识常见错误、黄色标识警告、绿色标识成功状态、青色标识 IP 地址，HTTP(S) 链接使用带下划线的蓝色。“选项 › 终端 › 关键词高亮”可关闭高亮，或编辑和预览规则。规则支持全词或正则匹配、区分大小写、颜色和样式，可对所有主机或某个已保存的主机生效。只改变新增的输出，不处理转义序列、使用备用屏幕的全屏程序或 ZMODEM 传输数据。

### 会话录制

用 SSH 窗格中的录制按钮，或会话菜单中的录制命令，开始或停止当前窗格的录制。正在录制的窗格显示红点。在“选项 › 终端 › 会话录制”中可选择保存目录、同时保存去掉 ANSI 转义序列的 `.txt` 日志、调整单个文件的轮转上限，或开启新 SSH 窗格的自动录制。自动录制默认关闭。

录制使用 asciicast v2（`.cast`），可用外部播放器回放。不直接捕获键盘输入，但会保存回显的命令和其他可见输出；显示密码、私钥或机密内容前请先停止录制。可用“打开录制文件夹”查看文件。

### 外观：字体、配色、背景图片

选项的“终端 › 字体”“终端 › 配色”“终端 › 背景图片”三页管终端的外观。改了立刻应用到所有打开的终端（`SetFont`、`SetTheme`），新开的终端也用新设置；连接过程中改了，连上后也会补上。每页下面有“恢复默认”，上面有预览：示例提示符、彩色 `ls`、带连字的代码，用界面控件画，用的是同样的字体、配色和背景。

字体：

- 字体名称：输入时提示系统里已安装的等宽字体（来自 `ui.FontFamilies`）。可以写逗号隔开的多个，用第一个装了的。空着是默认的 JetBrains Mono, Cascadia Mono, Consolas, Menlo, DejaVu Sans Mono, monospace。
- 字号：6 到 48，默认 13.5。
- 行高：字体本身行高的 0.8 到 2 倍，默认 1。
- 粗细：细 300、常规 400、中等 500、半粗 600、粗 700。插件的粗体总是比它重 300、至少 700，没有单独的粗体粗细。
- 连字：默认开，关掉是 `-calt`、`-liga`。

改字体会结束终端里的 Ctrl+= 缩放；只改配色不会。

配色：

- Ghostty 自带的几百个主题（`terminal.GhosttyThemes()`），也包括 Ghostty 主题目录里用户自己的。
- 搜索框按名称过滤。每行带背景色和几种颜色的小样，预览下面是 16 种 ANSI 颜色。
- 默认 Tomorrow Night。主题文件不见了时用默认的。
- 应用的浅色和深色外观（选项 › 常规 › 外观）用同一个配色，所以只有一个选择，同时设给插件的 `Theme` 和 `DarkTheme`。

背景图片：

- “选择…”用系统的打开对话框选 PNG、JPEG、GIF、WebP 或 BMP 图片（文件 64 MB 以内，最多 1 亿像素）。先解码确认能显示，再复制一份到配置目录（`finallyshell/background-<时间>.<扩展名>`），所以原图移走、删掉都没关系。换图或 “移除”会删掉旧的副本。
- 填充方式：铺满（裁剪）、完整显示或平铺。不透明度：5% 到 100%，默认 30%。
- 不是图片、读不了的文件只显示错误，不复制，也不替换现在的图。
- 副本不见了（或 `settings.json` 里的名字不是副本）时，这一页显示“背景图片不见了：请重新选择，或者移除。”可以重新选择或移除。
- 图片的读取和解码都不在界面线程上。启动时不读；第一次要显示时在 goroutine 里读，读完再通过 `App.post` 显示，没读完时终端只显示配色的背景色。读的过程中换了或移除了图片，旧的结果直接丢掉。
- 超过 3840 像素（长边）的图片缩小后再保存在内存里（磁盘上的副本仍是原文件）。JPEG 按 EXIF 方向摆正。

怎样画：终端都用 `Transparent: true` 创建，应用自己在终端下面画背景：先是配色的背景色，再画图片，再盖一层 (1 − 不透明度) 的背景色，所以文字一直在配色背景上。程序自己设的背景色（OSC 11、单元格背景）照常画。

在 `settings.json` 里是 `termFontFamily`、`termFontSize`、`termLineHeight`、`termFontWeight`、`termNoLigatures`、`termTheme`、`termBackground`（副本的文件名）、`termBackgroundFit`（`contain` 或 `tile`；没有是铺满）、`termBackgroundOpacity`（百分比）。没有就是默认值。

## 文件面板

右下的“文件”页用 SFTP 浏览服务器：左边目录树，右边文件表格（可多选），路径栏可以直接输入路径。

### 跟随终端目录

shell 的工作目录变了，比如执行 `cd /var/log` 之后，文件面板也会跟着过去。面板工具栏里主目录按钮后面的开关按钮可以关闭或打开这个功能，对所有会话生效；重新打开时面板会立刻转到 shell 所在的文件夹。默认打开。

- 只有 shell 的目录变了，面板才会移动。用户在面板里浏览到的文件夹，执行 `ls` 这类命令后不会被拉回去，直到下一次 `cd`。
- shell 会报告目录（OSC 7：fish，以及配置过的 zsh、bash）时直接用它。否则在 Linux 服务器上，应用会在同一个连接上另开一个通道，从 `/proc` 读出 shell 终端前台程序的工作目录，读不到时用 shell 自己的。这需要该主机打开了服务器监控（用的是同样的 exec 通道），不需要 root，除了 shell 也不需要别的工具。
- 会话连上时读一次 shell 的起始目录，但不移动面板；之后在终端里按回车，或命令输入栏发送一行之后：约四分之一秒后读一次，一秒半后再读一次。没有输入时不再读。登录脚本里 `cd` 到别处的 shell，面板会留在主目录，直到下一次 `cd`。
- 跟随不了的情况：没有 `/proc` 且 shell 不报告 OSC 7 的服务器（如 macOS）、`sudo -i` 或 `su` 进入的 root shell（普通用户读不到 root 的进程）、tmux 或 screen 里的 shell。面板打不开的文件夹，比如 shell 通过 ssh 去了另一台主机上的路径，面板会留在原处。
- [分屏](#分屏)的会话，面板跟随获得焦点的分屏。每个分屏的 shell 分开读：服务器按连接上各个 shell 启动的先后区分它们，也就是分屏打开它们的顺序。有分屏正在打开或关闭时数目对不上，对上之前读不到。

### 文件图标主题

文件面板按文件名显示图标：`docker-compose.yml` 是 Docker 图标，`main.go` 是 Go 图标，`src/` 是 src 文件夹图标，展开的文件夹换成打开的样子。用的是 VS Code 的文件图标主题格式，所以 VS Code 的图标主题都能用。在选项的“文件管理 › 文件图标主题”页选择，上面有预览，选了立刻生效。

- 内置：Material Icon Theme（默认）、Seti（VS Code 自带的那个），以及“简洁”（只有文件和文件夹两个图标，就是以前的样子）。
- “从 VSIX 安装…”：选一个 `.vsix` 文件（VS Code 扩展包，比如从 [Open VSX](https://open-vsx.org) 下载的），确认它有能读的图标主题后原样复制到配置目录的 `icon-themes/<发布者>.<名称>.vsix`。同一个扩展的新版本替换旧的。装好后自动选中。最大 50 MB。列表里的删除按钮删掉这个副本。
- 自动列出 VS Code、VS Code Insiders、VSCodium、Cursor、Windsurf 里已经装了的图标主题（`~/.vscode/extensions` 等，Windows 上在 `%USERPROFILE%` 下），直接读，不复制。已卸载的（`.obsolete`）跳过，同一个扩展只列最新版本。“刷新”重新查找。
- 选中的主题后来不见了或读不出来时，面板显示 Material Icon Theme，并在选项页说明原因。

只读取主题的 JSON 和它引用的 SVG、PNG、字体，扩展里的代码不会运行。引用到扩展外面的路径直接忽略。用字体做图标的主题（Seti 用 WOFF，file-icons 用 WOFF2）先转成 TrueType 再注册给界面。按 VS Code 的规则匹配：先文件名，再扩展名（最长的优先，`a.test.ts` 先找 `test.ts`），再语言（文件名到语言的对应表来自 VS Code 自带的语言扩展），最后是默认的文件图标。和 VS Code 一样，只在应用是浅色时用主题的 `light` 部分；深色外观下用主题本来的图标。切换外观时图标立刻跟着换。

在 `settings.json` 里是 `fileIconTheme`：没有是 Material，`minimal` 是简洁，`bundled:seti` 是 Seti，其他是 `<发布者>.<名称>/<主题 ID>`。

内置的两个主题都是 MIT 协议，许可证在各自的 VSIX 里（`internal/fileicons/bundled/`）。更新它们和语言表：改 `internal/fileicons/internal/gen` 里的版本号，运行 `go generate ./internal/fileicons`（需要 git 和网络）。

### 软链接

文件表格里每个软链接的图标左下角有一个小箭头，名字后面用浅色字显示它指向哪里（`bin → usr/bin`）。和 `ls -l` 一样，这是链接里写的原样，相对或绝对路径，不解析。

- 指向文件夹的链接显示成文件夹，排在文件夹一组，双击进入。
- 指向文件的链接“类型”是“链接”，“大小”是它指向的文件的大小，“权限”是链接自己的。
- 目标不存在（或链接成环）的是失效的链接：名字是红色，“类型”是“失效的链接”，没有大小，双击不打开。目标没有权限查看的不算失效。
- 列目录时同时解析最多 16 个链接（每个要 `readlink` 和 `stat` 两次往返），所以链接多的目录（比如 `/usr/lib64`）不用一个一个等。
- 左边的目录树不显示箭头。

### 文件操作

在文件表格和目录树的右键菜单里可以重命名、删除、新建文件和文件夹：

- 文件表格的菜单有“新建文件夹”“新建文件”“重命名”（选中一项时）和“删除”（选中一项或多项时）。表格有焦点时，F2 重命名选中的项目，Delete（macOS 上也可以用 Cmd+Backspace）删除选中的项目。
- 目录树的菜单作用于右键点击的那个文件夹，不会打开它：打开、上传文件、上传文件夹（传到这个文件夹）、新建文件夹、新建文件、重命名、删除、刷新、复制路径。`/` 没有重命名和删除。

重命名、新建文件夹和新建文件会询问名称。重命名时和 Finder、资源管理器一样，默认选中扩展名之前的部分。名称为空、是 `.` 或 `..`、含有 `/` 的不能用，文件夹里已经有的名称也不能用：重命名不会覆盖别的文件，新建文件也不会清空已有的文件。服务器返回的错误（比如没有权限）显示在对话框里，对话框不关闭。

删除前总是先确认。文件夹连同其中的所有内容一起删除。不会跟随链接：删除指向文件夹的链接只删除链接本身，不动它指向的文件夹。一个文件夹里的文件同时最多删除 16 个，大文件夹不用每次等一个往返。删除还在进行时取消对话框会停止删除，已经删掉的不会恢复。

操作完成后重新列出文件夹，表格里选中重命名或新建的项目。当前文件夹（或它所在的文件夹）被重命名时，面板跟到新路径；被删除时，回到它所在的文件夹。

### 上传和下载

上传：把文件或文件夹从资源管理器 / Finder 拖到文件表格（传到当前目录）或目录树的某个文件夹上。也可以用工具栏的上传按钮或右键菜单选文件、选文件夹。

下载：选中文件或文件夹，点下载按钮。存到下载目录，默认是系统的“下载”文件夹（`~/Downloads`），可以在选项的“传输”页修改。右键菜单的“下载到…”自己选位置。“传输”页勾选“每次下载时询问保存位置”后，下载按钮每次都先用系统的选择文件夹对话框问保存位置。

### 打包传输

SFTP 每个文件都要来回好几次，传大量小文件的文件夹很慢。“打包下载”和“打包上传…”改用 tar 和 gzip 打包传输，和 FinalShell 的打包传输一样：

- “打包下载”在文件表格的右键菜单（选中文件夹或多个项目时有，单个文件没有）、目录树的右键菜单（`/` 以外的文件夹）和工具栏下载按钮的右键菜单里（右键点它；左键点击仍是下载）。服务器在这些项目所在的文件夹运行 `tar -czf -`，应用读取数据流，一个文件一个文件地解包到下载目录。
- “打包上传…”在文件表格和目录树的右键菜单，以及工具栏两个上传按钮的右键菜单里（右键点它们；左键点击仍是选文件或文件夹），选择文件夹。应用把它们打包成数据流，服务器在目标文件夹用 `tar -xzf -` 解包，文件夹不存在时先创建。文件归登录的用户所有，与本机上的所有者无关。

两个方向都是流式的，两边都不产生临时压缩包。每次打包传输是队列里的一个传输，和其他传输一样：“传输”页显示“打包下载”或“打包上传”、按文件字节数计的进度（传输开始后同时统计总大小），以及正在打包或解包的文件。取消会停止服务器上的 tar 并关闭它的通道，本机写了一半的文件会被删掉。开始前目标位置已有同名项目时询问一次，然后覆盖。文件夹（包括空文件夹）、软链接、权限和修改时间都保留；所有者、设备文件和套接字不保留。

服务器上没有 `tar` 或 tar 出错时，传输失败并显示它的输出，“改用 SFTP 重试”按普通方式重新传这些项目，每个一个传输。

想默认打包，就打开“打包传输”：文件面板工具栏里“跟随终端目录”右边的包裹按钮，或选项“传输”页的“打包上传和下载文件夹”，两者是同一个设置；桌面版的“文件”应用工具栏也有这个按钮。打开后，从系统文件管理器拖放进来的项目、上传和下载按钮、菜单里的“下载”和“下载到…”、粘贴文件，以及桌面版“文件”应用的上传和下载，都会把要传的内容作为一个打包传输压缩发送，单个文件也一样：文本和日志能小很多，已经压缩过的文件（zip、gz、图片、视频）几乎不变小。单独一个符号链接仍走 SFTP（SFTP 传的是它指向的文件）；禁用了 SSH 命令执行的连接也全部走 SFTP。桌面版一次下载来自多个文件夹的项目（比如搜索结果）时也走 SFTP。

下载的解包是安全的：绝对路径、含 `..` 或不在所选项目之下的名字会让传输停止；不会经过软链接写入（要放文件夹的位置是软链接时，像 tar 一样换成文件夹）；硬链接只能指向这次下载写出的文件；去掉 setuid、setgid 和 sticky 位。gzip 数据流会读到结尾，校验和或大小对不上时传输失败，并提示解包出的文件可能有误。在 Windows 上，Windows 不允许的名字（如 `a:b` 或 `CON`）会让传输失败并显示这个名字，不会被改名。

有些软链接不创建，其余内容照常下载：

- 指向下载目录以外的链接：看它的目标，以及全部解包后经过其他链接实际到达的位置（如 `b -> ..` 时的 `a -> b/../..`）。
- 在 Windows 上，Windows 不允许用户创建链接时的所有链接（开发者模式下或管理员可以创建）。

这时传输仍算完成，并显示一行提醒，如“2 个链接没有创建：它们指向文件夹以外”，鼠标悬停列出这些链接。这种情况不提供“改用 SFTP 重试”。

### 发送到另一台服务器

在文件面板选中文件或目录，点击**发送到另一台服务器…**，也可以把工具栏中的发送按钮拖到已连接的 SSH 会话上。已连接的服务器排在前面；选择尚未连接的服务器时，应用按正常流程获取凭据并确认主机密钥。通过 SFTP 浏览目标目录，或直接输入绝对路径，然后核对项目和目标再开始传输。

**自动**模式先探测源服务器能否通过公钥非交互式登录目标服务器，并要求源服务器已信任目标的主机密钥。探测不通过时，应用通过两端的 SFTP 连接转发数据，不写本机磁盘。也可以手动指定模式。直连使用 tar 数据流；应用不会把目标的密码或私钥交给源服务器。

遇到同名项目时，一次选定跳过、给传入项目换名，或将旧项目备份为 `.bak-年月日时分秒`（协调世界时）后再替换。目录整体替换，不会合并。数据先写到目标端的临时目录，按文件校验大小后再移入目标位置。保留普通权限和修改时间，不复制所有者、符号链接、特殊文件或特权权限位。不同 SFTP 服务器可能对文件名有不同解释，因此不接受含反斜杠或冒号等不兼容的文件名。传输使用当前 SSH 账号，不提权。

传输页以一条“源服务器 → 目标服务器”任务显示字节进度、文件数、速度、预计剩余时间和取消按钮。失败或取消后无法续传。发布过程中取消不会回退已发布的项目；连接中断时可能留下临时目录，清理失败会报告其路径。

### 传输页

右下的“传输”页显示进度、速度、剩余时间和取消按钮。同时最多跑 3 个，其余排队。

- 目标位置已有同名项目时先询问是否覆盖。
- 失败或取消的可以“重试”：在同一个会话里用它现在的连接重新排队；会话已关闭或未连接时不能重试。
- 下载完成后可以“打开”（用系统默认的程序；没有能打开它的程序时在文件夹中显示），或 “在文件夹中显示”。

### 下载列表弹出框

文件面板工具栏最右边的“下载列表”按钮和 FinalShell 的一样。有传输在进行时按钮上显示数目。点开是一个弹出框：

- 第一行是下载目录（太长时省略中间部分）、“更改…”和“在访达中显示”（Windows 是 “在资源管理器中显示”，Linux 是“在文件夹中显示”；目录不存在时先创建）。
- 下面是最近的传输（上传和下载），最新的在最上面，每行和“传输”页一样。
- 底部是“清除已完成”。

弹出框和“传输”页是同一个队列：“传输”页按开始的顺序排，弹出框反过来。

### 应用图标上的进度

有传输在进行时：

- macOS 的 Dock 图标显示数目和总进度。
- Windows 的任务栏按钮显示总进度（MyGo 在 Windows 上没有图标角标）。
- 支持 Unity launcher API 的 Linux dock 两样都显示。

总进度算的是正在跑、已知大小的传输的字节数。全部结束后清除。进度每秒最多更新 4 次，数目一变立刻更新。

## 编辑远程文件

和 FinalShell 一样，在文件表格里双击文件（或选中后按回车），或右键“编辑”，在编辑器窗口里打开。双击文件夹仍然是进入文件夹。

编辑器用 MyGo 的代码编辑器（`ui/editor`）：30 多种语言的语法高亮、查找和替换、跳转到行、撤销、多光标、折叠。语言按文件名认，没有扩展名的脚本看第一行的 `#!`。nginx、systemd 这类没有的语言按纯文本显示，`.conf` 是 MyGo 认作 TOML 的。

### 窗口

一个编辑器窗口（主窗口的子窗口，1000×700，可以调整大小），每个文件一个标签。标签记着它来自哪个会话。窗口标题是选中标签的 `主机:路径`，有没保存的修改时标签上显示一个圆点。再打开已经打开的文件只切换到它的标签。

工具栏是保存、撤销、重做、搜索、替换、跳转到行、自动换行、从服务器重新加载。下面的状态栏显示“已保存”或保存的错误、语言、行和列、编码、换行符（编码和换行符点一下可以换）。

### 按键

- Ctrl+S（macOS 是 Cmd+S）保存。
- Ctrl+W（macOS 是 Cmd+W，“关闭标签”改了键的话那个键也行）关闭标签。关掉最后一个标签就关闭窗口。
- Ctrl+Tab / Ctrl+Shift+Tab 切换标签。
- Esc 只给编辑器（关掉查找栏、跳转栏、补全，多个光标回到一个）。和别的子窗口不同，Esc 从不关闭编辑器窗口：编辑时常按 Esc，误按一下不该关掉窗口。关闭窗口用它的关闭按钮，或关掉最后一个标签。
- 编辑器自己的键（Ctrl+F 查找、Ctrl+H 替换、Ctrl+G 跳转到行、Ctrl+D 选下一个……，macOS 上是 Zed 的键）见 MyGo 的文档。
- 编辑器窗口里没有主窗口的快捷键。

### 读取

在 goroutine 里通过 SFTP 把文件整个读进内存（不写临时文件），大文件显示进度，读完通过 `App.post` 显示。

- 超过 10 MB 的文件先问（“仍然打开”）。
- 前 8000 个字节里有 NUL 的文件当作二进制文件，不打开。“用默认程序打开”把它下载到应用的缓存目录（`<缓存目录>/finallyshell/opened/<时间>/`，超过一天的下次打开时删掉），再用系统的默认程序打开。这个副本改了不会传回服务器。

### 保存

先在同一个目录里写一个隐藏的临时文件（`.<文件名>.finallyshell-<随机>.tmp`），设成原文件的属主（属主不一样时）和权限（包括 setuid 等位），再用 `posix-rename@openssh.com` 替换原文件。服务器没有这个扩展（或它失败了）就先删掉原文件再改名（SFTP 第 3 版的改名不能覆盖已有文件，所以中间有一小段时间文件不存在）。这样读这个文件的程序只会看到旧的或新的，连接中途断开原文件也不受影响。

替换会得到一个新文件，丢掉原文件的扩展属性、ACL、SELinux 标签和硬链接，而且只有 root 能把文件交给别的用户。所以这些情况下改成就地写（截断再写）：

- 文件是符号链接（写到它指向的文件，链接保持是链接）；
- 目录没有写权限；
- 改不了属主或权限；
- 改名被拒绝（比如 `/tmp` 这样的粘滞目录）。

就地写保留文件的一切，但不是原子的：写到一半失败文件会被截短（编辑器里的内容还在，可以再存一次）。

建临时文件因为别的原因失败（比如磁盘满了）时报错，不动原文件。保存时文件已经不见了的话重新创建。

### 冲突

记下打开（或上次保存）时服务器上文件的修改时间和大小，保存前再查一次。变了（或者文件被删了）就问“覆盖”还是“重新加载”。重新加载算一次编辑，“撤销”可以找回自己的内容。

### 换行符和编码

- 保持文件原来的换行符（CRLF 或 LF；两种都有的文件按多的那种保存）。
- 默认 UTF-8，开头的 BOM 保持。
- 不是有效 UTF-8 的文件，上面提示可能是 GB18030（或 GBK），可以“以 GB18030 重新打开”。原样保存时不是 UTF-8 的字节也原样写回。
- 状态栏可以换成 GBK 或 GB18030（`golang.org/x/text`）。还没修改时按新编码重新读原来的字节，改过之后只改变保存用的编码。GBK 里没有的字符（比如 emoji）保存时报错，并指出在第几行。

### 没保存的修改

- 关闭标签、用关闭按钮关闭窗口时先问“不保存 / 取消 / 保存”。窗口是“全部保存”：存好的标签关掉，全存好了窗口就关。
- 退出程序时，确认框里也写上有几个文件没保存。这一项不管“关闭窗口前确认”开没开都问。
- 主窗口隐藏到托盘时，有没保存修改的编辑器窗口不关。

### 断开的会话

会话断开时编辑器里的内容保留，上面提示没有连接，“保存”不能用。重新连接后用会话新的 SFTP 连接保存。会话标签关掉了的话，用同一个主机的另一个已连接的会话保存。

普通编辑器无法保存没有写权限的文件。如需提权编辑，请使用代码编辑器。

### 代码编辑器

- 在文件列表中选择“用代码编辑器打开”或“以管理员权限在代码编辑器中打开”。每次打开都会创建独立窗口。工具一次传入多个文件时（例如 Caddyfile 和它导入的配置文件），可以在可折叠的文件树中选择文件并打开标签。圆点表示文件有未保存的更改。
- 支持 Caddyfile、Nginx、systemd 单元、dotenv、INI 和 MyGo 内置语言的语法高亮。编辑 Caddyfile 时，按 `Ctrl+Space` 补全指令、全局选项和匹配器，按 `Tab` 跳到下一个占位项，按 `Ctrl+/`（macOS 上为 `Cmd+/`）切换注释。工具栏提供查找、替换、跳行、撤销、重做、自动换行、折叠和调节字号；状态栏可切换语言、缩进和 LF/CRLF，并保留 UTF-8 BOM。
- “保存”（`Ctrl+S` / `Cmd+S`）和“全部保存”会先显示确切路径和可切换为并排或合并的差异视图。底部显示进行中的操作和结果，包括校验输出与备份路径。Caddy 的保存流程会一次接收全部修改的文件，并以原始字节检测冲突；校验失败不会保存，也不能跳过。
- 未提供专用保存流程时，编辑器拒绝替换已变动的文件和符号链接，在原目录生成 `<file>.bak-<yyyymmddHHMMSS>`，再保留属主和权限原子替换。当前用户保存需要 SFTP 的原子重命名扩展；管理员保存使用通用提权流程。普通多文件保存只保证单个文件的原子替换，不是一个事务。超过 5 MiB 的文件只读预览前 256 KiB；二进制或非 UTF-8 文件不可编辑。
- 连接断开不会丢失内存中的更改。重新连接同一主机后可重试；如果由带专用校验流程的工具打开，请重新连接原 SSH 会话。编辑器不会覆盖冲突文件。关闭有未保存更改的标签或窗口时，会询问保存、丢弃或取消。

## 桌面模式

在 SSH 会话菜单、底部面板角落，或连接管理器和“连接”页的 SSH 主机菜单中选择
“打开桌面”。从已保存的主机打开时，会复用已连接的会话，或发起新连接。桌面有独立
的会话行，共用 SSH 连接，不在服务器上安装任何东西。应用全屏快捷键也适用于桌面。

一台服务器显示终端或桌面，即终端模式和桌面模式；应用根据当前所在（或上次停留）的行判断是哪种。它的标签和会话列表里的行的右键菜单会给出“切换到桌面模式”或“切换到终端模式”中当前不在的那个；桌面壁纸的右键菜单和任务栏主机按钮的弹窗也一样。底部面板标签旁的按钮切换到桌面，快捷键“切换终端/桌面模式”（macOS 上 Cmd+Shift+B，Windows 和 Linux 上 Ctrl+Shift+D）双向切换，在终端里也能用。终端自身的右键菜单（复制、粘贴、全选、清屏）由 MyGo 终端组件生成，不能加入应用的菜单项。

### 桌面窗口

- 拖动标题栏移动窗口，拖动任意边缘或角调整大小。双击标题栏可最大化或还原。
  拖到顶部、左侧或右侧会预览并完成贴靠。桌面较窄时，贴靠窗口可能超过一半宽，
  以保留应用要求的最小宽度。窗口可以部分移出桌面的左、右、下边缘，标题栏始终
  留 120 DIP 在桌面上，方便拖回来。新打开和还原的窗口仍完整显示在桌面内。
- 按下窗口内任意位置即可聚焦。右击标题栏可还原、最小化、最大化、置顶或关闭。
  同一次运行中记住应用最近调整的窗口大小，不保存其位置。

### 桌面图标和文件夹

- 单击选中；按住 Ctrl（macOS 上为 Command）切换单项选中状态，按住 Shift 连续选择，
  或从空白处拖出矩形框选。双击或按 Enter 打开，也可以设置为单击打开。
- 将图标拖到另一个网格位置或拖进文件夹。“新建 › 新建文件夹”会创建文件夹并直接
  编辑名称。打开后可查看其中的应用、拖出图标、重命名，或删除文件夹并把图标放回
  桌面。上述操作不会改动服务器文件。
- 桌面菜单可调整图标大小、自动排列、按名称或类型排序、刷新，以及打开文件管理器、
  终端和个性化。移除图标不会卸载应用，可在启动器中重新添加。文件管理器发送的路径
  快捷方式会打开相应路径。

### 程序坞、启动器和个性化

半透明程序坞分为三组：启动器和助手、固定和运行中的应用、桌面控件。圆点表示正在
运行，聚焦的应用显示更宽的标记。单击可打开、聚焦、最小化或还原；同个应用有多个
窗口时可从列表中选择。右击可管理窗口或固定项，拖动可重排固定应用。“显示桌面”
暂时隐藏所有可见窗口，再点一次还原。时钟显示本地时间；主机弹出面板显示连接状态，
可返回终端或切换到其他已连接 SSH 会话的桌面。

启动器按类别列出可用应用，并按当前语言的应用名称搜索。右击可固定或添加到桌面；
按 Esc 或点击外部可关闭启动器。

在“设置 › 个性化”中，可以从八款绘制壁纸、八种纯色和本地图片中选择。支持 PNG、
JPEG、GIF（静态帧）和 WebP。此页还可调整图标大小、单击或双击打开、窗口层叠或堆叠，
以及最大化窗口是否覆盖程序坞。覆盖时，把指针移到屏幕底边即可唤出程序坞。壁纸和
程序坞固定项可分别重置。图标布局和文件夹按主机保存，其余个性化设置留在本机。

### 桌面模式 › 此电脑和文件

**此电脑**显示远程用户主目录、常见 Linux 目录和收藏，还列出挂载点、文件系统和可用空间。双击位置可在**文件**中打开。每个文件窗口都有独立的目录、浏览历史、选择、排序和视图。可以在地址栏输入绝对路径，在搜索框中即时筛选当前目录，或按回车搜索子目录（最多 300 条结果）。侧栏保留最近使用的 20 个位置，收藏可拖动排序。备注按主机保存在本机，并显示在详细信息视图和图标提示中。读取文件夹、搜索或打开文件稍久时，文件列表右下角浮出带转圈和“取消”的提示卡片；列表本身不会移动，双击不会点错位置。

可在行内新建或重命名，也可用工具栏和右键菜单打开终端、传输文件、压缩、解压或编辑属性。文本文件在远程文件编辑器中打开，其他文件可下载后交给系统默认应用。上传支持文件和文件夹选择器、拖放及系统剪贴板中的文件列表。远程下载在服务器上运行，支持 HTTP、HTTPS 和 FTP。连接禁用 SSH 命令执行时，不提供依赖该功能的操作。

可在文件窗口之间剪切、复制和粘贴。同一服务器上的粘贴可以复制或移动；跨服务器时使用传输队列复制，能直传时直传，否则由客户端中转，不落盘。替换会保留原项目作为备份，保留两者会为副本添加编号。上传和解压不覆盖同名项目。压缩包在服务器的临时目录中解压，仅支持普通文件和目录。属性可修改八进制权限和所有权；递归修改前会要求确认。删除将项目移入回收站；按 Shift+Delete 可在确认后永久删除。

### 桌面模式 › 回收站

在桌面文件管理器中确认删除后，文件会移入服务器回收站。回收站显示原始路径、删除时间、
大小、权限、所有者和文件备注。可按名称、路径或备注搜索，对列表排序，并选择一个或多个
项目还原或永久删除。右键菜单还可复制原始路径，或在「文件」中打开原始文件夹。

还原会重新创建缺失的文件夹。目标已有同名项目时，可保留两者、跳过或替换；选择「替换」
会先将现有项目移入回收站，仍可找回。备注会随项目还原，包括以新名称还原的副本。
「全部还原」和「清空回收站」作用于已列出的整个回收站，
不受搜索条件限制。永久删除和清空前会显示项目数量、大小及受影响的路径。可取消批量操作，
已处理的项目不会回退。

回收站使用 Linux 的 freedesktop 布局，无需安装服务。文件保留在原文件系统的用户回收站或
分区回收站中。若移动需要提权，通知和操作日志会标明 root 回收站。若尚未显示 root 回收站，
可点击盾牌按钮授权查看。提权操作会拒绝其他用户可重定向的目录。缺少可读元数据的项目可以永久删除，但无法还原到未知位置；刷新时
会清理无对应项目的过期元数据。

### 桌面模式 › 任务管理器

任务管理器通过 SSH 监控当前 Linux 服务器，无需在服务器安装程序。
**性能**提供负载、处理器、内存和交换空间、磁盘活动与网络流量。
选择磁盘或分区可查看吞吐量、IOPS、容量和挂载点；选择网卡可查看流量、
地址和链路速率（如果有）。图表最多保留 60 次采样。处理器详情包括各类
时间占比和各逻辑处理器的利用率。每个逻辑处理器的负载达到 70% 时为较忙，
达到 100% 时为超负荷。清理缓存和整理内存均需确认，并复用统一的提权流程。

### 桌面模式 › 终端、浏览器与应用中心

- 每个终端窗口在现有 SSH 连接上独立打开一个 Shell 通道。最小化不会中断 Shell；关闭仍在运行的 Shell 前会询问。工具栏可以在文件管理器中打开当前目录、在 Shell 退出后重连、调整字体、复制屏幕文本、粘贴和查找。复制选中文字请使用终端右键菜单或复制快捷键。目录跟踪依赖 Shell 的目录报告，或服务器上可读取的 Linux 进程信息。
- 服务器浏览器使用现有 SSH 连接与仅监听本机的 SOCKS5 代理，打开本机的 Chrome、Edge、Brave、Chromium 或 Firefox，不改动系统代理。可输入网址或选择探测到的服务器本机端口。点击「查询出口 IP」才会通过代理访问 `api.ipify.org`。停止浏览器、关闭桌面窗口或断开 SSH 都会停止代理。代理运行期间，本机其他程序也能使用该监听端口。从网站列表打开的域名固定连到服务器上 Nginx 的监听地址，不经 DNS，窗口中会列出这些域名。
- 同一窗口的 **浏览器内核** 按需下载浏览器，不随应用打包：Chrome for Testing（Google 官方免安装 Chrome，下载 200 MB，占用 470 MB）、Firefox（Mozilla 正式版，90 MB，380 MB）或 Camoufox（带指纹防护的 Firefox，1.3 GB，2.6 GB）。都从官方来源下载，Firefox 和 Camoufox 按官方公布的 SHA-256 校验；Chrome for Testing 没有公布校验和，经 HTTPS 从 Google 的存储下载。下载时显示进度，可以取消；下载失败、取消或停滞（一分钟没有数据）时，原有的内核保持不变。**检查更新** 向来源查询最新版本，**更新到** 和 **重新下载** 整体替换内核，**删除** 前会先确认。正在被浏览器使用的内核，要等浏览器停止后才能更新或删除。**选择浏览器** 里，下载的内核排在本机已安装的浏览器前面。每台服务器各自记住为它选择的浏览器，只保存在本机，不参与同步；那个浏览器被删除时窗口改用其他浏览器，重新下载后自动换回。浏览器停止时，**重置浏览器数据** 清除这台服务器的浏览器配置（登录状态、Cookie 和缓存）。
- 应用中心列出客户端内置应用，不提供应用安装商店。可搜索、按类别筛选、重新打开最近使用的应用，也可通过应用菜单添加到此主机的桌面或固定到程序坞。服务器工具沿用现有管理页及其确认流程，覆盖 Docker、数据库、Nginx 站点、系统工具、网络和传输等。桌面默认显示全部应用。

### 桌面模式 › AI 助手

在 **选项 › AI 助手** 中接入自己的 OpenAI 兼容服务。选择服务商预设，填写接口基础地址和默认模型，在 **其他可选模型** 中每行填一个其他模型 ID（**添加已获取的模型** 可以加入 **获取模型** 找到的模型），再测试连接。只有本机 Ollama 可以不使用密钥。请求与更新程序使用相同的系统或环境代理。

在服务器桌面打开 **AI 助手**。顶栏显示当前操作的服务器和使用的模型：模型菜单可以把当前对话切换到默认模型或其他已配置的模型，每条回复都标注由哪个模型生成。左侧列出该服务器的对话（顶栏第一个按钮可以收起；窗口较窄时改由 **历史对话** 按钮列出）。Enter 发送，Shift+Enter 换行。对话的第一个问题只发送问题和助手指令；之后的问题默认附带最近的对话，可以取消勾选 **附带聊天记录**。可以勾选附加预览过的附件：已检测到的操作系统、工作目录、最近 20 行终端输出及选中的日志；附件在输入框上方收成一行，点开查看全部。“服务器为什么变慢了？”还可以附加当前负载、CPU、内存和主要进程。应用会遮盖识别到的敏感信息，但发送前仍应检查预览。附件以及基于附件生成的回复都不会写入对话记录文件。

输入框下方和欢迎页的 **常用功能** 列出 77 条服务器上最常做的事，分 16 类：系统巡检、性能排查、磁盘与存储、网络与端口、安全加固、用户与权限、服务与进程、日志分析、Docker、Web 服务、数据库、备份与定时任务、软件与更新、证书与 HTTPS、防火墙、命令与脚本。可以跨分类搜索；点一条就填进输入框，把【】中的内容换成实际值后发送。左侧的对话可以用行上的删除按钮或右键菜单删除，删除前会确认，另一个对话执行中时也可以删除。多个对话可以同时进行：点 **新建对话** 或切换到其他对话时，正在执行的对话会在后台继续；它在列表里的行执行中显示转圈，有命令等你确认时显示提醒图标，点一下即可回到它当前的进度。只有正在执行的对话不能删除；拖动输入框上沿可以调整它的高度，双击恢复默认高度。

**服务器概况：**通过 SSH 连接的服务器上，助手每次连接时用只读命令读取一次服务器概况：系统和版本、init 系统、包管理器、`sudo` 是否免密（只对管理员组成员检查）、CPU、内存和磁盘、时区、防火墙、SELinux 或 AppArmor、容器工具、运行中和失败的服务、语言运行时和监听端口。概况作为不可信数据随提问发送，日期只记到天，让模型给出的命令贴合这台服务器，比如用 `apt` 还是 `dnf`、`systemctl` 还是 OpenWrt 的 `init.d`、`ufw` 还是 `firewall-cmd`。每个对话保留它开始时的概况。窗口顶栏的 **服务器概况** 可以查看，点 **刷新** 重新读取。读取慢或失败时，提问照常发送，只是不带概况。在 选项 › AI 中取消勾选 **随提问发送服务器概况** 即可关闭。

**上下文：**对话历史按 token 预算发送，在 选项 › AI › **上下文长度** 中设置（32K、默认 64K、128K 或 200K）。每个问题发送能放进预算六成的最新历史，并附带本次运行中命令的输出摘要。历史超过预算的四分之三时，先由模型把较早的部分压缩成摘要（目标、服务器信息、执行过的命令和改动、当前状态、未解决的问题、已做的决定、下一步），最近三个问题保留原文；此后由摘要代替那部分，对话里有一行提示标出压缩到哪里。压缩失败时问题照常发送，只带放得下的历史。同一个问题执行多轮命令时，最早的命令输出会先被缩短。

**安全护栏：**可能断开助手所用 SSH 连接的命令（停止或重启 SSH 服务、关闭网络、开启防火墙却没放行 SSH、杀掉某个用户的全部进程）不会自动执行，即使开启了 **全部自动执行** 也一样：卡片会警告可能断开连接，需要你输入 `RUN` 才执行。选项 › AI 的 **需要手动确认的命令** 每行一个正则表达式，助手调用的命令只要匹配任意一条，就会等你手动确认后才执行，只读命令也不例外，卡片上会注明命中的规则；无效的正则会被标出并忽略。一个问题最多连续执行 30 轮命令。

每个问题下方有“复制内容”和“编辑后重发”：编辑会把问题放回输入框，上方有提示，发送后替换这个问题及之后的对话。每条回复下方有“复制内容”，对话最后一条回复还有“重新生成”，重新提问，用新回复替换它。请求失败时，错误提示旁的“重试”重新发送这个问题。

通过 SSH 连接的服务器上，助手会自己执行命令来排查：模型通过工具调用，每次执行一条命令，在独立于终端的 SSH 通道上以登录用户身份运行，没有终端和输入。每条命令的时限由模型决定（`timeout_seconds`，10–1800 秒，未指定时 120 秒），耗时的扫描会给足时间。每条命令都在服务器上作为后台任务运行，脱离 SSH 通道，输出和退出码保存在用户自己的目录（`/tmp/finallyshell-ai-<uid>/`，权限 700）；超过 20 秒还没结束的命令转入后台继续运行，卡片上会标明，应用每隔几秒用一个短连接查看一次，命令结束后结果自动交给模型。执行中的卡片显示已运行时间和上限，**多等 5 分钟** 可以在执行中延长时限，单条命令最长共 1 小时；到达时限或停止提问时，命令连同它的进程组一起停止。输出超过模型能读取的长度时，模型会被告知完整输出在服务器上的位置，可以按需读取其中一部分。超过一天的任务目录会在下一条命令开始时清理。只依赖 POSIX `sh`，BusyBox 和 OpenWrt 也能用。命令达到时限被停止时，已输出的内容会连同建议一起交给模型：缩小范围或拆分命令、用 `nice -n 19 ionice -c3` 降低优先级，或加大时限重新执行，模型会自动这样做。每条命令显示为一张卡片，包括状态、退出码和耗时，下方可以展开输出（开头和结尾共 16 KB，已遮盖敏感信息）。只读命令直接执行：白名单里不做任何修改的程序和参数，例如 `df`、`ps`、`journalctl -n`、`systemctl status`、`docker ps`（前面加 `nice`、`ionice`、`timeout` 也算），且没有重定向到文件、命令替换、变量或 `sudo`，也不读取密钥或密码文件。其他命令在卡片上等待你点 **允许** 或 **拒绝**；拒绝后模型会改为询问你。看起来具有破坏性的命令还需要输入 `RUN`。勾选 **全部自动执行** 后，本对话中除破坏性命令外的命令都不再询问；每个新对话都默认关闭。一个问题最多连续执行 30 轮命令。会修改系统的命令记入桌面的操作日志。命令输出、日志和附件一律作为不可信数据交给模型。对话记录保存命令和退出码，不保存输出。没有 SSH 连接时（本地终端、Telnet、串口），助手只能给出命令建议；模型或服务商不支持工具调用时也一样：问题会去掉工具重新发送，窗口里会说明原因。

代码块支持复制；单行 Shell 命令可插入终端而不发送回车。**运行**会展示完整命令并要求确认，明显可能破坏磁盘的操作还需输入 `RUN`。请确认终端停在空白 Shell 提示符处，助手无法验证终端正在运行什么程序或已有何种输入。**Ctrl+Shift+I**（macOS 为 **Cmd+I**）可打开终端弹层，生成一条供审核的命令，不会自动运行。要解释选中的终端文本，先复制，再从命令输入框区域的右键菜单选择 **用 AI 解释复制的文本**，进入助手审核并发送。命令弹层只生成建议；助手没有内置托管服务或知识库。

### 桌面模式 › SSL 证书

**SSL 证书**应用为你输入的域名从 Let's Encrypt 免费申请证书，就像 Caddy 给自己的网站申请证书一样，然后打包成 ZIP，适用于各种 Web 服务器。列表显示本机保存的证书，每张都有域名、验证方式、颁发者和到期时间：剩余不到 30 天显示黄色，不到 7 天或已过期显示红色。

**新建证书**可以填一个或多个域名，用空格、逗号或换行分隔；粘贴整个网址时只取主机名，中文域名会自动转成 ASCII 形式。填 `*.example.com` 申请泛域名证书。密钥默认用 ECDSA P-256，也可以选 RSA 2048 给老系统用。Let's Encrypt 的证书有效期为 90 天。

Let's Encrypt 只给能证明归你所有的域名签发证书，所以应用会自动找一种不需要你动手的方式，并说明选了哪种、为什么：

1. **DNS 服务商接口。**泛域名，或域名的 NS 属于你已配置的 DNS 服务商时，应用通过服务商接口添加 TXT 记录 `_acme-challenge.<域名>`，等它生效后申请，申请完删除，服务器上什么都不改。域名托管在支持的服务商、但还没配置时，应用会提示你，填好密钥后下次就能全自动。
2. **通过当前服务器的 HTTP 验证。**域名能访问到当前会话的服务器时，由服务器响应 Let's Encrypt 的 HTTP 请求（`http://<域名>/.well-known/acme-challenge/…`）。应用先检查 80 端口被谁占用、运行着哪些 Web 服务器，再按改动从小到大逐一尝试；每种方式都先放一个探测文件，从本机通过域名去取，取到了才向 Let's Encrypt 申请：
   - 把文件放进为这个域名服务的网站目录（Nginx 站点、Caddy 的 `root`、Apache 的 `DocumentRoot`，以及常见的 `/var/www/html`），不改任何配置；
   - 80 端口空闲：在 80 端口启动应用自己的小型 Web 服务（服务器上有 Python 3、BusyBox `httpd` 或 Perl 中的哪个就用哪个），签发完就停，最长 30 分钟后也会自动退出；
   - 80 端口被 Caddy 占用：通过 Caddy 的管理接口添加一条只匹配验证路径的临时路由，只改正在运行的 Caddy，不动它的配置文件，用完删除（Caddy 重启后也会自动消失）；
   - 80 端口被其他任何程序占用（Nginx、Apache、Docker、Traefik 或应用不认识的程序）：征得你同意后，对 80 端口做透明分流。应用临时添加 iptables 规则（没有 iptables 时用 nftables），把从外部进入 80 端口的连接转给应用自己的一个小程序：它只应答验证路径 `/.well-known/acme-challenge/`，其他请求原样转发给原来占用 80 端口的程序，网站不会中断。期间原程序看到的访客 IP 都是服务器自己的地址（不会是 127.0.0.1，以免它把访客当成本机、放开只给本机看的页面）；只监听 127.0.0.1 的程序原本就没有访客能访问，分流时也不会把任何请求转给它。大约 1 分钟后撤销规则、停止小程序；小程序最长 30 分钟也会自动退出。原程序和它的配置都不会被改动。需要服务器上有 Python 3；
   - 80 端口被服务器防火墙（ufw 或 firewalld）挡住：征得你同意后临时放行 80 端口，用完关闭。云服务商的安全组无法从服务器上修改，探测仍失败时应用会说明这一点。

   中国大陆的机房（阿里云、腾讯云等）会拦截未备案域名在 80 和 443 端口的访问，Let's Encrypt 不可能取到验证文件。探测取回的是这种拦截页时，应用会说明原因，改用 DNS 验证。
3. **DNS 服务商密钥，或手动添加 TXT 记录。**以上都不行时，如果域名托管在支持的服务商，应用提示你填写它的密钥，填好就能全自动；否则列出要添加的记录，每条都能一键复制，然后每 10 秒检查一次，最长 30 分钟，域名的 NS 能查到记录后自动继续。

每一步都实时显示，**取消**会在下一步停止签发；无论成功、失败还是取消，在服务器上做的临时改动都会撤销。

**自签名证书**不需要验证，也不需要联网：任意域名和 IP 地址一键生成，有效期一年。添加到系统的受信任证书之前，浏览器都不会信任它，所以只适合内网和测试。

**下载**会保存一个 ZIP，勾选的每种格式一个文件夹：

| 文件夹 | 文件 | 适用于 |
|---|---|---|
| `nginx/` | `fullchain.pem`、`privkey.pem` | Nginx、Caddy、大多数面板 |
| `apache/` | `<域名>.crt`、`<域名>.chain.crt`（自签名证书没有）、`<域名>.key` | Apache |
| `iis/` | `<域名>.pfx` | IIS、Windows、Tomcat 8.5 及以上 |
| `tomcat/` | `<域名>.jks` | Java 和老版本 Tomcat |

另附一个 `README.txt`，说明每个文件怎么用。PFX 和 JKS 文件有密码保护：随机生成的 16 位字母和数字，每张证书生成一次，每次下载都相同，在下载对话框里显示并可一键复制，不会写进 ZIP。PFX 用 AES-256 和 SHA-256 加密，Windows 10 1709、Windows Server 2019、OpenSSL 1.1.1 和 Java 12 及以上都能读取。

**续期**为同样的域名和密钥类型重新申请证书，按当时找到的方式验证，密码保持不变。Let's Encrypt 限制同一组域名的签发频率（每周 5 次）；勾选 **使用 Let's Encrypt 测试环境** 会从它的测试 CA 签发，限额高得多，但证书不受任何浏览器信任，适合试用。

**DNS 服务商**在应用里配置：Cloudflare（API 令牌，需要 Zone › DNS › Edit 权限）、阿里云 DNS（AccessKey ID 和 AccessKey Secret）、腾讯云 DNSPod（SecretId 和 SecretKey）、华为云 DNS（Access Key ID、Secret Access Key 和区域，默认 `cn-north-4`）。密钥保存在系统凭据库。

证书和私钥只保存在本机，不会同步，也不会上传。删除证书时私钥一并删除。

## 系统页

底部面板的“系统”页管理已连接的服务器本身：顶部一行在“服务”“日志”“定时任务”“磁盘”“软件更新”“安全”“防火墙”“网站”之间切换。每个模块显示时才通过 SSH 读取服务器；需要 root 的操作和其他功能一样走提权，每次修改前都会确认。本地终端和关闭了监控的主机不可用。OpenWrt 上改为显示[系统页 › OpenWrt](#系统页--openwrt)中的模块。

### 系统页 › 服务、日志和定时任务

- **服务：**按运行状态或自启动配置筛选和排序。选择一行或多行后，从“操作”或右键菜单执行。详情显示状态、单元文件和属性。编辑覆盖配置会先备份已有的 `override.conf`，保存后重新加载 systemd 配置，不会重启服务。支持读取 OpenRC 或 SysV 的服务列表，但不会修改这些服务。
- **日志：**可跟踪系统日志、指定单元的日志或远程绝对路径下的文件。系统日志支持按级别和时间段筛选，已接收的日志支持按文本或正则表达式筛选。暂停只冻结显示，后台最多缓存最近 20,000 行，文本上限为 24 MiB。离开日志页会关闭 SSH 日志流。可复制或保存筛选结果；保存到本地时不会覆盖已有文件。最近输入的路径只保留在本机，不随连接同步。
- **定时任务：**可查看自己的 crontab、其他用户的 crontab、系统任务文件和 systemd 定时器。编辑用户的 crontab 会保留无关行，并在实际写入用户的主目录备份原表（提权时是 root 的主目录）。禁用任务只会注释该行。未来三次运行时间按服务器当前的 UTC 偏移估算，不考虑之后的夏令时切换或 `CRON_TZ` 设置。系统任务文件可单独编辑并备份，systemd 定时器仅供查看。“立即运行一次”会显示命令输出，但不会复现 cron 的运行环境，也不支持 `%` 输入语法。

### 系统页 › 磁盘、更新、安全和防火墙

- **磁盘**列出挂载点的用量，每次只扫描一个文件系统。输入绝对路径或打开挂载点；双击目录可继续下钻，“大文件”最多列出 100 个超过 50 MiB 的文件。扫描可取消、有超时，结果缓存到刷新或断开连接为止。右键可在文件面板打开、复制路径，或删除选中且未受保护的项目。在普通用户可修改的目录内操作时，请取消“以 root 扫描”，用当前账号操作。清空 `.log` 文件前会在原目录备份。清理项包含 APT 和 DNF 缓存、可设大小上限的归档系统日志及匹配的轮转日志；显示的估算大小不等于实际释放的空间。
- **软件更新**显示系统版本、内核、可更新的软件包、安全更新，以及系统支持检测时的重启提示。APT、DNF 和 YUM 支持刷新索引、全部升级、仅装安全更新或升级所选；Zypper、APK 和 Pacman 只读取本地索引。包管理操作会实时显示输出，确认后无法在客户端取消，请保持 SSH 连接直至完成。确认重启后，服务器将在一分钟后重启。
- **安全**按来源 IP、用户名或日期汇总近期 SSH 失败，并显示成功登录、当前和历史会话、近期使用 sudo 的用户及重点 SSH 生效设置。IP 归属地沿用现有查询设置。Fail2ban 列出运行中的防护项和封禁地址，封禁与解封都需确认，且不能封禁当前 SSH 来源。
- **防火墙**显示 UFW 编号规则、Firewalld 区域及监听端口。保护主机配置中的 SSH 端口、当前连接的实际端口，以及可确认的其他 SSH 端口。启用 UFW 前会先放行当前 SSH 来源和端口。应用能识别原样保留的软件包默认预规则；可能阻断 SSH 的自定义预规则仍会阻止启用。Firewalld 只更新指定端口或服务的运行时及持久配置，不重载无关的运行时规则。富规则、nftables 和 iptables 仅供查看；变更前会在原目录备份现有防火墙配置文件。

### 系统页 › 网站和证书

- **网站：**查看 Nginx 版本、服务状态和主进程 PID。支持筛选和排序的网站列表来自 `nginx -T`，列出 HTTP 虚拟主机、监听选项、TLS 有效期、上游或网站根目录，以及配置文件和行号。Apache 和 Caddy 仅检测，不支持管理。通过右键菜单或“网站操作”查看详情、编辑配置，或打开该网站的访问日志和错误日志。“在浏览器中打开”用桌面浏览器打开网站，浏览器的连接从服务器发出：先列出网站在各监听端口上的每个域名，这些域名不经 DNS，直接连到 Nginx 在服务器上的监听地址（域名尚未解析到这台服务器时也能打开，并使用网站自己的证书）；再列出它转发到的后端（`proxy_pass`，以及具名 `upstream` 中的每个 server），如 `http://127.0.0.1:10161`。安装在 `/etc/nginx` 之外的 Nginx（如宝塔面板的 `/www/server/nginx`）按运行中主进程的启动配置（`-c`）读取，测试和重载也使用该文件，网站配置文件同样可以编辑；在宝塔面板中修改网站时，面板可能重新写入该文件。解析器按 Nginx 的规则读取配置，包括 `*_by_lua_block` 指令中的 Lua 代码块（OpenResty、宝塔的证书验证配置）；仍无法解析的文件会在列表上方列出，其中的网站不显示，在能解析之前不能修改配置。Debian 风格的目录布局支持批量启用或停用对应的 `sites-enabled` 符号链接，原配置文件不会删除。
- **配置：**可以创建静态网站，或将请求反向代理到 `127.0.0.1` 上的端口，也可以指定已有的 TLS 证书和私钥路径。新配置写入 `sites-available` 并建立对应链接，或写入 `conf.d`。每次修改前都会确认。编辑前在原目录生成 `.bak-YYYYMMDDHHMMSS` 备份；文件被其他人改动时拒绝写入。只有 `nginx -t` 通过后才会重载运行中的 Nginx。配置测试失败时立即自动恢复原文件，编辑器里仍保留你的修改，Nginx 下次启动不会读到坏配置；万一自动恢复也失败，可用“恢复备份”手动恢复。新建网站或修改链接后测试失败，会撤销这次变更。自定义目录布局、不安全的文件属主或权限，以及会加载备份文件的 `include` 通配规则，均可能导致操作被拒绝。
- **Nginx 设置：**第三个页签，参照主机面板的布局。“服务”显示 Nginx 是否运行、版本和主进程 PID，提供启动、停止、重启、重载和测试配置；启动和重启前先测试配置，停止和重启前先确认。“配置文件与日志”可以像编辑网站配置一样编辑主配置 `nginx.conf`，并在“日志”页打开错误日志和访问日志。“性能调整”可以设置 `worker_processes`、`worker_connections`、`keepalive_timeout`、`client_max_body_size`、`client_header_buffer_size`、`client_body_buffer_size`、`server_names_hash_bucket_size`、`gzip`、`gzip_min_length`、`gzip_comp_level` 和 `server_tokens`，每项都有说明和 Nginx 默认值。保存前列出改动并确认；每条指令只在 Nginx 读取它的位置修改（主配置、`events` 或 `http`，不会改 `server` 内部），文件里没有就加在所在块的开头，其余内容（包括注释）原样保留。保存流程与编辑配置相同：先备份，`nginx -t` 测试通过后重载，测试不通过立即恢复原文件。
- **证书：**查看 Nginx 使用的公开证书及 Let's Encrypt 的 `fullchain.pem`，包括使用者、SAN、签发者、公钥类型和有效期。剩余不足 30 天显示黄色，不足 7 天及已过期显示红色。“检查域名”分别从 SSH 服务器和本机连接域名的 443 端口，可比较实际返回的证书；只有本机侧验证证书是否可信。
- **ACME：**查看 Certbot 管理的证书和常见续期定时器或计划任务。`acme.sh` 仅检测。Certbot 正式续期和试运行都需要确认，因为两者都可能执行已有钩子。签发证书要求安装 Certbot 的 Nginx 插件；向 ACME CA 提交域名并允许插件修改 Nginx 前需确认。执行这些工具前会备份受支持的 Nginx 配置。取消输出流不保证远程操作已撤销，重试前请刷新并核对实际状态。

### 系统页 › OpenWrt

在 OpenWrt 及其衍生系统（ImmortalWrt、iStoreOS 等带有 `/etc/openwrt_release` 的系统，21.02 到 25.12）上，系统页改为显示路由器需要的模块：“概况”“网络接口”“DHCP”“端口转发”“服务”“软件包”“日志”，以及和其他服务器一样的“定时任务”“磁盘”。桌面上也有同样内容的 **OpenWrt** 应用。修改以 root 执行且事先确认；和 LuCI 一样通过 `uci` 写入，只重载相关服务。

- **概况：**固件版本、型号、内核、运行时间、负载、内存、根分区（overlay）和 `/tmp` 的空间、包管理器（opkg，25.12 起为 apk）、防火墙（fw4 使用 nftables，fw3 使用 iptables），以及是否有 SFTP 服务。“备份配置”把 `sysupgrade -b` 生成的备份（与 LuCI 的备份相同）保存到下载文件夹。“重启”重启路由器。
- **网络接口：**netifd 的各接口及其状态、协议、设备、地址、网关、运行时间和流量。“重启接口”（`ifup`）和“停用接口”（`ifdown`）在当前连接经过该接口时会给出警告。
- **DHCP：**dnsmasq 的活动租约及剩余时间，以及静态租约。“设为静态”让所选设备固定使用当前地址；也可添加、删除静态租约。
- **端口转发：**防火墙的转发规则。可添加（名称、TCP 和/或 UDP、外部端口或端口范围、内部 IP 和端口、区域，默认从 `wan` 到 `lan`）、启用或停用、删除；防火墙重新加载规则，不中断已有连接。
- **服务：**`/etc/init.d` 中的脚本、procd 是否在运行它们、是否开机启动。可启动、停止、重启、重载、启用或禁用；停止或重启 `network`、`dropbear`、`sshd`、`firewall` 时会提示连接可能断开。
- **软件包：**已安装的软件包，以及已下载列表中的可升级版本。“更新软件源”下载列表（OpenWrt 把列表存在内存里，重启后需重新下载）。“安装…”按名称搜索列表；“升级”“卸载”作用于所选软件包。和 OpenWrt 官方一样，不建议单独升级核心软件包，操作前会提示。
- **日志：**系统日志（`logread`）或内核日志（`dmesg`）的最后 200、500 或 2000 行，输入即筛选。

OpenWrt 默认没有 SFTP 服务，需安装 `openssh-sftp-server`。在这类路由器上，文件页会在错误下方说明原因，并提供“安装 SFTP 服务”按钮：下载软件源列表、安装该软件包，然后重新连接文件管理。

BusyBox 的 `ps` 不支持 `-o` 时（如 OpenWrt），进程页、任务管理器和监控的进程列表改为读取 `/proc`；没有 `realpath` 时，磁盘扫描改用 `readlink -f`。

## Caddy 页

Caddy 页用于管理 SSH 连接所在服务器上的 Caddy，包含概览、网站、全局设置、配置文件、证书、日志和安装与迁移。可以将面板打开为全尺寸标签页。需要根权限的操作通过连接的提权机制执行。更改配置时先备份并原子写入，再校验完整配置；运行中的服务会热重载，已停止的原生服务保持停止。校验或热重载失败时恢复原文件。

### Caddy 页 › 概览和服务

概览自动检测已有实例，显示服务或容器、版本及可用更新、配置和数据目录、自定义模块、管理接口可用性、监听地址和端口冲突。有数据时还会显示服务资源占用、网站、即将到期的证书和反向代理上游的失败情况。启动、停止、重启、热重载、校验和更改开机自启均需先确认。停止 Caddy 会中断网站服务；发现端口冲突时可进入系统页的“网站”分区。

### Caddy 页 › 网站

- 可按地址、类型、目标或文件筛选网站。完整表格显示 TLS、配置文件和行号，以及基本认证、IP 限制、标头和访问日志图标。窄面板中可将鼠标停在地址上查看这些详情。
- 新建或复制网站时实时预览 Caddyfile。托管布局为每个新网站创建独立文件，其他布局则追加到主 Caddyfile。模板涵盖静态文件、反向代理、Node.js 和 Go 应用、PHP/WordPress、单页应用、www 跳转、带认证的文件浏览、API 网关、Docker 端口、WebSocket 和负载均衡。可查找服务器上的 PHP-FPM 套接字，也可从当前连接的 Docker 概览选择已发布的 TCP 端口。
- 表单支持 TLS、客户端证书、IP 和认证规则、压缩、标头与跨域请求、请求体大小、访问日志、路径路由和反向代理健康检查。基本认证新密码由服务端的 Caddy 生成哈希，明文不会进入预览或保存的配置。表单无法保留的设置或注释可在代码编辑器中修改。
- 通过右键菜单启用、停用或删除网站，打开 HTTP(S) 地址，或从本机和服务器测试响应头。校验会检查完整的候选配置而不保存。提交前会列出地址和文件；确认后先备份、再校验和热重载，失败则恢复原文件。

### Caddy 页 › 全局设置

- 按常规、端口和绑定、管理接口、日志、TLS/ACME、按需 TLS、服务器、本地 CA 和指标分组。复合选项提供 Caddyfile 语法示例，可单独修改草稿中的服务器设置。表单不会改写未知或敏感条目。
- 可使用 Caddy 内置的私有代理网段，或从本机下载 Cloudflare 官方 IPv4 和 IPv6 网段。保存前请核对草稿，只信任实际转发请求的代理。
- 可新增、编辑和删除命名片段。若要为已有片段改名，请使用代码编辑器同时修改片段和引用。保存前需确认，随后检查文件是否已被改动、校验完整配置并热重载，失败时恢复原文件。

### Caddy 页 › 配置文件

浏览主配置及其导入的文件，并用代码编辑器一起打开。格式化或恢复备份前会显示差异。读取后已在服务器上变更的文件不会被覆盖。可以将 Caddyfile 转换为 JSON，或通过管理接口查看正在运行的配置；两者均为只读预览。检测到服务的环境变量文件后也可以打开。分享截图前请隐藏私密值。

### Caddy 页 › 证书和日志

证书列表显示签发机构、密钥类型、存储路径及剩余有效期；不足七天标红，不足三十天标黄。Caddy 自动续签托管证书。可以复制公开的本地根证书，或在 SFTP 可读取时下载。日志可跟随服务日志、容器日志或检测到的访问日志文件，支持暂停、清空、文本及正则筛选、按列查看 JSON 访问日志（没有访问日志条目的日志，比如服务日志，仍按整行文本显示，并提示原因）和单条完整记录。

### Caddy 页 › 安装、更新和迁移

向导会推荐安装方式，并预览启动、开机自启和可选的防火墙变更：在启用的 UFW 或 firewalld 默认区域放行 80/TCP、443/TCP 和 443/UDP。其他网站服务占用 80/443 时，可保持 Caddy 停止，也可明确确认停止受支持的冲突服务并关闭其自启。安装失败时尝试恢复受影响的防火墙规则和服务状态。更新沿用检测到的安装方式；由 Compose 管理的容器应通过 Compose 更新。卸载默认保留配置和数据；移除标准原生安装的配置和数据需要输入 `caddy`，文件会移入私有恢复目录。

可以按原状接管已有实例、预览托管布局的差异，或将受支持的独立二进制文件迁移到官方软件包。导入 Nginx 网站时，可选择并审阅可编辑的草稿；复杂规则会标记为需要人工检查。可选的切换流程先校验已审阅的配置，再停止 Nginx 并关闭其开机自启，随后启用并启动 Caddy，确认其服务进程同时监听 TCP 80 和 443 端口。失败时恢复原配置和服务状态；不会移除 Nginx 文件。端口检查不代表各个网站可访问。不支持在 Docker 与主机服务之间迁移。

## 隧道页

当前会话的**隧道**页显示监听地址（含分配的实际端口）、目标或出口、状态、最近一次错误、当前及累计连接数、拒绝数和上下行流量。小图按秒显示最近的流量。标签数字表示正在监听的隧道数。

右键点击一行或打开**隧道操作**，可确认启动或停止、复制地址或示例命令、查看连接日志，或编辑配置。复制内容不含凭据。反向代理的地址和命令应在服务器上使用。每次运行在内存中保留最近 200 条已结束或已拒绝的连接，可筛选或复制；不记录网址、请求头或请求体。HTTP 长连接访问多个目标时，日志显示最后一个目标。

SSH 会话连上后启动已启用的隧道。监听失败不影响会话本身。关闭会话、手动断开或连接丢失时停止隧道；重连时使用主机当前的设置。经过跳板机时，转发使用到最终主机的 SSH 连接。

## 隧道管理器

可从命令面板、隧道页工具栏的网络图标或托盘菜单打开**隧道管理器**。在 SSH 主机的右键菜单选择**隧道…**，可直接筛选到该主机。

- 隧道按主机分组。可按隧道或主机名称搜索，或按主机、类型和状态筛选。表格显示实际监听地址（包括自动分配的端口）、目标或出口、运行模式、当前和累计连接数、近期流量和运行时长。窗口较窄时，可横向滚动查看其余列。
- 可多选隧道并批量启动、停止或重启。**启动所有后台隧道**只启动已标记为后台自动启动的隧道；**全部停止**结束所有管理中的监听和待重试任务，但不会断开终端。右键菜单可复制实际监听地址、查看最近一次错误和下次重试时间，或打开主机终端。添加或编辑隧道会打开该主机的连接编辑器。修改或删除运行中的后台隧道会停止它；如需使修改生效，请重新启动隧道。
- 同一主机的后台隧道共用一条独立 SSH 连接，不打开终端，也不执行监控。连接沿用主机保存的凭据、跳板机、代理和 SSH 保活设置。遇到未知或变更的主机密钥时，不弹窗，也不会自动接受；请先在终端连接并核验密钥，再回到管理器重试。网络故障或监听被拒绝后，以带随机抖动的指数退避重试，从约两秒逐步延长至最多一分钟。电脑从睡眠唤醒或恢复联网时会提前检查连接。
- 应用启动时自动运行已标记的后台隧道，即使它们没有设为随终端会话启动。管理器的复选框控制本设备的自动启动，行菜单控制每条隧道的标记；这些设置均不会立即启动或停止隧道。**无需终端，在后台启动**不会修改保存的标记。
- 主窗口关闭到托盘后，后台隧道仍继续运行。退出应用会停止它们并取消重试。主窗口**隧道**标签上的圆点表示有后台隧道正在监听，感叹号表示有后台隧道失败或正在等待重试。

## 进程页

右下的“进程”页是当前会话的进程管理器，相当于 FinalShell 的“高级进程管理”。点侧栏的进程列表也会打开它。

- 表格列出所有进程的 PID、用户、内存（RSS）、CPU %、名称、命令行和可执行文件路径。点列标题按该列排序，再点一次反过来；默认按 CPU 从高到低。上方的筛选框匹配名称、命令行和用户，不分大小写，旁边的数字是显示了多少个。
- 这一页显示时每 2 秒重新读取一次，切到别的页或别的会话时完全不读。列表变动时选中行跟着它的进程走。“刷新”立即读取。
- CPU % 是进程从上次读取以来占用单个 CPU 的比例，用 `/proc/<pid>/stat` 里的 CPU 时间算，和 `top` 一样：多线程的忙进程可以超过 100%。第一次读取显示 `ps` 给出的进程整个生命期的平均值（BusyBox 的 `ps` 没有，显示 0）。
- 其他用户的进程的路径要 root 才能读，显示“-”。
- 双击、回车或右键菜单的“打开详情”在列表下方用一个标签打开这个进程，标签名形如 `7267-java`，左边是 PID、名称、用户、完整命令行、可执行文件路径和工作目录，右边是环境变量。标签上的按钮把这些全部复制成文本，或重新读取；环境变量的右键菜单复制值、一行 `名称=值`，或全部。要 root 才能读的项显示“-”和“需要 root 权限”。进程已经退出时会说明。标签点 × 关闭；列表和标签之间、字段和环境变量之间的分隔条都可以拖动。
- 行的右键菜单还有“复制 PID”“复制命令行”“发送信号”（SIGTERM、SIGKILL、SIGHUP、SIGINT、SIGSTOP、SIGCONT）和“结束进程…”。每个信号都先确认。“结束进程”发送 SIGTERM；3 秒后进程还在运行时，对话框提供“强制结束”，发送 SIGKILL。服务器拒绝时，对话框显示服务器的原话，比如“服务器拒绝：Operation not permitted”。因权限不足被拒绝后，可选择“以 root 身份运行”，必要时通过 SSH 提权提示授权；重试发送前会再次核对进程启动时间。对话框打开期间已经退出的进程不会收到信号，即使这个 PID 此时已被别的进程使用：对话框显示“进程已经结束，没有发送信号。”
- 会话断开时保留最后的列表，变灰，上方是和终端一样的重新连接条。不是 Linux 的服务器显示“仅支持 Linux 服务器”；关闭了服务器监控的主机显示监控已关闭：这一页用的是同样的 exec 通道。

每次读取是一段通过 exec 通道运行的 POSIX sh 脚本，和服务器监控一样：`ps` 读用户、内存和命令行，`cat` 所有 `/proc/<pid>/stat` 读名称和 CPU 时间，一次 `ls -l` 读 `/proc/<pid>/exe` 链接得到路径。BusyBox 的 `ps` 和 `ls` 也能跑，并且不列出脚本自己的进程。详情在打开标签时读取一次 `/proc/<pid>/cmdline`、`exe`、`cwd` 和 `environ`；信号用 `kill` 发送，脚本先核对 `/proc/<pid>/stat` 里这个 PID 的启动时间和列表读到的是否一致。

## 网络页

右下的“网络”页是当前会话的网络监控，相当于 FinalShell 的“高级网络监控”：哪些进程在监听哪些端口，谁连着它们，各自传了多少数据。

- 表格每个监听中的 socket 一行（处于 LISTEN 的 TCP，以及等待数据包的 UDP socket），每个有其他连接（它自己发起的连接）的进程也一行：PID、名称、监听 IP、端口、协议、远程 IP 数、连接数、上传和下载速度、已上传和已下载的字节数。连到某个监听 socket 的连接都算在它下面，不论是哪个进程持有（fork 出来的 `sshd`、nginx 的 worker）；几个进程共用的 socket 算在 PID 最小的那个下面。点列标题按该列排序。筛选框匹配名称、PID、监听地址和端口，以及这一行的连接的远程地址。
- 这一页显示时每 2 秒重新读取一次，切到别的页或别的会话时完全不读；“刷新”立即读取。行变动时选中行跟着它的 socket 或进程走。
- 上传是服务器发出的，下载是服务器收到的。速度是每个 TCP 连接两次读取之间字节数（`ss -i` 的 `bytes_acked` 和 `bytes_received`）的差：新连接在下一次读取之前显示 0。UDP 没有 TCP 意义上的连接，它的 socket 的计数显示“-”。
- 不是 root 时读不到其他用户的 socket 属于哪个进程：这些连接放在“-”这一行，数量旁边写着“需要 root 才能看到其他用户的进程”。TIME-WAIT 状态的连接不属于任何进程。
- 双击、回车或右键菜单的“查看连接”在表格下方用一个标签打开这一行，标签名形如 `0.0.0.0:80` 或 `7267-java`，每个连接一行：归属地（只在有位置数据时，见下）、IP、端口、状态、上传和下载速度，以及总量。繁忙服务器的标签只显示前 5000 个连接，并说明这一点。连接的右键菜单复制它的 IP 或地址，追踪到它的路由，开启在线查询时还可以在线查询它。
- 会话断开时保留最后一次读取的结果，变灰，上方是重新连接条。不是 Linux 的服务器和关闭了服务器监控的主机会说明，和进程页一样。

每次读取是一段通过 exec 通道运行的 POSIX sh 脚本：`ss -tunapiH`（iproute2），用 `awk` 只保留 TCP 信息里的字节数。没有 `ss` 时（比如 BusyBox）读 `/proc/net/tcp`、`tcp6`、`udp` 和 `udp6`，通过 `/proc/<pid>/fd` 里的 socket 链接找到每个 socket 的进程，从 `/proc/<pid>/stat` 读进程名；`/proc` 没有字节数，速度和总量显示“-”。

### IP 归属地

程序里不带任何 IP 位置数据；没有数据时不在任何地方查询：表格只显示 IP 地址，没有“归属地”列。

- 第一次显示网络页时，表格上方的提示条问“显示 IP 地址的归属地？需要下载约 11 MB 的位置数据（ip2region）。”，按钮是“下载”“暂不”和“不再询问”。
  - “下载”下载 [ip2region](https://github.com/lionsoul2014/ip2region) v3.18.0 版的 `ip2region_v4.xdb`，保存到配置目录的 `geo/` 里，进度显示在提示条上，可以取消。文件先用临时名字写入，SHA-256 和程序记录的一致才保留；下载失败或取消不留下任何文件，提示条提供“重试”。数据在后台读进内存，每次读取都再检查校验和。
  - 文件从 GitHub（`raw.githubusercontent.com`）下载；GitHub 连不上、约 15 秒内没有发来任何数据、返回错误，或者给出的文件大小或校验和不对时，改从 jsDelivr（`cdn.jsdelivr.net`）下载。jsDelivr 镜像同一个版本，在 GitHub 常常连不上的地方（例如中国大陆）通常可以访问。两处给出的是同一个文件：无论从哪里下载，校验和都一样。改从 jsDelivr 下载时进度从 0 重新开始；“取消”会直接停止，不再尝试 jsDelivr。两处都失败时，提示条列出每个主机和它的回应。IPv6 文件对 jsDelivr 来说太大（它只提供 20 MB 以内的文件），只从 GitHub 下载。
  - “暂不”在程序下次启动之前不再显示提示条。
  - “不再询问”关闭归属地（`geoLocations` 为 `"off"`），直到在选项里打开。
- 有数据时，连接显示每个地址的国家、地区、城市和运营商，来自数据本身：中国境内是中文名称，其他地方多为英文。内网、回环、链路本地、CGNAT（100.64.0.0/10）和组播地址显示“局域网”，从不查询。
- IPv6 地址需要单独的数据文件，再下载约 37 MB：第一次出现 IPv6 对端时提示条会询问（`geoLocationsV6`）。
- 在线查询默认关闭，在选项里打开（见[网络监控](#网络监控)）。打开后，显示出来的行里数据中没有城市或运营商的地址会发送给 ip-api.com，每次请求 100 个，按程序的语言返回中文或英文名称，并按它返回的计数遵守每分钟 15 次请求的限制；它返回 429 时改问 ip.sb，每次一个地址。查询结果补上数据缺的部分，在 `geo/cache.json` 里保存 30 天。连接右键菜单的“在线查询”重新查询，并优先显示在线结果。

数据来自 ip2region（Apache-2.0 或 MIT 许可）。ip-api.com 的免费服务不加密（HTTP），仅限非商业用途。

### 路由追踪

连接右键菜单的“路由追踪”，或工具栏的路由按钮（输入地址或主机名），在表格下方的标签里追踪从服务器出发的路由，标签名形如“路由 8.8.8.8”：跳数、IP、延迟（有回应的探测的平均值）、归属地、ASN 和主机名。

- 标签通过 exec 通道在服务器上运行 `nexttrace --traceroute --raw -M -g <en|cn> <目标>`：[NextTrace](https://github.com/nxtrace/NTrace-core) 作为独立程序运行，用它自己的服务定位每一跳，这正是它的用途；`-M` 让它不为地图上传路由，`-g` 让它用程序的语言给出归属地（简体中文用 `cn`，其他用 `en`）。程序自己从不调用 NextTrace 的服务。它的 RAW 输出边追踪边逐个探测输出一行，所以各跳随到随显示；一跳有多个路由器回应时显示第一个。NextTrace 的默认模式改成 MTR 后（它的 README 说不早于 2027 年），`--traceroute` 让它保持传统模式；`--help` 里没有这个参数的旧版 NextTrace 不加它运行。
- 服务器的 PATH（加上 `/usr/local/bin`、`/usr/sbin` 和 `/sbin`）里没有 `nexttrace` 时，标签会说明，并给出 NextTrace README 里的安装命令 `curl -sL https://nxtrace.org/nt | bash` 和复制按钮：程序从不在服务器上安装任何东西。服务器有 `traceroute -n -w 2` 或 `tracepath -n` 时改用它们追踪，各跳随到随显示，下载了 ip2region 数据时用它显示归属地；两个都没有时会说明。
- 很多服务器上 NextTrace 和 traceroute 需要 root 或发送原始数据包的权限：它们的报错显示在标签里。
- 标签上的按钮把路由复制成文本，或重新追踪。

## 批量执行

可从连接管理器的选中项或右键菜单打开**批量执行**，也可从命令页的
**发送到**旁打开。在这两处按 **Ctrl+Shift+P**（macOS 为
**Cmd+Shift+P**）也可通过命令面板打开。独立窗口可以与终端同时打开。

- 在连接树中搜索并勾选单台 SSH 主机，或勾选整个文件夹（含子文件夹）。
  远程桌面主机和禁用执行通道的 SSH 主机不可选。可以输入 POSIX Shell 脚本，
  也可载入已保存的快捷命令。与**发送到**不同，批量执行不会向终端输入命令。
- 每次执行和重试都须确认，并列出实际目标。默认并发 10 台、每台超时
  60 秒（含连接和提权）。启用**首次失败后不再启动新任务**时，尚未开始的
  主机会被跳过，已开始的任务独立运行至结束。
- 优先复用已连接的会话；其他主机使用已保存的 SSH 认证和代理、跳板机设置。
  不会接受未知或已变更的主机密钥，跳板机也一样；请先手动连接并核验密钥。
  如果缺少 SSH 登录凭据，也请先手动连接并提供。
- **以 root 身份执行**使用统一提权。如果需要 sudo 或 root 密码，可以选择在
  本次执行中让其他主机尝试同一个密码，只在内存中保留。勾选**记住密码**才会将
  该主机验证通过的密码存入系统凭据库。
- 结果支持排序、按状态筛选、查看标准输出和标准错误，以及多选重试。
  **重试失败项**包括超时。每台主机最多保留 1 MiB 输出，可复制或导出为
  CSV 或纯文本；覆盖已有导出文件前会要求确认，并创建带时间戳的备份。
- 本地保留最近 20 次执行的目标编号、选项和摘要，不保存输出。勾选
  **将脚本保存到本地历史**后也可以重新载入脚本。请勿在脚本或输出里放入
  敏感信息，并提前备份脚本会覆盖的文件。取消或超时会关闭执行通道，
  但不会撤销改动，也不保证远端任务停止。

## 数据库页

在已连接的 SSH 会话中打开**数据库**页，即可访问 MySQL/MariaDB、
PostgreSQL 或 Redis，也可以将面板展开成独立标签页。数据库连接复用现有
SSH 会话，不监听本地端口，也不在服务器上安装程序。**探测数据库**根据 TCP
监听端口和 Docker 发布的端口提供地址建议；若无权访问 Docker，可使用统一提权重试。

- 连接配置按 SSH 主机保存。数据库地址以该 SSH 服务器为准（默认
  `127.0.0.1`）。若数据库在另一台机器上，建议启用验证证书和主机名的 TLS：
  SSH 不会加密从 SSH 服务器到数据库的这一段。勾选**记住密码**且认证成功后，
  密码才会存入系统凭据库。
- 在左侧选择数据库、模式、表或视图。数据每页 200 行；按列排序可使翻页更稳定，
  筛选时输入不带 `WHERE` 关键字的条件表达式。右键单元格可查看完整值；NULL
  与空字符串分开显示，二进制值用十六进制显示。结构页显示列、约束、索引和
  CREATE 语句（PostgreSQL 的定义是根据元数据重建的参考文本，不是可恢复的备份）。
  不支持直接编辑表格单元格。
- SQL 编辑器可执行选中内容或全部语句，并按语句查看结果、耗时和可用的受影响行数。
  每个打开的连接最多在内存中保留最近 100 次执行记录。查询结果有大小限制，可将当前
  结果或当前页导出为 CSV 或 JSON。JSON 保留 NULL，CSV 用空字段表示。覆盖导出文件前
  须确认，并备份原文件。
- Redis 使用游标式 `SCAN`，不使用 `KEYS`。可查看字符串、哈希、列表、集合、
  有序集合和流以及键的 TTL。可以编辑文本字符串和哈希字段而不清除过期时间，或多选
  删除键。控制台每行执行一条命令，含空格的参数需加引号，不支持凭据和连接管理命令。
- **只读**默认关闭。开启后仅允许明确列出的读命令，SQL 读取也在只读事务中执行。
  使用读取语法调用服务端例程时，例程仍可能产生副作用。
  如果需要独立于客户端的权限保障，请使用数据库自己的只读账号。写操作须确认，按顺序
  执行，遇错即停。取消不撤销改动，已完成的语句可能已经提交。请提前备份重要数据，
  不要在编辑器或控制台中填写密码或私钥。

## 命令页

右下的“命令”页存放快捷命令，相当于 FinalShell 的快捷命令面板：把常用命令存成按钮，点一下就发给当前会话。所有主机共用同一份，保存在 `quickcommands.json` 里（见 [configuration.md](configuration.md#quickcommandsjson)）。

- 左边是分组：“全部”显示所有命令，然后是你的分组，按你排好的顺序，每个分组后面是它的命令数；“新建分组”在原地输入新分组的名称（回车保留，Esc 放弃）。分组的右键菜单可以重命名，或在询问后删除；删除分组时其中的命令会保留，不属于任何分组，显示在“全部”下。
- 右边是所选分组的命令按钮，一行放不下时换行。按钮显示命令的名称，命令只有一行时在后面用灰色显示命令本身，有多行时显示行数；鼠标悬停显示完整的命令。上面的搜索框按名称和命令内容筛选，不区分大小写。
- 点按钮就把命令发给会话，走的是和命令输入框回车一样的路径：用会话的编码发送，文件面板像回车后一样跟随 shell 的目录，执行的每一行都记入这台主机的命令输入框历史。每一行后面都跟一个回车，所以多行命令会逐行执行。关掉“每行发送后按回车”时，最后一行不带回车：它停在提示符后面，等你检查后自己按回车；前面的行仍会执行。在会话那一行里，发送后键盘回到终端。
- 工具栏里搜索框前面的“发送到”选择按钮发到哪里（显示[命令编辑器](#命令编辑器)时，由它“发送”旁边的“发送到”代替，设置的是同一个目标）：“当前会话”（默认）、“全部会话”（所有已连接的会话），或“选择会话…”：弹出一个列表，每个会话一个复选框，带状态圆点和名称。目标不是当前会话时，它用警告色显示。命令输入框不跟随它，总是发给自己的会话。
  - 每个会话只收到一次（面板行就是它所属的会话，不算另一个）。新标签页和未连接的会话会跳过，其他会话照常收到。
  - 目标改成当前会话以外的选项后，第一次发送会询问“发送到 N 个会话？”，列出这些会话，按钮是“发送”和“取消”。之后发到同一个目标不再询问。
  - 目标不保存：每次启动都发给当前会话。选中的会话关闭后从中去掉；全部去掉后，目标回到当前会话。
  - 发送后键盘仍在当前会话的终端里；“放进命令输入框”仍然只填当前会话的输入框。
- 会话未连接时、在新标签页里、以及在会话未连接的面板行里，按钮显示为灰色，点了也不发送（目标是其他选项时：它的会话都没有连接时）；命令仍然可以新建、编辑和整理。
- 右键按钮有“发送”“放进命令输入框”（只限一行的命令：填进命令输入框但不发送，键盘也交给它）“编辑…”“复制”（放在它后面，名称为“名称（副本）”）“移到分组”和“删除”（会先询问）。
- 把按钮拖到另一个按钮上，就移到那个位置；拖到按钮后面的空白处，移到最后；拖到左边的分组上，移进那个分组。
- “新建命令”在单独的窗口里打开编辑器：名称、分组（新建时是当前显示的分组）、命令（可以多行）和“每行发送后按回车”（默认勾选）。名称留空时按钮显示命令的第一行。“保存”保存；Esc 或“取消”放弃修改。
- “命令”页也可以在单独的标签中打开（见[上面](#底部面板单独成标签)），得到一整块和窗口一样高的命令面板；里面的按钮发给它所属的会话。

暂不支持：带参数的命令、只属于某台主机的命令、同步命令，以及给每条命令设快捷键。

### 命令编辑器

相当于 FinalShell 的命令编辑器：按钮旁边的一个文本框，随手写几行命令直接发送，不用先存成快捷命令。

- 工具栏里“新建命令”后面的“命令编辑器”按钮显示或隐藏它，显示时按钮呈按下状态。它在按钮的右边，分组仍在命令页的左边；中间的分隔条调整它的宽度，最窄 280 DIP，最宽到按钮只剩 220 DIP，双击恢复为 460。命令页窄于 670 DIP 时（比如在右栏里），它放在分组和按钮的下面，占满整个宽度，分隔条调整按钮占的高度比例（默认 40%）。是否显示和这两个大小都和其他区域的大小一起保存（见[布局和分隔条](#布局和分隔条)）。显示编辑器时，工具栏搜索框的提示文字只写“搜索”，以便放得下。
- 顶部：“命令编辑器”“存为命令”和“清空”（清空后可以用 Cmd+Z，其他系统 Ctrl+Z，恢复）。文本带行号，用等宽字体，不做语法高亮：输入什么就发送什么。回车换行，Tab 缩进，Esc 把键盘还给终端，和命令输入框一样。
- 底部：“选项”“发送到”和“发送”。
  - “发送”，或在文本里按 Cmd+Enter（Linux 和 Windows 上是 Ctrl+Enter），发送选中范围涉及的每一整行，没有选中时发送全部，这样随手拖选也不会只发出半条命令。选中范围结束在某一行的行首时（比如拖到下一行开头），不包括那一行。有选中时按钮显示为“发送选中”。发送方式和多行快捷命令一样：逐行发送，每一行都走命令输入框的路径（会话的编码、目录跟随、主机的历史），后面跟一个回车。每一行原样发送，控制字符也照发，和快捷命令一样。末尾的空行不发送。
  - “发送到”和工具栏的是同一个目标（见上文）：同样的警告色，改成新目标后第一次发送同样会询问，每个已连接的会话只收到一次。
  - “选项”里有“每行发送后按回车”（默认勾选；关掉时最后一行停在提示符后面，键盘交给终端，由你在那里按回车）和“发送后清空”（默认不勾选），发送后把发出去的内容从编辑器里去掉：有选中时去掉选中的那几整行，否则全部清空。不清空时文本保留，键盘也留在编辑器里。两项都保存在 `settings.json`（`commandEditorNoEnter`、`commandEditorClear`）。
  - 编辑器为空，或目标里没有已连接的会话时，“发送”显示为灰色，Cmd+Enter 也不发送，和命令按钮一样。
- “存为命令”打开快捷命令编辑窗口，新建一条命令，内容是选中的那几整行（和“发送”取的一样）或全部文本，“每行发送后按回车”和编辑器的选项一致。
- 所有会话、以及面板行里的“命令”页共用同一份文本，重启后仍在：停止输入一秒后、以及退出应用时，保存到设置目录下的 `commandeditor.txt`（见 [configuration.md](configuration.md#commandeditortxt)），不参与同步。文件读不出来时，编辑器里会提示，并且不会覆盖它。
- 文本长度没有限制（除了文件本身）：编辑器只排版看得见的行，只在发送时才把文本拆成行。

暂不支持：语法高亮、多个编辑器标签、命令里的变量，以及在单独的窗口里打开编辑器。

## 告警

在**选项 › 告警**中为所有 SSH 主机设置默认规则，也可以按主机覆盖。规则默认关闭，可检测发起连接时 SSH 地址不可达、SSH 连接意外中断、CPU 使用率连续若干分钟超阈值、内存或受监控挂载点的磁盘使用率超阈值、一分钟平均负载超过在线 CPU 核心数的指定倍数，以及 systemd 服务故障。主动断开不会触发告警。资源和服务检查要求会话已连接且启用监控。systemd 检查独立运行，约每分钟一次，非 systemd 主机自动跳过。

持续未恢复的故障只提示一次；即使已恢复，同一主机的同一规则在 15 分钟内也不会再次通知。桌面通知通过系统发送，发送失败时改为应用内提示。点击铃铛查看时间、主机、规则、观测值和确认状态，可筛选、排序并批量确认。告警检查和历史只在应用运行期间有效。

## 选项窗口

点左下“会话”标题旁的齿轮按钮打开“选项”窗口。和 FinalShell 一样，左边是页面树，右边是页面。所有选项改了立刻保存在 `settings.json`，除了下面“鼠标”页说的两项和保活间隔、SSH Agent 地址（对修改后新建的连接生效），也立刻生效。

终端外观的几页见[外观](#外观字体配色背景图片)，文件图标主题页见 [文件图标主题](#文件图标主题)。

### 常规

- 界面语言：跟随系统、English 或简体中文。
- 外观：跟随系统（默认）、浅色或深色。跟随系统时按系统的浅色或深色外观显示，应用运行中系统切换了也跟着变；浅色、深色则固定。所有窗口立刻切换，包括系统标题栏，下次启动也用保存的外观。终端在两种外观下都保持自己的配色。保存为 `appearance`。
- 自动选中标签（默认开）：新连接打开后切换过去。关掉后新会话在后台打开，当前会话保持选中；没有选中的会话时仍然选中新的。
- 关闭时最小化到托盘（默认关）：点主窗口的关闭按钮时隐藏到托盘图标（macOS 是菜单栏）。图标菜单里有“显示主窗口”“检查更新…”和“退出”。Windows 上左键单击图标也能显示窗口，macOS 上点 Dock 图标也能显示。系统没有托盘时（Linux 没装 `libayatana-appindicator3`）按没开这一项处理。
- 关闭窗口前确认（默认开）：有会话已连接或正在连接时，关闭主窗口或退出（托盘菜单、macOS 的 Cmd+Q）之前用系统的消息框问一次。同时开了托盘：关闭按钮直接隐藏，不问；“退出”才问。
- 连接：“每隔 N 秒发送一次保活消息”，默认 30，设为 0 关闭保活，最大 3600。见[会话和标签](#会话和标签)。保存为 `keepAliveSeconds`。
- 连接：“SSH Agent 地址”，用 [SSH Agent](#ssh-连接) 登录的主机用的 agent，带一个 **检测** 按钮列出里面的私钥。留空就用默认：macOS 和 Linux 读 `SSH_AUTH_SOCK`，Windows 用 `\\.\pipe\openssh-ssh-agent`。下面的表格列出常见的地址：Bitwarden `~/.bitwarden-ssh-agent.sock`，1Password `~/Library/Group Containers/2BUA8C4S2C.com.1password/t/agent.sock`，Windows `\\.\pipe\openssh-ssh-agent`（Bitwarden 的 Windows agent 也用这个）。Unix socket 的路径可以用 `~` 开头。macOS 上从程序坞打开的应用读不到 `.zshrc` 里设置的变量，所以在那里设置的 agent 要在这里填一次。保存为 `sshAgent`，只对这台电脑生效，不同步。
- 更新：当前版本、“检查更新…”、“自动检查更新”（默认开）和检查到的新版本，或者这个副本为什么不能自行更新；见[更新](#更新)。

完整的行为见[关闭和退出](development.md#关闭和退出)。

### 传输

- 下载目录，带“更改…”和“使用默认”。
- “每次下载时询问保存位置”（默认关）。

在 `settings.json` 里是 `downloadDir`（没有是系统的下载文件夹；选回系统的下载文件夹也存成没有）和 `askDownloadDir`。下载目录被删掉了，下载时会重新创建。

### 终端

“终端”页是字符编码和按键序列的全局默认值，连接编辑器里选“默认”的主机用它们。

- 字符编码：UTF-8（默认）、GBK、GB18030、Big5、Shift_JIS、EUC-JP、EUC-KR、ISO-8859-1 或 Windows-1252。要和服务器的 locale 一样：老的中文服务器 locale 是 GBK 的，选 UTF-8 时中文是乱码。
  - libghostty-vt 只解码 UTF-8，所以程序在 SSH 和终端之间转码（`internal/termenc`，用 `golang.org/x/text`）。服务器的输出解码成 UTF-8 再给终端，一个字被拆在两个包里也能拼回来，解不了的字节显示成 U+FFFD。键盘输入、粘贴和终端的回复编码后再发给服务器，这个编码里没有的字发成 `?`（不用 x/text 默认的 0x1A，那在 shell 里是 Ctrl+Z）。选 UTF-8 时不转码。
  - 文件面板的文件名和内置编辑器还是按 UTF-8 处理，服务器监控只读 ASCII 输出，所以都不受影响。
  - 在 `settings.json` 里是 `termEncoding`、`hosts.json` 里是 `encoding`，值是 `utf-8`、`gbk`、`gb18030`、`big5`、`shift_jis`、`euc-jp`、`euc-kr`、`iso-8859-1`、`windows-1252`。不认识的按 UTF-8。
- 退格键发送：`^?`（ASCII DEL，默认）或 `^H`（Control-H，一些老系统和串口控制台要这个）。连接时把服务器终端的 erase 字符设成一样的。Alt+退格键发送 Esc 加同一个字符。FinalShell 的第三项“VT220 - Delete”（`ESC [3~`）在 shell 里是向后删除，所以没有加。
- 删除键发送：`ESC [3~`（VT220，默认）、`^?` 或 `^H`。只换掉不带修饰键的 Delete；Ctrl+Delete 等仍然发送插件的 `ESC [3;5~`，程序按带修饰键的 Delete 读它。
- 改了在下次连接时生效（转码和 erase 字符都是连接时定的）。这一页有“恢复默认”。在 `settings.json` 里是 `termBackspace`（`ctrl-h`；没有是 `^?`）和 `termDelete`（`del`、`ctrl-h`；没有是 `ESC [3~`）。不认识的值按默认处理。

“本地终端”下的“本地终端程序”是[本地终端](#本地终端)运行的程序和参数，比如 `wsl.exe`、`cmd.exe`、`pwsh -NoLogo` 或 `/opt/homebrew/bin/fish -l`。留空（占位文字“默认 shell”）运行用户的登录 shell，Windows 上运行 PowerShell。这一行像 shell 那样分成多个参数，但不展开变量和通配符：空白分开参数，单引号和双引号里的空白不分开（`sh -c 'echo hi; exec bash'`），反斜杠转义下一个字符；Windows 上反斜杠就是它自己，路径不用写两遍（`"C:\Program Files\PowerShell\7\pwsh.exe" -NoLogo`）。引号没有闭合时标签里显示错误。程序在 `PATH` 里查找。改了之后新打开或重新连接的本地终端才用它。在 `settings.json` 里是 `localShell`；它是这台电脑自己的，不同步，因为不同电脑上的程序和路径不一样。

### 终端 › 鼠标

用的都是 terminal 插件本身的功能。

- 选中即复制（默认关）：用鼠标选中文字（还有“全选”）后自动复制到剪贴板。
- 右键：显示右键菜单（默认）、粘贴、复制选中的文字、有选中的文字时复制，没有时粘贴，或不做任何操作。服务器上的程序接管鼠标时（比如开了 `mouse=a` 的 vim）右键交给程序，按住 Shift 才按这里的设置。
- Ctrl+单击打开链接（macOS 是 Cmd+单击，默认开）：终端里显示的网址和 OSC 8 超链接用系统浏览器打开。关掉后单击链接什么也不做。插件没有关掉链接识别的开关，所以按住 Ctrl 时链接仍然显示下划线（文件路径也会显示），只是不打开。
- 鼠标滚轮每格滚动行数（1 到 20，默认 3）：只管鼠标滚轮，不改触控板。Windows 上 3 对应系统鼠标设置里的“一次滚动的行数”，其他值按比例换算。

选中即复制和滚动行数在已打开的终端里立刻生效（插件有 `SetCopyOnSelect`、`SetScrollMultiplier`）。右键和链接插件只在创建终端时读取，没有 setter，所以已打开的会话重新连接后才生效。重建正在用的终端会丢掉屏幕和滚动历史，所以不这么做。

在 `settings.json` 里是 `copyOnSelect`、`rightClick`（`paste`、`copy`、`copy-or-paste` 或 `ignore`；没有或不认识的值是右键菜单）、`noLinkClick` 和 `wheelLines`（没有是 3，超过 20 按 20）。

没有中键粘贴。插件只把中键交给接管鼠标的程序，自己不处理，也不公开程序是否接管了鼠标；应用另外处理中键的话，这样的程序会同时收到中键和粘贴的文字。插件也没有 Linux 的 PRIMARY 选区。要做需要插件加一个像 `RightClick` 那样的中键选项。

### 终端 › 快捷键

表格列出每个操作、现在的快捷键和默认的快捷键（见[快捷键](#快捷键)）。选中一行点 “修改…”，在弹出的框里按下新的组合键，点“确定”保存。“使用默认”填回默认键，“恢复默认” 恢复选中的一行，“全部恢复默认”恢复所有。

shell 需要的键不让用，框里用红字说明原因：

- 不带修饰键（或只带 Shift）的键；
- 只带 Ctrl 的字母、数字、标点、空格和方向键等（Ctrl+C、Ctrl+R、Ctrl+W、Ctrl+←……）；
- 只带 Alt 的这些键（Alt+B、Alt+F 在 shell 里是 Meta，按词移动）；
- macOS 上只带 Option 的这些键（会输入字符）；
- Windows 上 Ctrl+Alt 加字母（就是 AltGr，很多键盘布局用它输入字符）；
- 系统占用的键（macOS 的 Cmd+Q、Cmd+H、Cmd+M、Cmd+Tab、Cmd+空格等，Windows 和 Linux 的 Alt+Tab、Alt+F4，Windows 上的 Win 键组合）。

例外：“切换到第 1–9 个标签”可以用 Alt 加数字（readline 的数字参数很少用，GNOME Terminal 也这样），“终端：重新连接”可以用任何键（它只在会话断开、没有 shell 的时候起作用），分屏的操作（分屏、移动焦点、交换分屏）可以用 Alt 加任何键，和 Windows Terminal 一样，但会用黄色提示：这个操作占用这个键时，shell 就收不到它。

和别的操作冲突时用黄字提示，“确定”后那个操作变成没有快捷键（显示“无”）。和终端自己的键（Ctrl+Shift+A 全选、Ctrl+= 缩放、Shift+PageUp 滚动、Ctrl+Insert / Shift+Insert 复制粘贴）冲突时也提示，“确定”后归这个快捷键。

窗口的快捷键立刻生效。终端的复制、粘贴是 terminal 插件的 `Keybinds`，插件只在创建终端时读取，所以改了之后新连接（包括重新连接）的会话才生效。

macOS 上这一页还有“将 Option 用作 Alt（Meta）键”（默认关，插件的 `OptionAsAlt`）：开了之后 Option+B 发送 Esc b，而不是输入 ∫。同样对之后连接的会话生效。

在 `settings.json` 里只存改过的键：`"shortcuts": {"find": "Ctrl+Alt+F", "closeTab": "none"}`。键名是 `copy`、`paste`、`find`、`fullScreen`、`reconnect`、`previousTab`、`nextTab`、`closeTab`、`connectionManager`、`newTab`、`switchTab`（值像 `"Alt+1-9"`）、`focusCommandBar`、`switchLeftPanel`、`toggleBottomPanel`、`splitRight`、`splitDown`、`zoomPane`、`focusPaneLeft`、`focusPaneRight`、`focusPaneUp`、`focusPaneDown`、`movePaneLeft`、`movePaneRight`、`movePaneUp` 和 `movePaneDown`。`Super` 在 macOS 上是 Cmd，`none` 是没有快捷键。没有或读不出来的就是默认。Option 用作 Alt 是 `optionAsAlt`。

### 终端 › 命令输入框

“在终端下方显示命令输入框”下面的“按键”一节列出输入框的按键：回车、Tab、↑ 或历史列表快捷键、历史列表里的 ← →、Esc，以及“终端 › 快捷键”里当前绑定的“聚焦命令输入框”快捷键。输入框本身不显示按键说明。

[命令输入框](#命令输入框)的开关，默认都打开，改了立刻对所有会话生效：

| 选项 | 键 | |
|---|---|---|
| 在终端下方显示命令输入框 | `noCommandBar` | 关掉后所有会话都不显示输入框：没有弹出列表，不保存也不读取历史，也不为它打开 exec 通道。关着的时候其他开关不能改。 |
| 路径选择 | `noCommandBarPaths` | 在路径上，或在第一个词之后的词上按 Tab。 |
| 历史命令 | `noCommandBarHistory` | ↑、Alt+H（macOS 上为 Cmd+Shift+H）和“历史”按钮，关掉时按钮隐藏。关掉后也不再保存发送的命令。 |
| 命令补全 | `noCommandBarCommands` | 在第一个词上按 Tab；关掉后在那里按 Tab 打开路径选择。 |
| 读取服务器的 shell 历史 | `noServerHistory` | 在历史列表里加上 `~/.bash_history` 和 `~/.zsh_history`。 |

这些键都以“关掉”命名，所以 `true` 表示关。“清空所有主机的历史…”先询问，再删除程序保存的所有主机的历史（`history` 文件夹）；服务器自己的历史文件不会改动。

### 网络监控

[网络页](#网络页)的 IP 归属地和路由追踪的选项。说明都放在这里，网络页本身保持简洁。

| 选项 | 键 | |
|---|---|---|
| 显示 IP 归属地（下载 ip2region 数据，约 11 MB） | `geoLocations` | `"on"` 显示“归属地”列；打开时如果没有数据就下载。`"off"` 隐藏这一列，保留文件；“不再询问”也是它。用户回答提示条之前没有这个键。 |
| 包括 IPv6 地址（再下载约 37 MB） | `geoLocationsV6` | IPv6 数据的同样设置。 |
| 在线查询 IP 归属地（ip-api.com） | `geoOnline` | `true` 在线查询数据中没有城市或运营商的地址。默认关闭，只在显示归属地时可用。 |

页面显示下载的数据在磁盘上占多少空间，“删除已下载的位置数据”先询问，然后删除 `geo/`（数据和在线查询的缓存），并关闭归属地和在线查询。在线查询开关下面的说明写明地址会发给第三方，以及 ip-api.com 的免费服务不加密、仅限非商业用途。最后一节说明路由追踪在服务器上运行什么。这些键都不同步：同意下载、同意把服务器的对端地址发给某个服务，是每台电脑自己的决定。

### 同步

“选项 › 同步”通过你已有的存储，让多台电脑上的连接和设置保持一致。Finallyshell 不为它运行任何服务器；在选择服务之前它是关闭的：

| 服务 | 要填什么 | 个人免费使用 |
|---|---|---|
| GitHub Gist | 一个带 `gist` 权限的个人访问令牌（“在 GitHub 上创建令牌”会打开已勾好权限的页面）。Gist ID 可以留空：第一次同步会找你账号下含 `finallyshell-sync.json` 的 gist，找不到就新建一个私密 gist，并记下它的 ID。 | 任何 GitHub 账号。 |
| WebDAV | 文件夹地址、用户和密码（服务提供应用密码时用应用密码）。文件夹不存在会自动创建。 | 坚果云、Nextcloud、群晖、Box 等。 |
| S3 兼容存储 | 端点、区域（Cloudflare R2 填 `auto`；留空为 `us-east-1`）、存储桶、文件名（留空为 `finallyshell-sync.json`）、访问密钥 ID 和私有访问密钥。请求用路径风格，并用 AWS Signature Version 4 签名。 | Cloudflare R2 和 Backblaze B2 有免费额度；MinIO 可以自己部署。 |

服务保留一个主文件和版本历史。内容离开电脑之前，用 AES-256-GCM 加密，密钥由 Argon2id（3 轮、64 MiB、4 路并行、随机盐）从**同步密码**派生；同步密码由你自己设定，每台电脑都要输入。主机名、地址、密码和手动备份备注都在密文里；版本的时间、设备名、应用版本、项目数量和原因不加密。同步密码无法找回。密码不对时，同步会提示，不会改动任何东西。

同步的内容：

- 文件夹和连接，包括已删除的（这样删除也能同步到其他电脑），但不包括每台主机上次连接的时间，所以每台电脑的最近连接列表各是各的。
- 已保存的快捷命令和分组，以及每台主机的命令历史（最近 500 条，本地终端的也算），逐条合并；某台电脑上更早的历史保留在那台电脑上。命令编辑器草稿留在本机。
- “数据库”页的连接，以及信任的主机密钥（`known_hosts`），逐行合并：一台电脑信任的主机密钥会同步到其他电脑；一台电脑删除或替换的（例如信任了重装服务器的新密钥），其他电脑上也会删除。注释行保留。
- 换到另一台电脑也有意义的设置：界面语言、外观，“常规”“鼠标”“快捷键”“终端”页，字体、配色、背景图片的填充方式和不透明度，AI 助手的设置（API 密钥随密码一起同步），关键词高亮，告警阈值，桌面模式的设置和图标，以及每个副本都有的文件图标主题（Material、Seti 或简洁）。
- 勾选“包括已保存的密码”（默认不勾）时，还包括：记住了密码的主机的密码和私钥口令；AI 助手的 API 密钥；数据库、隧道和远程桌面网关的密码；以及用 `~/.ssh` 下私钥登录的主机的私钥文件。私钥路径会同步成 `~/.ssh/<文件名>`，每台电脑按自己的用户目录读取；本机没有这个私钥时会写入那里，只有当前用户可读。一台电脑替换或删除的私钥会从同步中删除，仍保留旧私钥的电脑不会再把它加回来。已有的私钥文件绝不会被替换或删除：本机同名的另一把私钥保持不动；两台电脑有同名的不同私钥时，两把都不会写到第三台电脑上。没勾的电脑会原样保留文件里已有的密码。

以下内容各台电脑各自保留，不同步：面板大小和窗口布局、下载文件夹、背景图片和桌面壁纸图片（内置壁纸和纯色会同步）、从 VSIX 安装的图标主题、本地终端程序、SSH Agent 和 X11 显示、会话录制的保存位置、应用锁及其密码、随应用在本机启动的隧道、IP 归属地数据、AI 助手的对话记录、最近连接时间，以及“同步”页和账户本身的设置。

每次同步做三方合并：本机的数据、文件里的数据，以及上次同步后两边共有的数据（存在 `sync-state.json` 里，仍是加密的）。每个文件夹、主机、设置和密码分别合并：只有一边改了的，保留改过的；一边删了、另一边没改的，删除；两边都改了的，保留本机的版本，状态栏会显示有几项。第一次同步到某个服务（或改了同步密码之后）不会删除任何东西，两边有的都保留。同步过程中如果另一台电脑写了文件，会重新读取再合并一次（WebDAV 和 S3 会发送 `If-Match`，支持它的服务器会拒绝过时的写入；Gist 在写入前再检查一次）。在应用同步收到的改动之前，会先保存本机备份。同步进行中本机做的改动，会合并到同步带回来的结果之上，下次再同步出去；这期间保存的密码会保留，不会被同步带回的密码覆盖。同步进行中改了服务或它的字段时，这次同步带回的结果会被丢弃。

可能保存着旧数据的电脑，会先询问再合并。这包括三种情况：第一次同步到这个服务的电脑；上次同步留下的数据已经解不开的电脑（另一台电脑改了同步密码）；超过 30 天没有同步的电脑。如果它的连接和云端不一样（有本机独有的，或者内容不同），同步会在两边都没有任何改动之前停下，状态显示**等待选择同步方式**。**选择同步方式**窗口会列出两边各有多少连接，以及仅本机有、仅云端有、两边不同、相同的数量，并提供三个选择：

- **合并两边**（推荐）：保留两边的所有连接，同一条连接两边不同时保留云端的版本，因为它通常更新。
- **用云端覆盖本机**：替换本机数据，替换前会先备份。
- **以本机为准覆盖云端**：替换云端数据，其他电脑下次同步时跟着变，云端原来的内容保留在服务的历史版本中。

等待选择期间，自动同步不会运行；点**稍后再说**可以先不处理。如果这台电脑没有自己独有的内容，就不询问，直接合并，内容不同的条目保留云端的版本。

“立即同步”马上同步。“自动同步”在启动时、本机改动一分钟后（每分钟检查一次），以及每 5、15（默认）、30 或 60 分钟同步一次，以拉取其他电脑的改动。出错后会等到下一个间隔再试。状态栏显示上次同步的时间和结果，或者失败的原因。

“用本机数据替换远端…”会先询问，然后不做合并，直接把本机数据用当前输入的同步密码加密后写入文件。可以用它从头开始，或者更换同步密码（输入新密码，替换，再到其他电脑上输入新密码）。如果当前密码仍能打开旧文件，关闭“包括已保存的密码”会保留服务器已有的密码。

同步密码和服务的令牌、密码或私有密钥存在系统凭据存储里（见[密码存在哪里](configuration.md#密码存在哪里)）；系统没有凭据存储时只留在内存里。其他字段在 `settings.json` 的 `sync` 键里（见[同步](configuration.md#同步)）。

暂不支持：Google Drive、OneDrive，以及用浏览器登录 GitHub 代替令牌。

#### 备份与版本

从**选项 › 同步**，或连接管理器内「显示已删除」旁打开**备份与版本**。列表合并本机和服务器的版本，显示来源、时间、设备、数量、原因、大小和固定状态。**同步日志**显示最近 100 条同步记录。

- WebDAV 和 S3 在覆盖主文件前保存加密版本。默认保留最近 7 天的所有版本、30 天内每日一份、26 周内每周一份，此后每月一份，目标上限 200 份。固定的版本和最新 10 份不受清理限制。Gist 使用 GitHub 的原生修订，不能固定、删除或自动清理。
- 即使关闭同步，本机也会在应用同步改动、恢复、导入、批量删除或删除文件夹前备份。未固定的备份默认保留至多 50 份、最长 90 天。**立即备份**会保存本机版本，并可同时创建服务器版本。
- **预览**按名称列出新增、移除和修改的项目。**恢复**先保存现状，再用所选版本替换本机数据，包括文件夹及其连接归属；同步已开启时还会上载新版本。服务器更新失败后，自动同步保持暂停。**仅补齐缺失项**不覆盖已有项目或还原已知删除项。**导出 JSON**写入明文，可能包含密码。打开使用其他同步密码的版本时，需要输入原密码。
- 如果同步将从本机或服务器移除超过「10 条或现有连接的 20%，取较大者」的连接，便会暂停。永久移除「已删除」的连接，或移除包含超过 10 条连接的文件夹子树时，也会检查。可以查看版本、用服务器副本恢复本机，或明确批准删除；自动同步不会代为确认。

## 账户

左侧栏最底部是账户状态条。未登录时显示**登录 GitHub，同步你的连接**，点击打开**使用 GitHub 登录**窗口，走 GitHub 的设备授权流程：窗口显示要打开的地址（`https://github.com/login/device`）和 8 位设备码，各有**打开**和**复制**按钮，**复制设备码并打开 GitHub** 一次做完两件事。在 GitHub 页面输入设备码并授权 Finallyshell，窗口会显示设备码的剩余时间（15 分钟）并等待，授权完成后自动关闭。整个过程不需要输入或粘贴令牌，Finallyshell 也接触不到 GitHub 密码，只申请 Gist 的读写权限（用于账户同步）和读取邮箱的权限。授权被拒绝或设备码过期时，点**重新获取设备码**重新开始。

登录后，状态条显示账户头像（首字母，角上有个圆点：绿色表示已同步，蓝色表示同步中，橙色表示等待你处理，红色表示失败或登录已失效）、显示名（没有设置时显示用户名）、GitHub 标志和同步状态（如**已同步 · 2 分钟前**）。点击状态条弹出账户卡片：名字、`@用户名`、打码后的主邮箱（点**显示**看完整邮箱）、**GitHub · 已登录**、同步状态和设置、**立即同步**、**账户与同步设置…**、**操作记录**和**退出登录**。退出登录会先询问，本机的连接和 GitHub 上的 Gist 都会保留。

登录后不需要任何其他操作，账户会自动同步。账户同步与[同步](#同步)完全独立：使用单独的私密 Gist（`finallyshell-account.json`），有自己的同步密码、状态和记录。两者可以同时开启，但不会同时运行。合并方式相同，也包括[可能保存着旧数据的电脑](#同步)先询问的处理。

**账户与同步设置…**打开**账户**窗口。登录状态下，**选项 › 账户**里显示同样的内容，和窗口保持同步：

- **同步密码**：默认是账户的 GitHub 邮箱，这样每台登录同一账户的电脑都不用输入任何东西就能同步。但邮箱不算机密：开启了“包含已保存的密码”时，窗口会提醒你，拿到 Gist 链接又知道你邮箱的人可以解密。**当前同步密码**默认隐藏，点**显示**查看，点**复制**复制。**修改同步密码…**会用新密码重新加密云端当前的数据（GitHub 上的历史版本仍是旧密码加密的），并保留上次同步的数据作为下次合并的基准；**改回使用 GitHub 邮箱**可以改回去。
- **多台电脑密码不同**：云端文件的明文头里只记录用的是哪种密码，从不记录密码本身。本机密码打不开时，会自动用账户所有已验证的邮箱逐个尝试，能打开就改用那个，比如另一台电脑已经改回使用邮箱的情况。都打不开时才会询问：如果是另一台电脑设置了自定义密码，会写明是哪台电脑、什么时候改的；输入一次后本机会记住。
- **更换邮箱**：已经同步过的电脑继续使用它保存的密码。登录状态下，应用启动时以及之后每 6 小时会重新读取一次账户资料；如果主邮箱变了，而账户正在用邮箱作同步密码，就在后台用新邮箱重新加密云端数据，并记入操作记录。之后登录的电脑直接用新邮箱；其他电脑会自动跟随，因为新邮箱在它们尝试的邮箱列表里。
- **使用默认同步设置**（默认开启）：自动同步、包含已保存的密码、每 15 分钟检查一次。本机改动约 1 分钟后上传，每次检查都会拉取其他电脑的改动，逐条合并。取消勾选后，**包括已保存的密码**、**自动同步**及其间隔由账户单独设置，与“同步”页互不影响。
- **立即同步**、**用本机数据替换远端…**，以及**在 GitHub 上查看 Gist** 和 **GitHub 上的历史版本**（分别打开 Gist 和它的修订记录）。
- **历史版本…**（账户卡片上的**历史版本**也是）打开**账户历史版本**窗口：列出账户每次同步留下的版本（即 Gist 的修订），以及本机自己的备份，用法同[备份与版本](#备份与版本)。**预览**把某个版本和本机数据对比，列出连接、文件夹、快捷命令、设置、代理、数据库、信任的主机密钥和命令历史各自新增、删除、修改了什么；如果还原会删除本机现有的内容，会醒目提醒。**还原**会先备份本机数据，再把本机和 Gist 都恢复成这个版本；**仅补齐缺失项**只添加本机缺少的内容，不删除任何东西。防误删窗口里的**查看版本**也会打开这个窗口。
- **操作记录**：账户的记录，最新的在最上面，包括每次登录、退出登录、续期、登录失效、修改同步密码（你自己改的、跟随其他电脑的、更换邮箱后自动的）、选择同步方式，以及每次同步（自动、手动或选择后的）和它的结果。点击一条同步记录可以展开它的步骤（续期登录令牌、读取 Gist、首次同步时创建 Gist、合并、上传、备份本机数据、应用到本机），在本机和服务器上各新增、删除、修改了几项，冲突数，所在设备，以及出错原因。什么都没改的自动同步会合并成一条，并记下次数（如“**12 次检查都已是最新（自 19:10 起）**”），不会把其他记录挤掉；旧版本逐条写下的这类记录也一样合并显示。账户页只显示最近 5 条，**查看全部记录…**打开**账户操作记录**窗口：用表格列出全部记录（时间、操作、触发方式、结果、本机和服务器的变化、设备），可以筛选**有改动**、**失败与暂停**或**账户操作**，选中一条在下方显示详细步骤。**清空记录**清除全部记录。“同步”页的同步日志不会记录账户同步，账户记录里也不会出现“同步”页的同步。

OAuth 应用开启了令牌过期时，GitHub 的登录令牌有效期为 8 小时，到期前用刷新令牌自动续期。关闭令牌过期后，登录令牌一直有效，直到被撤销，也不再续期；此时如果 GitHub 拒绝旧的刷新令牌、而登录令牌本身仍然有效，就丢弃刷新令牌、继续保持登录。刷新令牌有效期为 6 个月，每次续期都会换成新的。应用会在同步前检查，令牌快到期时先续期。如果另一个运行中的 Finallyshell 已经抢先续期，就直接使用它换来的令牌。GitHub 拒绝令牌时，应用会续期或检查一次再重试；如果被拒的是刚续期得到的令牌，就只检查、不再续期，因为 GitHub 可能在续期时返回一个用不了的令牌。GitHub 不再接受这次登录时（授权被撤销、6 个月没有使用，或续期得到的令牌用不了），显示**登录已失效**；用同一个账户**重新登录**后，原来的 Gist 和设置都会保留。登录另一个账户时，会使用那个账户自己的 Gist。

## 应用锁

应用锁默认关闭。在 **选项 › 安全** 设置密码后，每次启动都要解锁；更改或移除密码需要输入当前密码。空闲锁定可选 **关闭** 或 **1、5、15、30、60 分钟**，也可在主窗口最小化或隐藏到托盘时锁定。可在此页、命令面板和托盘菜单选择 **立即锁定**。Windows 和 Linux 的快捷键是 `Ctrl+Alt+L`，macOS 是 `Command+Option+Shift+L`。

锁定后，各窗口只显示锁屏，已建立的连接和正在进行的传输继续运行。输错密码后，重试等待时间依次为 1、2、4、8、16 秒，之后最多 30 秒。应用锁只保护应用界面，不能替代操作系统锁屏。

忘记密码时，选择 **重置应用锁…**，并确认删除此设备上本应用记住的凭据。重置会移除应用锁并退出，断开所有连接、停止传输，并丢弃未保存的编辑。已保存的连接配置、私钥文件和云端备份不会更改。完成重置后，重新打开应用即可继续使用。

[分屏](#分屏)的会话里，关闭标签先关闭获得焦点的分屏。

说明：

- 以前 Ctrl+Shift+T 打开连接管理器，现在和别的终端程序一样是新标签页；新标签页上就有最近的连接和“连接管理器”按钮。连接管理器改成 Ctrl+Shift+O。
- 关闭标签在 macOS 上是 Cmd+W，不是 FinalShell 的 Cmd+Q（那是退出）。为了让 Cmd+W 到达窗口，macOS 上的菜单栏去掉了 MyGo 默认的“文件”菜单（里面的“关闭窗口”占着 Cmd+W）。主窗口里 Cmd+W 关闭标签。子窗口（选项、连接编辑器）里 Cmd+W 关闭这个子窗口，和别的 Mac 程序一样（“关闭标签”改成别的键后，那个键也关闭子窗口），Esc 也照样关闭。Windows 和 Linux 上子窗口用 Esc 和系统的关闭按钮。文件编辑器例外：Cmd+W（Ctrl+W）关闭标签，Esc 不关闭窗口（见[编辑远程文件](#编辑远程文件)）。
- macOS 上切换标签只用 Cmd+数字：Option+数字会输入字符（¡、™、£……）。
- Windows 上 terminal 插件默认还把 Ctrl+C（有选中时复制）和 Ctrl+V（剪贴板有内容时粘贴）绑成复制粘贴。Finallyshell 去掉了这两个，和 Linux 一样留给 shell（中断、原样输入下一个键）。复制粘贴用 Ctrl+Shift+C / Ctrl+Shift+V，或 Ctrl+Insert / Shift+Insert。
- 聚焦命令输入框不用 Ctrl+Shift+K：Windows 上那是终端的清屏（和 Windows Terminal 一样）。FinalShell 单按 Ctrl 切换，会和 shell 用的每个 Ctrl 键冲突，所以没有照搬。关掉命令输入框后，这个键交给终端。
- 切换会话/连接用 E，和 VS Code 打开侧栏文件树的“资源管理器”一样；没有终端绑定 Ctrl+Shift+E。macOS 上也加 Shift，因为 Cmd+E 在 Mac 应用里是“用所选内容查找”。Linux 上旧版 IBus 用 Ctrl+Shift+E 输入表情，会先于本程序拿走这个键；按了没反应的话，在“快捷键”页换一个键，或在 IBus 的首选项里改掉。
- 显示或隐藏底部面板用 J，和 VS Code 一样。只按 Ctrl+J 在 shell 里是换行，所以 Windows 和 Linux 上也加 Shift。全屏时和在单独标签中打开的面板上，这个键不起作用。
- 分屏的快捷键在 macOS 上和 Ghostty 一样，在 Windows 和 Linux 上和 Windows Terminal 一样（Alt+Shift+= 就是它在美式键盘上的 Alt+Shift+Plus）。Windows Terminal 没有放大的快捷键；Ctrl+Shift+X 是 Terminator 的，也不是哪个终端或文本框的键（Ctrl+Shift+Z 在文本框里是重做）。Alt+方向键也是一些 shell 和编辑器会读的键（fish 和一些 readline 配置里 Alt+← 按词移动），Alt+Shift+- 是 bash 的 Alt+_（插入上一条命令的最后一个参数，和 Alt+. 一样）：移动焦点和放大的键只在显示的会话分了屏时才占用，只有一个分屏的会话照常收到它们；分屏的键只在能分屏时占用。“快捷键”页允许分屏的操作用这些 Alt 键，会给出提示，都可以在那里改。
- 只带 Ctrl 的字母键（Ctrl+A……Ctrl+Z 等）都是 shell 的，在 Windows 和 Linux 上不当快捷键用。MyGo 的 legacy 键盘模式下 Ctrl+[、Ctrl+I、Ctrl+M 什么也不发送，是上游的问题（#21），这里没有绕开。

## 布局和分隔条

拖动窗口各区域之间的分隔条调整大小（获得焦点后也可以用方向键），双击分隔条恢复默认大小。每个区域有最小尺寸，不会被拖到看不见。大小保存在 `finallyshell/settings.json`，下次启动恢复。“进程”和“网络”页的分隔条也一样，所有会话共用，在底部面板里和在单独标签里打开的面板中都是同一个位置。

底部面板还可以收起，只留一行标签（见[窗口布局](#窗口布局)）；分隔条的位置会保留，展开后回到原处，是否收起和大小一起保存。

底部面板在右边时，终端和右栏之间的分隔条调整右栏的宽度，最窄 410 DIP（面板里各区域需要的宽度，最宽的是“进程”详情的左右两半），最宽到终端只剩 320 DIP；双击恢复为 460。宽度和其他大小一起保存；终端下方那条分隔条的位置会保留，面板放回底部时回到原处。

监控和底部面板都在右边时，两者之间的分隔条调整监控占这一栏高度的比例，默认 45%，监控至少留下 IP 那一行，面板至少留下标签和表格的一行；双击恢复为 45%。比例和其他大小一起保存。不论这一栏里放的是哪个，宽度都一样。

“命令”页的命令编辑器有自己的分隔条，在按钮旁边或下面；它也和其他大小一起保存（见[命令编辑器](#命令编辑器)）。

## 更新

Finallyshell 从本项目 `geekoutnet/finallyshell` 的 GitHub 发布更新自己。这些构建没有签名，所以不用 MyGo 的签名更新插件，而是由应用自己检查、下载和安装（`updates.go`）。

- 检查：每次启动都检查一次（不论上次检查是多久以前），有新版本就在右下角弹出更新卡片；运行期间每天再检查一次（距上次成功检查满 24 小时）。同时询问本项目的全部下载镜像（`updates.go` 里的 `updateMirrors`），用最先回答的那个；镜像都不可用时才查询 GitHub API。“选项 › 常规”里的“自动检查更新”可以关掉后台检查，默认开。
- 发现新版本时，主窗口右下角弹出更新卡片：新版本号、当前版本、“查看更新内容”（打开这个版本的发布页面），以及“稍后再说”和“立即更新”。“稍后再说”之后本次运行不再提示这个版本，下次启动或发现更新的版本时再提示。
- “立即更新”从镜像下载这个版本的安装程序，用发布里的 `SHA256SUMS` 校验，卡片上显示下载进度；之后应用退出，静默运行安装程序，装完重新启动。下载或校验失败时卡片上会说明，并提供“重试”。
- “选项 › 常规”里的“检查更新…”立刻检查，已是最新版本或检查出错时也会说明。这里还显示当前版本和检查到的新版本，也可以在这里安装。

哪些副本能在应用内安装更新：

| 系统 | 安装方式 | 应用内安装 |
|---|---|---|
| Windows | 安装程序安装的（安装目录里有 `Uninstall.exe`） | 能 |
| Windows | 便携版 zip | 不能，卡片上是“前往下载” |
| macOS、Linux | 任意 | 不能，卡片上是“前往下载” |
| 任意 | 开发版本（`go run`、`mygo dev`） | 不检查 |

不能在应用内安装的副本同样会检查和提示，“前往下载”打开这个版本的[发布页面](https://github.com/geekoutnet/finallyshell/releases)，手动下载安装。

说明：

- macOS 版是 ad hoc 签名、没有公证的，第一次打开要按发布说明解除隔离；Windows 的安装程序没有 Authenticode 签名，SmartScreen 可能提示。
- 是否自动检查、上次检查的时间保存在配置目录的 `update-check.json`，见 [configuration.md](configuration.md#update-checkjson)。
