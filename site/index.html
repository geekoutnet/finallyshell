所有服务器，
一个窗口。

终端、文件、监控、Docker、网站和数据库放在同一个原生窗口里。布局和 FinalShell 一样，会话标签竖着排，开二十台也看得清。

免费下载 全部安装包 支持 macOS、Windows 和 Linux，免费使用
SSH、Telnet、串口、远程桌面四种连接，跳板机和代理可以串起来
服务器上不装任何东西监控和管理都通过同一个 SSH 连接完成
密码不落地存在系统钥匙串里，同步前先在本机加密
原生程序不需要 Java，打开就是熟悉的布局
会话 (9)
  1. 终端与会话分屏、快捷命令、批量执行
  2. 文件与传输SFTP、编辑器、服务器间直传
  3. 服务器监控CPU、内存、网络、进程
  4. 服务器管理Docker、网站、系统、数据库
  5. 隧道与代理转发、SOCKS5、内网穿透
  6. 桌面模式多窗口、Dock、AI 助手
  7. 账户与同步GitHub 登录、多设备合并
  8. 迁移FinalShell、Xshell 等导入
  9. 下载macOS、Windows、Linux

会话竖着排，开多少台都不挤

左上是服务器状态，下面是会话列表，右边是终端，终端下面是服务器上的文件。会话标签可以滚动、拖动排序，也能拆成单独的标签和分屏。

  • 常用命令存成按钮，或者在命令编辑器里写几行一起发；一条命令可以同时发给多台服务器，结果汇总对比
  • 错误、警告、IP 地址等关键词高亮，会话录制回放，rz、sz 直接传文件
  • GBK、Big5、Shift_JIS 等编码的服务器照常显示，退格键和删除键发送什么可以按主机设置
  • 二次验证码自动填写，SSH 密钥一键生成和部署，支持 SSH Agent 和 X11 转发

服务器上的文件就在终端下面

文件面板跟着终端的当前目录走。拖进来就上传，成千上万个小文件自动打包压缩再传，两台服务器之间可以直接互传，不用先下载到本机。

  • 内置代码编辑器：多标签、语法高亮、指令补全，保存前先看改了什么
  • 压缩解压、修改权限、远程下载链接，删除先进回收站
  • 没有 SFTP 的路由器可以一键装上

服务器状态一眼看清

CPU、内存、交换区、网速、延迟、磁盘和进程就在会话旁边，走的是同一个连接。概览页把负载、端口、服务和容器放在一页里。

  • 网络连接列表、按网卡的网速曲线、路由追踪和 IP 归属地
  • CPU、内存、磁盘超过阈值时提醒
  • 一键清理缓存、整理内存碎片

常用的服务器面板，搬进了客户端

宝塔、1Panel 里最常用的那部分，直接通过 SSH 完成。需要 root 时自动提权；重启服务、改防火墙这类操作，执行前都会写清楚会动什么。

容器、镜像和编排

新建和重建容器，看资源曲线，进容器浏览文件；拉取、构建、推送镜像；部署和编辑 compose 项目。

  • 容器批量启停和清理
  • 网络和存储卷
  • 磁盘占用、事件、镜像仓库
  • 守护进程配置

Nginx、Caddy 和证书

站点表单和常用模板，配置检查失败自动恢复；Caddy 一键安装、更新和迁移；证书到期提醒。

  • 反向代理、静态站、PHP、SPA
  • Nginx 性能参数和日志
  • 配置备份和还原
  • 从 Nginx 迁移到 Caddy

服务、日志和定时任务

systemd 服务的启停和开机自启，按级别和时间筛选日志，定时任务立即运行。

  • 防火墙规则
  • 安全检查
  • 软件更新
  • 磁盘分析

MySQL、PostgreSQL 和 Redis

经 SSH 连接服务器上的数据库，浏览表和数据，执行查询；密码只存在系统钥匙串里。

  • MySQL 和 MariaDB
  • PostgreSQL
  • Redis 键值浏览

路由器也能管

自动识别 OpenWrt 和 ImmortalWrt，系统页换成路由器专用的内容。

  • 网络接口和 DHCP 租约
  • 端口转发
  • procd 服务
  • opkg、apk 软件包

端口转发，不用再记 ssh -L

本地、远程和动态转发都用表单建，可以在后台常驻、开机自启、断线自动重连。也能让服务器借用本机的网络，或者通过系统代理分流。

  • SOCKS5 和 HTTP 代理、反向代理、Unix socket，来源白名单和限速
  • 21 个常用场景一键创建，ssh -L/-R/-D 命令直接导入
  • 代理库统一管理代理，测试连通性、延迟和出口 IP

每台服务器都有自己的桌面

打开桌面模式，服务器就像一台电脑：此电脑、文件管理、任务管理器、终端、浏览器和应用中心，窗口可以拖动、缩放和贴边。

  • AI 助手直接在服务器上执行命令：只读的自动运行，会改动的逐条确认，危险操作要手动输入确认
  • 回收站、压缩解压、跨服务器复制粘贴
  • 壁纸、图标文件夹和 Dock 都能自定义

换一台电脑，连接都在

用 GitHub 账号登录，连接和设置会自动同步到你自己的私密 Gist。多台电脑之间逐条合并改动；很久没用的电脑重新同步前，会先问你是合并、用云端的，还是以本机为准。

  • 内容离开电脑前就已加密，默认用 GitHub 邮箱作同步密码，也可以换成自己的
  • 保留历史版本，可以预览和还原；大批量删除前会暂停，等你确认
  • 不用 GitHub 的话，也可以同步到坚果云、Nextcloud 等 WebDAV，或 S3 兼容存储

原来的服务器，直接带过来

导入 FinalShell、Xshell、SecureCRT、MobaXterm 的连接和文件夹，~/.ssh/config 里的主机，或者 CSV、Excel 格式的服务器列表。

下载

最新版本在 GitHub Releases。

Windows

  • 安装程序 .exe
  • 免安装版 .zip

SmartScreen 提示没有签名时，点“更多信息”，再点“仍要运行”。之后程序会自己更新。

macOS

  • Apple 芯片 .dmg
  • Intel 芯片 .dmg

还没有经过 Apple 公证。拖进“应用程序”后，在终端运行：

xattr -dr com.apple.quarantine /Applications/Finallyshell.app

或者在“系统设置 › 隐私与安全性”里点“仍要打开”。

Linux

  • Debian、Ubuntu（x64） .deb
  • Debian、Ubuntu（ARM64） .deb
  • 其他发行版（x64） .tar.gz
  • 其他发行版（ARM64） .tar.gz

压缩包解开后运行 sh install.sh，装到 ~/.local。记住密码需要 GNOME Keyring、KWallet 等密钥环。

从源码构建

需要 Go 1.27.3 或更新的版本。go tool mygo dev 运行程序，改了代码会自动重启。

git clone -b dev https://github.com/geekoutnet/finallyshell.git && cd finallyshell && go tool mygo dev
